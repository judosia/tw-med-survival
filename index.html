值班小撇步

值班時最需要知道的事

精選最實用的值班生存原則，其他的交給各科頁面。

緊急判斷

深夜接到叫喚：先問兩件事

「意識清楚嗎？生命徵象穩定嗎？」——這兩個問題決定你接下來五分鐘要做什麼。穩定 → 電話先處理；不穩定 → 立刻跑去。

叫主治

何時該叫醒主治？就現在

生命徵象嚴重異常、處置超出你能力範圍、你覺得不對勁——這三種情況打電話不是打擾，是你的責任。不打才是真的麻煩。

交班

交班讓接手的人能睡著

哪個穩定、哪個在觀察、哪個隨時可能出事——三分鐘說清楚。你希望怎麼被交班，就怎麼交班別人。

體力

有機會躺就躺，哪怕 15 分鐘

值班室的床是讓你不要站著撐完 36 小時用的。15 分鐘打盹讓你接下來兩小時比沒睡清醒。不用有罪惡感。

Code Blue

Code Blue 第一步：叫人

發現無反應，先啟動急救系統再開始 CPR。一個人做 CPR 是無效的急救，叫人才是對的。

critical value

Critical value 出現先打電話

K⁺ <2.5 或 >6.5、Na⁺ <120 或 >160、血糖 <50 或 >500、Hb <7——出現時第一件事是通知主治，不是查書。
