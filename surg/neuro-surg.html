神外評估基礎 Neurosurgical Assessment
神外評估三大核心：GCS（Glasgow Coma Scale）量化意識程度；瞳孔評估反映顱內壓和腦幹功能；神經學局部症狀定位病灶。正常顱內壓（ICP）= 5-15 mmHg；>20 mmHg = 顱內壓升高需處置；>40 mmHg = 嚴重危及生命。腦灌流壓（CPP）= MAP - ICP，目標 60-70 mmHg。

數值判讀
ICP 監測 + CPP 管理 + Cushing's Triad

Monro-Kellie 假說

  • 顱腔容積固定 = 腦組織（80%）+ 腦脊液（10%）+ 血液（10%）
  • 任何成分增加 → 其他成分代償性減少；代償耗盡 → ICP 急劇升高

Cushing's Triad（顱內壓升高的晚期徵象）

Cushing's Triad = 高血壓 + 心搏過緩 + 呼吸不規則 → 腦疝即將發生，立刻處置！
  • 高血壓（↑ SBP）：代償性維持 CPP
  • 心搏過緩（↓ HR）：迷走神經反射
  • 呼吸不規則：腦幹受壓

ICP 監測方式

方式特性
腦室外引流（EVD）金標準；可監測 + 引流 CSF；感染風險；需每日校正
腦實質感應器（Bolt）較簡單；只監測不能引流；Camino / Codman 系統
硬膜下 / 硬膜外感應器較不準確；較少用

關鍵數值目標

  • ICP 目標：<20 mmHg（嚴重 TBI）；<15 mmHg（一般）
  • CPP = MAP - ICP：目標 60-70 mmHg；<50 mmHg = 腦缺血風險
  • MAP 目標：TBI 患者維持 SBP >90 mmHg（避免低血壓惡化腦缺血）
  • SpO₂：>95%；PaO₂ >60 mmHg；避免低血氧
  • 血糖：維持正常（避免高血糖加重神經損傷）
  • 體溫：積極控制發燒（↑ 體溫 → ↑ 腦代謝 → ↑ ICP）
顱內出血 Intracranial Hemorrhage
顱內出血四大類型依解剖位置分：硬膜外血腫（EDH）= 動脈出血，雙凸透鏡形，classic lucid interval；硬膜下血腫（SDH）= 靜脈出血，新月形，老年人常見；蜘蛛網膜下腔出血（SAH）= 動脈瘤破裂，「一生中最嚴重的頭痛」；腦內出血（ICH）= 高血壓最常見原因。CT 是第一線影像。

蜘蛛網膜下腔出血（SAH）

「一生中最嚴重的頭痛（Thunderclap headache）」= SAH 直到排除為止！CT 陰性 → 腰椎穿刺（Xanthochromia）。
  • 最常見原因：腦動脈瘤破裂（75-80%）；動靜脈畸形（AVM）；外傷
  • 危險因素：高血壓；吸菸；家族史；多囊腎（PKD）；結締組織病（Marfan / Ehlers-Danlos）
  • 好發位置：前交通動脈（ACoA，最常見）；後交通動脈（PCoA）；大腦中動脈（MCA）分叉
  • CT：星狀高密度（蜘蛛網膜下腔；腦池充滿血液）；敏感度 98%（6 小時內）→ 之後下降
  • CT 陰性 + 高度懷疑 → 腰椎穿刺：Xanthochromia（黃變色）= 血紅素降解產物；出血後 2-4 小時出現，持續數週
  • Hunt-Hess 分級：I（無症狀）→ V（深昏迷 / 去大腦姿勢）；越高分預後越差
  • 主要併發症：
    • 再出血（Re-bleeding）：24 小時內最高風險；死亡率 70%；動脈瘤夾閉（Clipping）或線圈栓塞（Coiling）是根本治療
    • 血管痙攣（Vasospasm）：出血後 4-14 天；缺血性腦梗塞；Nimodipine（CCB）預防；3H 療法（Hypertension + Hypervolemia + Hemodilution）→ 現僅維持正常血容量
    • 水腦症：急性（CSF 阻塞）→ EVD 引流；慢性 → VP shunt
    • 低血鈉：SIADH 或 Cerebral salt wasting；需鑑別（治療不同）

腦內出血（ICH）

  • 最常見原因：高血壓（60-70%，基底核最常見）；澱粉樣血管病變（Amyloid angiopathy，老年人皮質下）；抗凝血藥物；腦腫瘤出血；AVM
  • ICH Score：GCS + 血腫體積 + 腦室內出血 + 出血位置 + 年齡；預測 30 天死亡率
  • 處置：血壓控制（SBP 目標 140-160 mmHg）；逆轉抗凝血（Vitamin K / PCC / FFP / Protamine）；ICP 管理；手術（幕上血腫 >30 mL 且可到達者；小腦出血 >3 cm 或壓迫腦幹 / 水腦症）
頭部外傷 Traumatic Brain Injury（TBI）
TBI 是全球主要致死和致殘原因。重度 TBI（GCS ≤8）需要氣道保護、ICP 監測和積極處置。輕度 TBI（腦震盪）= GCS 13-15，症狀多數數週內恢復，但需注意「Second impact syndrome」（二次受傷）。避免二次傷害（Secondary injury prevention）是神外處置的核心——防低血壓、低血氧、高 ICP、發燒。

Canadian CT Head Rule（輕度 TBI，需做 CT 的條件）

  • 高危（需立刻 CT）：GCS <15（受傷後 2 小時）；懷疑開放性或凹陷性骨折；顱底骨折徵象（熊貓眼、Battle's sign、CSF 耳漏/鼻漏）；嘔吐 ≥2 次；年齡 ≥65 歲
  • 中危（需 CT）：失憶 ≥30 分；危險機轉（行人被車撞、從高處墜落 >3 呎 / 5 階）
  • 無意識喪失或失憶的輕微頭部外傷 → 不需常規 CT

重度 TBI ICP 管理（階梯式）

  • 第一階梯：頭部抬高 30°；鎮靜止痛（Propofol + Fentanyl）；維持正常體溫；維持血糖正常；維持 CPP 60-70 mmHg
  • 第二階梯：CSF 引流（EVD）；Mannitol 0.25-1 g/kg IV（滲透性利尿，目標 Osm 300-320）；Hypertonic saline（3% NaCl）100-200 mL（↑ 血清滲透壓 → ↓ 腦水腫）
  • 第三階梯：過度通氣（目標 PaCO₂ 30-35 mmHg，短期緊急使用）→ ↓ PaCO₂ → 腦血管收縮 → ↓ 腦血流 → ↓ ICP；注意：過度使用會造成腦缺血
  • 第四階梯：去骨瓣減壓術（Decompressive craniectomy）；Barbiturate 昏迷（Pentobarbital，難治性 ICP 升高）；低體溫療法（爭議中）
機轉說明
瀰漫性軸索損傷（DAI）+ 腦震盪後症候群

瀰漫性軸索損傷（Diffuse Axonal Injury，DAI）

  • 機轉：加速-減速傷害 → 剪切力 → 白質軸索瀰漫性撕裂；好發胼胝體（Corpus callosum）/ 腦幹 / 腦白質深部
  • CT：可能正常（DAI 不一定在 CT 上可見）；小出血點（Petechial hemorrhages）於灰白質交界
  • MRI：遠比 CT 敏感；T2/FLAIR 高信號；SWI 序列（對微出血最敏感）
  • 臨床：昏迷（可能長期）；去皮質 / 去大腦姿勢；與 CT 顱內出血量不成比例的嚴重意識改變
  • 預後：腦幹 DAI 預後最差；嚴重 DAI 常導致植物人狀態

腦震盪後症候群（Post-Concussion Syndrome）

  • 症狀（持續 >3 個月）：持續頭痛；認知改變（記憶、注意力）；睡眠障礙；情緒問題（焦慮、憂鬱）；頭暈；光聲敏感
  • 危險因素：女性；年長；有頭痛病史；憂鬱焦慮；高強度工作壓力
  • 治療：認知休息（逐漸恢復）；心理支持；症狀治療（頭痛、睡眠）；避免過早恢復接觸性運動（二次受傷）
  • 運動員腦震盪：同一次賽季第二次腦震盪（Second impact syndrome）= 腦血流調節失常 → 惡性腦水腫 → 死亡率高；禁止帶傷上場
脊椎急症 Spine Emergencies（脊髓損傷 + 馬尾症候群）
馬尾症候群（Cauda Equina Syndrome）是外科急症——延遲手術 >48 小時預後顯著變差。脊髓損傷（SCI）急性期主要任務是固定 + 避免二次損傷 + 維持脊椎灌流壓。脊髓休克（Spinal shock）= 急性損傷後暫時性完全無反射，需與真正的完全性損傷鑑別。

ASIA Impairment Scale（AIS）

分級定義

不完全性脊髓損傷症候群

症候群損傷部位特徵
中央脊髓症候群（Central cord，最常見）頸椎中央（老年人過伸傷害）上肢 > 下肢無力；膀胱功能障礙；感覺保留
前脊髓症候群（Anterior cord）前脊髓動脈梗塞運動和疼痛/溫度感覺喪失；本體感覺保留（後柱保留）
Brown-Séquard 症候群半側脊髓切斷（穿刺傷）同側運動 + 本體感覺喪失；對側痛溫感覺喪失
後脊髓症候群（Posterior cord，罕見）後柱損傷本體感覺和振動感覺喪失；運動保留

急性脊髓損傷處置

  • 固定：頸椎護具（Cervical collar）+ 脊椎板（Spine board）直到影像排除不穩定骨折
  • 血壓目標：維持 MAP >85 mmHg（脊椎灌流壓）× 7 天；避免低血壓（神經性休克 → Norepinephrine）
  • 類固醇：Methylprednisolone（高劑量）= 現多數指引不建議常規使用（副作用 > 效益）；若使用需在 8 小時內開始
  • 手術：不穩定骨折；進行性神經惡化；有壓迫可解除者 → 早期手術（24-48 小時內）
緊急處置
馬尾症候群 + 頸椎骨折
馬尾症候群 = 外科急症！立刻 MRI + 緊急手術減壓。48 小時內手術預後顯著優於延遲。

馬尾症候群（Cauda Equina Syndrome，CES）

  • 原因：椎間盤突出（最常見）；腫瘤；硬膜外膿瘍/血腫；骨折
  • 症狀（ABCDE）：
    • A：Anorectal dysfunction（大便失禁 / 便秘）
    • B：Bladder dysfunction（尿滯留 / 尿失禁）= 最重要警訊！
    • C：Cauda equina pain（下背痛 + 雙側放射）
    • D：Decreased sensation（鞍區麻木，Saddle anesthesia）= 肛門 / 會陰 / 大腿內側
    • E：Extremity weakness（雙側下肢無力）
  • 診斷：MRI 腰椎（緊急）；CT 可評估骨骼
  • 治療：緊急手術減壓（Emergent decompression laminectomy）；48 小時內效果最好；延遲 → 永久膀胱/大腸功能障礙

頸椎骨折重要類型

顱內腫瘤 Intracranial Tumors
顱內腫瘤可分為原發性（起源自腦組織）和轉移性（最常見，尤其肺癌、乳癌、黑色素瘤）。膠質母細胞瘤（GBM）是最惡性的原發腦瘤，中位存活期約 15 個月。腦膜瘤（Meningioma）是最常見的良性顱內腫瘤。腦瘤常見三徵：頭痛 + 噁心嘔吐 + 局部神經缺損。

腫瘤特徵治療
膠質母細胞瘤（GBM，WHO Grade 4） 最惡性原發腦瘤；成人最常見惡性腦瘤；環形強化（Ring enhancement）；蝴蝶膠質瘤（Butterfly glioma，跨越胼胝體）；IDHI 野生型；預後極差 最大程度安全切除 → Temozolomide + 放療（Stupp protocol）→ 輔助 Temozolomide；MGMT 甲基化 → 化療反應較好；中位存活 15 個月
低惡性度膠質瘤（WHO Grade 2） 年輕成人；生長緩慢；IDH1 突變（預後較好）；癲癇常為首發症狀；T2/FLAIR 高信號，無明顯強化 手術切除（盡量多切）；放療 + 化療（依危險因子）；長期追蹤（可轉變成高惡性度）
腦膜瘤（Meningioma） 最常見良性顱內腫瘤；女性多（雌激素受體）；硬膜附著；Dural tail sign（MRI 增強）；WHO Grade 1（良性）多數；緩慢生長 小且無症狀 → 觀察；有症狀或進展 → 手術切除；放射手術（Gamma knife，小型）；復發率依切除完整度
聽神經瘤（Vestibular Schwannoma） 第八對腦神經（前庭蝸神經）；內耳道擴大；單側感音神經性聽損 + 耳鳴；雙側 = NF-2；Ice cream cone sign（MRI） 小 → 觀察；中 → Gamma knife；大 → 手術（面神經保留）
髓母細胞瘤（Medulloblastoma） 兒童最常見惡性腦瘤；後顱窩（小腦蚓部）；第四腦室阻塞 → 急性水腦症；容易沿 CSF 播種（Drop metastasis） 手術 + 全腦脊髓放療 + 化療；5 年存活率約 70-80%
顱咽管瘤（Craniopharyngioma） 鞍上區（Suprasellar）；兒童 + 老年雙峰；蛋殼樣鈣化（Shell-like calcification）；視野缺損（雙顳側偏盲）；尿崩症；垂體功能低下 手術切除 ± 放療；激素替代治療

腦轉移（Brain Metastasis）

  • 最常見的顱內腫瘤（比原發腦瘤更多）
  • 原發來源（依頻率）：肺癌（最常見，40%）→ 乳癌 → 黑色素瘤（最容易出血）→ 腎細胞癌 → 大腸癌
  • CT / MRI：多發性環形強化病灶；位於灰白質交界（cortical-subcortical junction）；伴隨大量血管性水腫
  • 治療：
    • 單一轉移（Solitary，可切除）+ 原發灶控制 → 手術切除 + 全腦放療（WBRT）
    • 1-4 個病灶（小）→ 立體定向放射手術（SRS，Gamma knife / Cyber knife）
    • 多發性或廣泛轉移 → 全腦放療（WBRT）+ 類固醇
    • 依原發癌種的靶向治療（如肺腺癌 EGFR 突變 → Osimertinib 可穿過血腦障壁）

腦水腫（Cerebral Edema）處置

類型機轉治療
血管性水腫（Vasogenic，最常見） 血腦障壁破壞 → 蛋白質和液體進入細胞外間隙；腫瘤 / 膿瘍 / 轉移 Dexamethasone 最有效；4-10 mg IV q6h；數小時內有效；適合腫瘤相關水腫；外傷性腦水腫不建議使用
細胞毒性水腫（Cytotoxic） 細胞能量耗竭 → Na/K-ATPase 失能 → 細胞內水分積聚；缺血性腦梗塞最常見 Mannitol / Hypertonic saline（暫時）；類固醇無效；治療原因（溶栓 / 取栓）
間質性水腫（Interstitial） CSF 從腦室滲漏至周圍白質；梗阻性水腦症 引流 CSF（EVD / VP Shunt）
神外急症 Neurosurgical Emergencies（腦疝 + 水腦症）
腦疝（Brain herniation）= ICP 升高導致腦組織被迫移位，壓迫關鍵結構，是神外最緊急的急症。小腦幕切跡疝（Uncal herniation）= 單側散大瞳孔 + 對側偏癱 = 立刻處置。急性水腦症需緊急 CSF 引流。

腦疝類型

類型移位方向臨床表現
小腦幕切跡疝（Uncal / Transtentorial） 顳葉鉤回向下穿過小腦幕切跡 同側 CN III 壓迫 → 同側散大固定瞳孔；對側偏癱（錐體束受壓）；意識惡化；Cushing's triad
中央性疝（Central / Transtentorial） 雙側向下位移穿過小腦幕 雙側小瞳孔（初期）→ 雙側固定散瞳（晚期）；意識逐漸喪失；去皮質→去大腦姿勢
小腦扁桃體疝（Tonsillar / Downward） 小腦扁桃體疝入枕骨大孔 壓迫延髓 → 呼吸驟停；頸部僵硬；心搏過緩；最致命
鐮狀疝（Subfalcine / Cingulate） 扣帶迴越過大腦鐮 對側下肢無力（前腦動脈受壓）；早期可無症狀；中線偏移 CT 可見

腦疝緊急處置（分鐘計）

  • 立刻：頭部抬高 30°；叫神外；叫麻醉（可能需要緊急手術）
  • 過度通氣（最快）：Ambu bag 過度通氣 → PaCO₂ 30-35 mmHg → 腦血管收縮 → ↓ 腦血容量 → ↓ ICP；僅用於即將腦疝的橋接（不宜長期）
  • Mannitol 1 g/kg IV：快速推注（15-20 分）；滲透性脫水；效果持續 2-4 小時；目標 Osm 300-320；需尿液排出（無尿禁忌）
  • Hypertonic saline（3% NaCl）250 mL：Mannitol 替代或合用；適合低血壓患者（不造成利尿）；Na 目標 145-155 mEq/L
  • 緊急手術：移除占位病灶（血腫清除）；去骨瓣減壓術（Decompressive craniectomy）；EVD 引流 CSF

水腦症（Hydrocephalus）

類型機轉治療
阻塞性（Non-communicating） CSF 循環通道阻塞（腫瘤、血塊阻塞導水管或第四腦室） 緊急 EVD（腦室外引流）；移除阻塞原因；VP shunt
交通性（Communicating） CSF 吸收障礙（SAH 後蜘蛛網膜顆粒阻塞；腦膜炎後） LP（腰椎穿刺）；VP shunt；ETV（內視鏡第三腦室造口）
正常壓力水腦症（NPH） 老年人；CSF 吸收↓；ICP 正常 臨床三聯症（磁步態 + 失禁 + 失智）；LP 放液改善 → VP shunt

神外術後常見問題

  • 術後神經惡化：立刻 CT（排除血腫 / 水腫 / 腦梗塞）；血壓管理；ICP 監測
  • 術後癲癇：預防性 Levetiracetam（幕上手術）；癲癇控制依標準流程
  • 術後感染：腦膜炎（術後 1-2 週）；硬膜下積膿；傷口感染；EVD 相關感染（每 5-7 天考慮更換）；腦室炎（EVD 引流出混濁 CSF）
  • VP Shunt 功能異常：頭痛 + 噁心嘔吐（阻塞）→ CT（腦室擴大）→ Shunt tap / 更換；過度引流 → 低顱壓頭痛（站立加重）→ 調整壓力
  • CSF 漏（Fistula）：清澈水狀鼻漏或耳漏（含 beta-2 transferrin）→ 頭部抬高 + 避免用力；嚴重 → 硬膜修補
