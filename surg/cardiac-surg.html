心臟外科評估基礎 Cardiac Surgery Assessment
心臟外科術前評估的核心：EuroSCORE II是歐洲最廣泛使用的手術死亡風險預測工具；STS Score是北美標準。體外循環（Cardiopulmonary Bypass，CPB）是大多數心臟手術的基礎，提供無血靜止心臟的手術環境。了解 CPB 的原理有助於理解術後照護重點。

EuroSCORE II 高風險因子

  • 患者相關：年齡（>75 歲）；女性；腎功能不全（Cr >200 μmol/L）；肺疾病；周邊血管疾病；神經功能障礙；前次心臟手術；糖尿病（胰島素依賴）
  • 心臟相關：NYHA IV；不穩定型心絞痛；EF <30%；心臟衰竭；心內膜炎；心肌梗塞 <90 天
  • 手術相關：緊急 / 急救手術；合併手術（CABG + 瓣膜）；主動脈手術；術後 ICU
  • 台灣多使用 STS Score + EuroSCORE II 綜合評估；整體死亡率 <1%（選擇性單純 CABG）到 >20%（急救複雜手術）不等
機轉說明
體外循環（CPB）原理 + 心臟停跳液

CPB 基本迴路

  • 靜脈引流：右心房 / 腔靜脈 → 儲血槽（Venous reservoir）
  • 氧合：膜式氧合器（Membrane oxygenator）= 現代標準；同時排除 CO₂
  • 加溫 / 降溫：熱交換器（Heat exchanger）調控體溫；降溫（28-32°C）= 腦保護；深低溫停循環（DHCA，18°C）= 主動脈弓手術
  • 幫浦：滾輪幫浦或離心幫浦；提供非搏動性血流（Non-pulsatile flow）
  • 動脈輸回：升主動脈（最常見）/ 股動脈 / 腋動脈插管；主動脈鉗夾（Cross-clamp）阻隔
  • 抗凝：Heparin 3 mg/kg（ACT >480 秒）→ 術畢 Protamine 逆轉

心臟停跳液（Cardioplegia）

  • 目的：提供快速舒張期心臟停跳 → 無血靜止手術視野 + 心肌保護
  • 機轉：高鉀溶液（K⁺ 15-30 mEq/L）→ 使心肌細胞去極化停留在舒張期
  • 種類：冷含血停跳液（Cold blood cardioplegia，4°C，最常用）；溫含血停跳液（Warm blood，持續輸注）；Custodiol（HTK solution，單次大量）
  • 給予路徑：順行（Antegrade，主動脈根部或冠狀動脈開口）+ 逆行（Retrograde，冠狀靜脈竇）= 常合用確保均勻分布
  • 缺血時間（Cross-clamp time）：越短越好；>120 分 → 心肌損傷風險增加；每 20-30 分重複給停跳液

CPB 常見術後影響

  • 全身炎症反應（SIRS）：血液接觸異物表面 → 補體活化 → 炎症介質釋放 → 術後低血壓 / 水腫
  • 凝血功能異常：Heparin 逆轉後殘餘效果；血小板功能↓；凝血因子消耗
  • 認知功能改變（Pump head）：非搏動性血流 + 微栓塞 → 術後認知功能下降（老年人較明顯）
  • 腎損傷：低灌流 + 溶血 + 造影劑 → AKI（術後 Cr 監測）
冠狀動脈繞道手術 CABG（Coronary Artery Bypass Grafting）
CABG 是最常見的心臟手術之一，適合藥物治療無效或解剖上不適合 PCI 的冠狀動脈疾病。左內乳動脈（LIMA）→ 左前降支（LAD）是最重要的血管吻合，10 年通暢率 >90%，顯著優於靜脈繞道。Off-pump CABG（OPCAB）= 不停心跳手術，可避免 CPB 相關併發症。
判斷框架
CABG 適應症 + CABG vs PCI 選擇

CABG 適應症（ACC/AHA 指引）

  • Class I（強烈建議 CABG）：
    • 左主幹狹窄（Left main stenosis）≥50%
    • 三支血管病變（Three-vessel disease）+ EF <50% 或糖尿病
    • 三支血管病變 + SYNTAX score 高（解剖複雜）
    • 兩支血管病變 + 近端 LAD 病變 + EF <50% 或缺血證據
    • 急性 STEMI：PCI 失敗 or 無法 PCI；合併機械性併發症（VSD、乳頭肌斷裂）
  • CABG 優於 PCI 的情況：左主幹 + 多支血管病變（SYNTAX score >22）；糖尿病多支血管病變（FREEDOM trial）；腎功能不全；預期壽命長（生物瓣膜壽命）
  • PCI 優於 CABG 的情況：單支或雙支血管病變（非左主幹）；高手術風險；不願意手術；SYNTAX score 低（解剖簡單）

SYNTAX Score

  • 評估冠狀動脈病變複雜度；分數越高 = 病變越複雜
  • 低（≤22）：PCI 和 CABG 結果相近；可考慮 PCI
  • 中（23-32）：個別化決策；心臟團隊討論
  • 高（≥33）：CABG 優於 PCI；尤其合併糖尿病或左主幹

Off-pump CABG（OPCAB）

  • 不停心跳、不使用 CPB；穩定器（Stabilizer）固定手術區域心肌
  • 優點：避免 CPB 炎症反應；↓ 腎損傷；↓ 中風（減少主動脈操作）；↓ 輸血需求；適合高風險患者（腎衰竭、主動脈嚴重鈣化）
  • 缺點：技術要求高；吻合品質可能較差（心臟在跳動）；轉換為 On-pump 的風險
  • ROOBY / CORONARY trial：長期通暢率 OPCAB 可能略低於 On-pump；適應症需個別化

CABG 術後處置重點

  • 抗血小板：術後 6 小時開始 Aspirin 100 mg（SVG 通暢率）；雙重抗血小板（DAPT）爭議
  • Statin：術後繼續高強度 Statin（↓ SVG 動脈硬化）
  • 血壓控制：SBP 目標 100-130 mmHg（避免吻合口出血）
  • 心房顫動（術後 AF）：發生率 25-40%；術後 2-3 天最常見；Beta-blocker 預防；Amiodarone 治療
瓣膜手術 Valve Surgery（換瓣適應症 + 瓣膜選擇）
瓣膜手術的關鍵決策：修復（Repair）優於置換（Replacement）——二尖瓣修復可保留乳頭肌 / 腱索結構，維護左心室功能，且不需長期抗凝。機械瓣 vs 生物瓣的選擇取決於年齡、抗凝意願和生活需求。TAVR（經導管主動脈瓣置換）已成為高齡或高風險患者的主流選擇。
判斷框架
主動脈瓣 + 二尖瓣手術適應症

主動脈瓣狹窄（AS）手術適應症

  • 嚴重 AS 定義：AVA <1.0 cm²；mean gradient >40 mmHg；Vmax >4 m/s
  • Class I（手術）：有症狀的嚴重 AS（心絞痛 / 暈厥 / 心衰竭）；無症狀但接受其他心臟手術；EF <50%
  • TAVR vs SAVR：高風險 / 高齡（>75 歲）→ TAVR；低中風險年輕患者 → SAVR（瓣膜耐久性）；解剖禁忌（血管路徑差）→ SAVR

主動脈瓣逆流（AR）手術適應症

  • 有症狀的嚴重 AR（NYHA II-IV 或心絞痛）
  • 無症狀嚴重 AR + 任一：EF ≤55%；LVEDD >65 mm；LVESD >50 mm；接受其他心臟手術

二尖瓣逆流（MR）手術適應症

  • 有症狀嚴重 MR（原發性 / 退化性，可修復）
  • 無症狀嚴重 MR + 任一：EF 30-60%；LVESD ≥40 mm；新發 AF；肺高壓（PA systolic >50 mmHg）
  • 修復 vs 置換：二尖瓣前葉脫垂（Anterior leaflet prolapse）較難修復；後葉病變（最常見）修復成功率高 >95%
  • 繼發性 MR（Functional MR）：心衰竭 → 瓣環擴張；手術效益有限；MitraClip（經導管）= 高風險患者

人工瓣膜心內膜炎（PVE）

  • 早期（<12 個月）：S. aureus / CoNS（手術汙染）；死亡率高；多需再次手術
  • 晚期（>12 個月）：口腔鏈球菌 / Enterococcus（社區感染）；長期抗生素；選擇性手術
  • 手術適應症：心衰竭；無法控制感染；大型贅生物（>10 mm）+ 栓塞高風險；瓣周逆流；真菌感染
主動脈手術 Aortic Surgery（剝離 + 主動脈瘤）
Stanford A 型主動脈剝離（升主動脈受累）= 外科急症，死亡率每小時增加 1-2%，需立刻手術。Stanford B 型（僅降主動脈）= 內科處置為主（降壓）；合併器官缺血或進展時才需手術（TEVAR）。主動脈瘤的手術時機依直徑決定：升主動脈 >5.5 cm；降主動脈 >6.0 cm。

診斷 + 術前評估

  • 症狀：突發「撕裂樣」胸痛（Tearing / Ripping）放射至背部；疼痛最初最劇烈（vs MI 漸進加重）；遷移性疼痛（剝離延伸）；脈搏差異（雙側血壓差 >20 mmHg）
  • CXR：縱膈腔擴寬（>8 cm）；主動脈結突出；胸腔積液（左側）
  • CT 主動脈（金標準）：真腔（True lumen）/ 假腔（False lumen）/ 內膜撕裂（Intimal flap）；評估器官缺血
  • TEE（手術室）：評估 AR 嚴重度；冠狀動脈開口；外科決策
  • DeBakey 分型（舊）：Type I = 升 + 降；Type II = 僅升；Type III = 僅降（= Stanford B）

手術方式

  • 開放手術（Open repair）：升主動脈 / 主動脈弓 → 需 CPB；深低溫停循環（DHCA）= 弓部手術腦保護
  • TEVAR（Thoracic Endovascular Aortic Repair）：降胸主動脈；股動脈入路；避免開胸；高風險患者首選；需監測脊髓缺血（截癱）
  • EVAR（Endovascular Aortic Repair）：AAA 首選（解剖合適時）；股動脈入路；術後需定期影像追蹤（Endoleak）

主動脈瘤相關基因疾病

  • Marfan syndrome（FBN1 突變）：升主動脈 / 主動脈根部擴張；二尖瓣脫垂；晶狀體脫位；骨骼異常；β-blocker + Losartan 減慢擴張；閾值較低（>4.5 cm）
  • Loeys-Dietz syndrome（TGFBR1/2）：更積極性擴張；更小直徑即需手術（>4.0-4.5 cm）
  • 二葉主動脈瓣（BAV）：主動脈病變高風險；即使瓣膜功能正常也需追蹤主動脈直徑
心律手術 Cardiac Rhythm Surgery（節律器 + AICD + 外科消融）
心臟節律裝置（CIED）的植入和管理是心臟外科的重要部分。永久性節律器（PPM）適用於症狀性心搏過緩；ICD / AICD適用於預防心室顫動猝死；心臟再同步化治療（CRT）適用於合併心臟衰竭和左束支傳導阻滯的患者。手術後管理注意電磁干擾和裝置感染。
判斷框架
永久性節律器（PPM）+ ICD 適應症

永久性節律器（PPM）適應症（Class I）

  • 竇房結功能不全（Sick sinus syndrome）：症狀性竇性心搏過緩（頭暈、暈厥、運動不耐）；竇性停搏；快慢症候群（Tachy-brady syndrome）
  • 房室傳導阻滯（AVB）：症狀性 Second degree AVB（Mobitz II）；Complete heart block（Third degree AVB）= 絕對適應症（即使無症狀）；束支傳導阻滯 + 暈厥
  • 術後適應症：心臟手術後持續 AVB（>5-7 天）；瓣膜手術後需節律器

ICD / AICD 適應症

  • 二級預防（已發生）：心因性猝死存活者（VF / 血流動力學不穩定 VT）；無可逆原因；預期存活 >1 年
  • 一級預防（尚未發生）：缺血性心肌病 EF ≤35% + NYHA II-III（最佳藥物治療 >3 個月）；非缺血性心肌病 EF ≤35%（條件更嚴格）；遺傳性心肌病（HCM、ARVC、Brugada、長 QT）有高風險特徵

CRT（心臟再同步化治療）適應症

  • EF ≤35% + LBBB（QRS >150 ms）+ 最佳藥物治療中的 NYHA II-IV
  • CRT-D（CRT + ICD）= 同時符合 ICD 適應症時；CRT-P（僅節律）= 預後差或不需 ICD
用藥指引
外科消融（Maze）+ 裝置管理 + CIED 感染

Cox-Maze 手術（外科消融心房顫動）

  • 適應症：持續性或長期持續性 AF 患者接受其他心臟手術時（二尖瓣手術合併率最高）；症狀性 AF 導管消融失敗
  • 原理：在心房創造「迷宮」樣切割線（切割縫合或消融）→ 阻斷 AF 的折返路徑 → 竇性節律
  • Cox-Maze IV：現代版本；使用射頻 / 冷凍消融替代切割縫合；成功率 >80%（長期竇性節律）
  • 左心耳封閉（LAA closure）：同時進行 → 降低 AF 栓塞風險

CIED 裝置管理重點

  • 電磁干擾（EMI）：手術電刀（Electrocautery）= 最常見問題；使用雙極電刀；節律器依賴患者 → 程式改為 VOO/AOO 模式；放磁鐵 = 節律器轉固定頻率、ICD 暫停感應
  • MRI 相容性：現代裝置多可進行 MRI（MRI-conditional）；需確認裝置型號 + 特定條件
  • 電池更換：節律器電池壽命 5-12 年；ICD 3-7 年（放電耗電）；ERI（Elective replacement indicator）提示更換

CIED 感染（Cardiac Device Infection）

  • 病原：S. aureus（最危險）；CoNS（最常見）；革蘭氏陰性菌（糖尿病 / 免疫缺陷）
  • 分類：囊袋感染（Pocket infection）→ 發紅 / 腫脹 / 波動；導線感染（Lead infection）→ 菌血症 / 心內膜炎
  • 治療：完整移除裝置（包括所有導線）+ 靜脈抗生素是根本治療；不能只給抗生素；感染控制後重新植入（對側或新位置）
心臟外科急症 Cardiac Surgery Emergencies（IABP + ECMO + 術後照護）
機械性循環輔助（MCS）是嚴重心衰竭和心臟外科術後低心輸出量的橋接治療。IABP（主動脈氣球幫浦）= 最常用的短期輔助；VA-ECMO= 最強力的心肺輔助，但併發症多。心臟外科術後低心輸出量症候群（LCOS）是最重要的術後急性問題。
緊急處置
IABP + ECMO + 其他機械性循環輔助

IABP（主動脈氣球幫浦，Intra-Aortic Balloon Pump）

  • 原理：氣球位於降主動脈（左鎖骨下動脈以遠）；舒張期充氣 → 冠狀動脈灌流↑；收縮期放氣 → 後負荷↓（Afterload reduction）→ 心輸出量↑
  • 適應症：心因性休克（Cardiogenic shock，橋接）；高風險 PCI / CABG 輔助；頑固性不穩定心絞痛；急性 MR / VSD（術前穩定）；術後低心輸出量（LCOS）；難以脫離 CPB
  • 禁忌：嚴重主動脈逆流（充氣加重 AR）；主動脈剝離；嚴重主動脈及周邊血管疾病；無法抗凝
  • 效果：CO ↑ 10-20%；PCWP↓；MAP 維持；舒張壓↑（coronary perfusion）
  • IABP-SHOCK II trial：急性心肌梗塞心因性休克患者，IABP 未改善 30 天死亡率 → 現 IABP 在 AMI 心因性休克地位下降

VA-ECMO（靜脈-動脈體外膜氧合）

  • 原理：靜脈（股靜脈）→ 氧合器 → 動脈（股動脈）= 完全心肺替代
  • 適應症：難治性心因性休克；心臟停止（ECPR = ECMO-assisted CPR）；術後無法脫離 CPB；橋接至恢復 / VAD / 移植；大面積肺栓塞合併休克
  • ECMO 主要併發症：出血（抗凝 + 血小板消耗）；肢體缺血（遠端灌流管）；感染；血栓；North-South syndrome（Harlequin syndrome = 差異性缺氧）= 心臟和上半身由缺氧心臟輸出，下半身由 ECMO 供氧
  • 脫離 ECMO（Weaning）：心功能改善 → 逐漸降低流量 → Echo 確認心室功能 → 脫離

其他機械性循環輔助（MCS）

低心輸出量症候群（LCOS）

  • 定義：CI <2.0 L/min/m²；低血壓；心搏過速；少尿；四肢冰冷；代謝性酸中毒
  • 原因：心肌頓挫（Myocardial stunning）；不完全血管重建；心包填塞；心律不整；低血容
  • 處置：首先排除心包填塞（Echo）；優化前後負荷；強心劑（Dobutamine / Milrinone）；機械輔助（IABP / ECMO）

  • 危險因子控制：戒菸（最重要）；血壓 <130/80；高強度 Statin；血糖控制；Aspirin 75-100 mg/天
  • 血管重建：PTA（球囊擴張）+ Stent（腸骨動脈最佳）；繞道手術（股膕動脈繞道，大隱靜脈 > 人工血管）；解剖部位和病變長度決定術式

急性肢體缺血（ALI）6P + 頸動脈狹窄
急性肢體缺血 6P → <6 小時再灌流！超過 6 小時 → 不可逆肌肉壞死 → 截肢風險。

急性肢體缺血（Acute Limb Ischemia，ALI）6P

  • Pain（疼痛）：突發劇烈疼痛；靜息時持續
  • Pallor（蒼白）：肢體蒼白；皮膚變色
  • Pulselessness（無脈搏）：遠端脈搏消失
  • Paresthesia（感覺異常）：麻木、針刺感 → 神經缺血
  • Paralysis（麻痺）：運動功能喪失 → 最晚期、最嚴重徵象
  • Poikilothermia（皮溫下降）：肢體冰冷；與對側比較
原因特徵
血栓栓塞（Embolism，最常見）AF 心臟血栓；突發完全阻塞；對側脈搏正常；無 PAD 病史
原位血栓（Thrombosis）已有 PAD 基礎；症狀較緩；有跛行病史
  • 立刻：Heparin 5000 U IV bolus → 持續輸注（ACT/aPTT 監測）；緊急血管外科會診
  • 血管重建：栓塞 → 栓子切除術（Embolectomy，Fogarty catheter）；血栓 → 溶栓（tPA）或繞道手術
  • 再灌流症候群（Reperfusion injury）：高鉀血症；肌球蛋白尿（Myoglobinuria）→ 腎損傷；大量補液 + 鹼化尿液；筋膜切開術（預防筋膜室症候群）

頸動脈狹窄（Carotid Artery Stenosis）

  • 診斷：頸動脈超音波（篩查）；CTA / MRA（術前評估）；導管攝影（金標準）
  • 有症狀狹窄（TIA / 中風後）：狹窄 >50% → 建議 CEA 或 CAS；2 週內介入效益最大
  • 無症狀狹窄：狹窄 >70% + 預期存活 >5 年 + 手術風險低 → 考慮 CEA
  • CEA vs CAS：CEA（頸動脈內膜切除術）= 低手術風險患者首選；CAS（頸動脈支架）= 高手術風險 / 放射後 / 再狹窄 / 解剖不利
  • CEA 術後過度灌流症候群（Hyperperfusion syndrome）：頭痛 + 癲癇 + 神經缺損 → 嚴格血壓控制（SBP <140）
靜脈疾病 + 透析廔管 Venous Disease & Dialysis Access
靜脈疾病以DVT（深層靜脈血栓）最重要，需警惕肺栓塞（PE）風險；靜脈曲張影響台灣 25-30% 成人，以女性和長時間站立者為主。透析廔管（AV fistula）是血液透析患者的生命線，廔管的照護和急性問題處置是腎臟科 / 血管外科的重要交集。
用藥指引
DVT（深層靜脈血栓）+ 靜脈曲張

DVT 診斷 + 治療

  • Virchow's triad：血流停滯（Stasis）+ 血管壁損傷 + 高凝狀態 → DVT
  • Wells score：臨床預測機率；低機率 → D-dimer（陰性排除）；中高機率 → 下肢靜脈超音波（確診金標準）
  • 症狀：單側下肢腫脹 + 壓痛（小腿後方）+ 皮膚發紅發熱；Homan's sign（背屈疼痛）特異性低不建議使用
  • 抗凝治療：
    • 近端 DVT（膕靜脈以上）→ 系統性抗凝；DOAC（Rivaroxaban / Apixaban）= 首選；Warfarin（INR 2-3）+ LMWH 橋接
    • 療程：誘發性（手術/外傷後）→ 3 個月；非誘發性 → 3-6 個月；復發性 / 癌症相關 → 長期
    • 遠端 DVT（膕靜脈以下，小腿）→ 症狀輕微可觀察；症狀明顯或高 PE 風險 → 抗凝
  • 下腔靜脈濾網（IVC filter）：抗凝禁忌 + DVT / PE；復發性 PE 仍在抗凝中；盡量使用可回收型
  • 血栓後症候群（Post-thrombotic syndrome）：DVT 後靜脈瓣功能不全 → 慢性腿部水腫 / 色素沉著 / 潰瘍；壓力治療（彈性襪）預防

靜脈曲張（Varicose Veins）

  • CEAP 分類：C0（無）→ C6（活動性潰瘍）；C2 以上（靜脈曲張可見）是最常見處置對象
  • 危險因子：女性；懷孕；長時間站立；家族史；肥胖；DVT 後
  • 治療：
    • 保守：彈性襪（壓力 20-30 mmHg）；抬高患肢；體重控制
    • 硬化劑注射（Sclerotherapy）：小靜脈曲張；液態或泡沫硬化劑
    • 熱消融（Endovenous thermal ablation）：雷射（EVLA）/ 射頻（RFA）= 微創首選；大隱靜脈主幹
    • 手術（Stripping）：傳統高位結紮 + 抽除術；較少使用（被微創取代）

廔管評估（使用前每次確認）

  • 震顫（Thrill）：觸診廔管感受到連續震動 = 通暢；消失 → 懷疑阻塞
  • 雜音（Bruit）：聽診連續性雜音；消失或音調改變 → 狹窄 / 阻塞
  • 血流量：透析時流速 >500-600 mL/min 理想；不足 → 再循環（Recirculation）↑ → 透析效率↓
