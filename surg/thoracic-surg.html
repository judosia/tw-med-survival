胸腔評估基礎 Thoracic Assessment + Chest Tube
胸腔外科評估的核心：胸部 X 光判讀是最快速的篩查工具；CT 胸腔是評估肺部病灶和縱膈腔的金標準；胸管（Chest tube / Intercostal drain）是最常需要的操作技能之一——適應症包括氣胸、血胸、胸腔積液和膿胸。

管路位置確認（術後或 ICU）

  • 氣管內管（ETT）：管尖應在隆突（Carina）上方 2-3 cm；若太深 → 右主支氣管插管（右肺過度充氣，左肺塌陷）
  • 中心靜脈導管（CVP）：管尖位於上腔靜脈（SVC）和右心房交界；避免進入右心室（心律不整）
  • 胸管：管尖確認位置；氣胸 → 頂端；積液 → 底部；確認無扭折
  • 鼻胃管（NGT）：應在胃內（左上腹）；確認不在支氣管
判斷框架
胸管（Chest Tube）適應症 + 置放 + 移除

適應症

  • 氣胸：大型（>2 cm 肺緣）；張力性（立刻！）；雙側；機械通氣中；復發性
  • 血胸：幾乎所有外傷性血胸；單側血胸 >300 mL
  • 胸腔積液：大量（呼吸困難）；膿胸；惡性積液（引流）
  • 乳糜胸（Chylothorax）：乳白色積液（TG >110 mg/dL）
  • 術後引流：開胸 / 心臟手術後常規

置放技巧（Safe triangle）

  • 安全三角（Safe triangle）：前界 = 胸大肌外緣；後界 = 背闊肌前緣；下界 = 第五肋間（乳頭水平）；在此範圍置入避免損傷神經血管
  • 置入位置：第 4-6 肋間腋中線（液體）；第 2-3 肋間鎖骨中線（氣體，前氣胸）
  • 肋骨上緣進針：避免損傷走行於肋骨下緣的神經血管束（VAN = Vein, Artery, Nerve）
  • 胸管大小：氣胸 → 小管（14-20 Fr）或豬尾巴導管；血胸 → 大管（28-36 Fr）

胸管引流系統判讀

  • 水封瓶（Water seal）：正常 = 呼吸時水柱波動（Tidaling）；無波動 = 胸管扭折 or 肺已完全擴張；持續氣泡（Bubbling）= 氣漏（Air leak）
  • 移除條件：氣胸 → 無氣漏 + CXR 顯示肺完全擴張；積液 → 引流量 <100-200 mL/天；移除時讓患者深吸氣後閉氣（Valsalva）
  • 持續大量引流：>200 mL/小時 × 2-3 小時 = 持續性血胸 → 手術適應症（開胸探查）
氣胸 Pneumothorax
氣胸是空氣進入胸膜腔，導致肺塌陷。張力性氣胸（Tension pneumothorax）= 最危急的急症之一，氣體只進不出，縱膈腔移位 → 靜脈回流受阻 → 心輸出量驟降 → 死亡。立刻針刺減壓，不要等 X 光。原發性自發性氣胸多見於高瘦年輕男性（Blebs 破裂）。

復發預防（胸膜固定術 Pleurodesis）

  • 適應症：第二次同側自發性氣胸；第一次對側氣胸；職業高風險（潛水員、飛行員）
  • 方式：VATS + 機械磨擦（首選）；Talc 灌注（Talc pleurodesis）= 化學性；Tetracycline / Doxycycline（替代）
胸腔積液 Pleural Effusion（Light's Criteria + 膿胸）
胸腔積液最重要的第一步是用 Light's criteria 判斷滲出液 vs 漏出液，決定後續評估方向。漏出液多為全身性疾病（心衰竭、肝硬化）；滲出液需找局部原因（肺炎、腫瘤、結核）。膿胸是感染性積液，依分期選擇抗生素、引流或手術。

胸腔積液進一步分析

  • 葡萄糖 <60 mg/dL：膿胸；RA；惡性；食道穿孔（接近 0）；結核
  • pH <7.2：膿胸（需引流）；食道穿孔；惡性；結核
  • Amylase ↑：食道穿孔；胰腺炎（左側）；惡性
  • TG >110 mg/dL：乳糜胸（胸管或淋巴系統損傷）
  • 血性積液（Bloody）：Hct >50% 血液 = 血胸；<50% = 惡性 / PE / 外傷

膿胸（Empyema）分期 + 處置

  • Stage I（滲出期）：稀薄液體；pH >7.2；抗生素可能足夠
  • Stage II（纖維化膿期）：pH <7.2；糖 <60；LDH ↑；纖維分隔形成 → 胸管引流 + 抗生素；考慮 tPA/DNase 注射（溶解纖維蛋白）
  • Stage III（機化期）：厚纖維殼；肺困陷（Trapped lung）→ VATS 清創 or 開胸去皮質術（Decortication）
  • 抗生素：社區型 → Amoxicillin-clavulanate；院內型 → Pip/Tazo + Vancomycin
肺癌 + 縱膈腔腫瘤 Lung Cancer & Mediastinal Tumors
肺癌是台灣癌症死亡率第一名。非小細胞肺癌（NSCLC，85%）= 腺癌（最常見，台灣女性）+ 鱗狀細胞癌 + 大細胞癌；小細胞肺癌（SCLC，15%）= 診斷時幾乎已擴散，以化放療為主。縱膈腔腫瘤記憶口訣「4T」依前中後縱膈腔位置分類。

手術切除適應症（可切除性評估）

  • 腫瘤因素（可切除）：Stage I / II；選擇性 Stage IIIA；無縱膈腔廣泛侵犯；無遠端轉移
  • 肺功能評估：FEV1 >1.5 L（肺葉切除）；FEV1 >2.0 L（全肺切除）；術前預測術後 FEV1 >800 mL 或 >40% 預測值
  • 不可切除：Stage IIIB-IV；惡性胸腔積液；對側縱膈腔淋巴腺（N3）；心臟大血管侵犯；氣管隆突侵犯（特殊情況可考慮）

上腔靜脈症候群（SVC Syndrome）

  • 原因：肺癌（最常見）/ 淋巴瘤 / 中心靜脈導管血栓壓迫 SVC
  • 臨床：臉部 / 頸部 / 上肢水腫；頸靜脈怒張；頭痛；側支循環（胸壁靜脈擴張）；症狀臥位加重
  • 處置：頭抬高；利尿劑（輕度）；放療（淋巴瘤 / 肺癌）；血管支架（血栓性）；類固醇（淋巴瘤）
食道疾病 Esophageal Diseases
Boerhaave syndrome（自發性食道穿孔）= 嘔吐後突發胸痛 + 縱膈腔炎，死亡率極高，需緊急手術。食道癌在台灣以鱗狀細胞癌為主（95%，與飲酒、吸菸、嚼檳榔相關），預後差（5 年存活率 <20%）。食道異物（魚刺、假牙）是急診常見問題。
緊急處置
食道穿孔 + Boerhaave Syndrome
Boerhaave syndrome = 外科急症！24 小時內手術死亡率 25%；延遲 >24 小時死亡率 >50%。

食道穿孔原因

  • 醫源性（最常見，75%）：上消化道內視鏡（EGD）；食道擴張術；插胃管創傷；最常見於食道咽喉交界和 Killian's dehiscence
  • Boerhaave syndrome（自發性）：劇烈嘔吐 → 食道內壓力驟升 → 下段食道後外側壁撕裂；最常見於大量飲食後嘔吐的男性（40-60 歲）
  • 外傷性：穿刺傷；鈍傷（罕見）
  • 腫瘤侵蝕：食道癌 / 肺癌

Boerhaave Syndrome 三聯症（Mackler's triad）

  • 劇烈嘔吐後 → 胸痛（撕裂感，左側多）→ 皮下氣腫（頸部、胸壁捻髮音）
  • CXR：縱膈腔積氣（Pneumomediastinum）；左側胸腔積液；皮下氣腫
  • Hamman's sign：聽診心臟時聽到與心跳同步的捻髮音（縱膈腔積氣）
  • 診斷：水溶性顯影劑食道攝影（Gastrografin swallow）= 首選；CT 胸腔（最敏感）；禁用鋇劑（縱膈腔炎症加重）

處置

  • 立刻禁食（NPO）+ 廣效抗生素（Pip/Tazo + Fluconazole）+ 大量補液
  • 早期（<24 小時，汙染少）：開胸 + 直接縫合修補 + 引流
  • 晚期（>24 小時，廣泛汙染）：食道切除 + 頸部造口 + 胃造口（分期重建）；或內視鏡支架（Esophageal stent，選擇性患者）
  • 醫源性小穿孔（早期發現、無縱膈腔炎）：禁食 + 抗生素 ± 內視鏡夾閉

臨床 + 診斷

  • 症狀：進行性吞嚥困難（先固體後液體）；體重下降；嘔吐（食道阻塞後逆流）；聲音嘶啞（喉返神經侵犯）；Horner syndrome（交感神經侵犯）
  • 診斷：上消化道內視鏡 + 切片（確診）；CT 胸腹（分期）；PET-CT（遠端轉移）；超音波內視鏡（EUS，T / N 分期）

治療

  • 早期（T1-T2N0）：食道切除術（Esophagectomy）= 根治性；Ivor Lewis / McKeown / transhiatal 術式
  • 局部進展（T3-T4 或 N+）：術前新輔助同步化放療（Chemoradiation）→ 再評估手術
  • 不可切除 / 轉移：同步化放療（根治目的）；姑息性化療；食道支架（緩解吞嚥困難）
  • 預後極差：診斷時 50% 已有轉移；整體 5 年存活率 <20%；早期診斷至關重要

胸腔創傷六大立即致命傷（ATOM FC）：Airway obstruction；Tension pneumothorax；Open pneumothorax；Massive hemothorax；Flail chest；Cardiac tamponade。這六種傷害必須在初次評估中立刻識別和處置。
緊急處置
血胸 + 心包填塞（Cardiac Tamponade）

血胸（Hemothorax）

  • 原因：外傷（最常見）；主動脈剝離；腫瘤；抗凝血藥物
  • 大量血胸（Massive hemothorax）：胸腔積血 >1500 mL（或 >1/3 血容量）；低血壓 + 患側呼吸音↓ + 叩診濁音（鑑別張力性氣胸）；頸靜脈可能因血容量下降而無怒張
  • 處置：大管胸管（28-36 Fr）引流 + 大量補液 / 輸血（同時）；手術適應症（開胸）：初始引流 >1500 mL；持續出血 >200 mL/h × 2-4 h；血流動力學不穩定；凝血性血胸（clotted hemothorax）
  • 凝血性血胸（Retained hemothorax）：胸管引流不完全 → 血塊機化 → 纖維胸（Fibrothorax）→ VATS 清除（2 週內）

心包填塞（Cardiac Tamponade）

Beck's triad = 低血壓 + JVD + 心音遙遠（Muffled heart sounds）→ 心包穿刺或開胸！
  • 原因：外傷（穿刺傷）；惡性腫瘤；尿毒症；心包炎後；主動脈剝離；醫源性（介入手術）
  • 病生理：心包內液體增加 → 心腔受壓 → 舒張期充盈↓ → 心輸出量↓ → 休克；少量液體（100-200 mL）若快速積聚即可造成填塞
  • Pulsus paradoxus：吸氣時 SBP 下降 >10 mmHg（正常 <10 mmHg）= 靈敏度高但不特異
  • ECG：電交替（Electrical alternans）= QRS 方向交替變化；心動過速；低電壓
  • 超音波：右心室舒張期塌陷（RA / RV diastolic collapse）= 最特異性；「搖擺心臟（Swinging heart）」
  • 處置：
    • 補液（暫時維持前負荷）；避免利尿劑（加重）
    • 心包穿刺術（Pericardiocentesis）：劍突下進針；超音波引導；緊急時可盲刺；引流 50 mL 即可顯著改善
    • 外傷性填塞（刀傷）→ 開胸探查（心包穿刺風險高）
    • 復發 / 惡性 → 心包窗手術（Pericardial window）
緊急處置
連枷胸 + 開放性氣胸 + 胸腔創傷

連枷胸（Flail Chest）

  • 定義：≥3 根相鄰肋骨，每根有 ≥2 處骨折 → 胸壁喪失完整性 → 矛盾性呼吸（吸氣時患側陷入，呼氣時膨出）
  • 危險：本身不是主要威脅，但幾乎必定合併肺挫傷（Pulmonary contusion）→ 肺內出血 / 水腫 → 低血氧 → ARDS
  • 處置：充分鎮痛（Epidural 或 PCA = 首選，改善呼吸力學）；機械通氣（嚴重低血氧）；手術固定（Open reduction，選擇性）；積極肺復原

開放性氣胸（Open Pneumothorax，「吸吮胸傷」）

  • 機轉：胸壁缺損 >2/3 氣管直徑 → 空氣優先從傷口進出 → 肺塌陷
  • 立刻處置：三面貼紮（Three-sided occlusive dressing）= 覆蓋傷口但留一邊開口（呼氣時排氣，防止張力性氣胸）→ 立刻胸管引流（另選位置）→ 手術修補

胸腔創傷 ATOM FC 立即致命傷速查

致命傷立刻處置
A — Airway obstruction清除異物；插管；環甲膜切開
T — Tension pneumothorax立刻針刺減壓 → 胸管
O — Open pneumothorax三面貼紮 → 胸管
M — Massive hemothorax大管胸管 + 輸血；失敗 → 開胸
F — Flail chest充分鎮痛；機械通氣（嚴重）
C — Cardiac tamponade心包穿刺 or 開胸（外傷性）
