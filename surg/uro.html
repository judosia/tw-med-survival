泌尿科評估基礎 Urological Assessment
泌尿科評估的核心工具：尿液分析（UA）是最快速的篩查工具；尿液培養是 UTI 確診的金標準；泌尿道超音波無輻射首選用於腎水腫和結石篩查；CT（非增強）是泌尿道結石診斷的金標準。常見泌尿症狀：血尿、排尿困難（Dysuria）、尿頻、尿急、排尿不完全感（LUTS）。

血尿（Hematuria）評估

  • 肉眼可見血尿（Gross hematuria）：尿液明顯血色；需評估上 / 下泌尿道；>35 歲 + 肉眼血尿 → 膀胱鏡排除膀胱癌
  • 顯微血尿（Microscopic hematuria）：≥3 RBC/hpf；需排除良性原因（月經、激烈運動）；持續性 → 泌尿系統評估
  • 初段血尿（Initial）：排尿開始有血 → 尿道病灶
  • 末段血尿（Terminal）：排尿末端有血 → 膀胱頸 / 攝護腺
  • 全程血尿（Total）：整段尿液有血 → 腎臟 / 輸尿管 / 膀胱

常用泌尿科指標

  • PSA（攝護腺特異抗原）：正常 <4 ng/mL；4-10 = 灰色地帶；>10 → 攝護腺癌高風險；良性 BPH 也可升高；PSA 速度（Velocity）和密度（Density）輔助判讀
  • 殘尿量（Post-void residual，PVR）：排尿後超音波測量；正常 <50 mL；>300 mL = 顯著尿滯留
  • IPSS 評分：International Prostate Symptom Score；評估 LUTS 嚴重度（0-35 分）；≤7 輕度；8-19 中度；20-35 重度
  • 尿流速測定（Uroflowmetry）：最大尿流速（Qmax）；正常 >15 mL/秒；<10 mL/秒 = 阻塞性
泌尿道感染 Urinary Tract Infection
UTI 是最常見的細菌感染之一，大腸桿菌（E. coli）佔 80-85%。單純性（Uncomplicated）UTI = 正常解剖、無功能異常、非懷孕女性；複雜性（Complicated）UTI = 男性、懷孕、糖尿病、解剖異常、免疫缺陷、院內感染、留置導尿管。腎盂腎炎（Pyelonephritis）是上泌尿道感染，需要更長療程和可能住院治療。

住院指標（腎盂腎炎）

  • 無法口服（嘔吐）；敗血症；孕婦；免疫缺陷；門診治療 48-72 小時無改善；梗阻性腎盂腎炎（需緊急引流）
  • 梗阻性腎盂腎炎 = 結石 + 腎盂腎炎 = 泌尿科急症！需緊急引流（輸尿管支架或腎造瘻術）+ 靜脈抗生素，否則可能敗血症休克

泌尿道結石 Urolithiasis
泌尿道結石（腎結石）影響 10% 人口，男性多於女性，草酸鈣（Calcium oxalate）最常見（80%）。典型腎絞痛（Renal colic）= 突發劇烈側腹/腰部疼痛，沿輸尿管路徑放射至鼠蹊 / 睪丸 / 大陰唇。非增強 CT（Non-contrast CT KUB）是診斷金標準。

種類比例X 光特殊危險因素 / 特徵

急性腎絞痛處置

  • 疼痛控制：NSAIDs（Ketorolac 15-30 mg IV，首選）= ↓ 輸尿管痙攣 + 鎮痛；Opioid（Morphine 2-4 mg IV）若 NSAIDs 禁忌；避免過度補液（不加速排石）
  • Alpha-blocker（Tamsulosin 0.4 mg/天）：Medical expulsive therapy（MET）；輸尿管遠端結石 ≤10 mm；↑ 自然排石率；目前 EAU 指引支持
  • 嘔吐 / 無法口服：止吐藥（Ondansetron）；靜脈補液（避免脫水）

手術適應症 + 方式

  • 緊急泌尿科介入：梗阻性結石 + 感染（膿尿/發燒）= 急症！→ 輸尿管支架（Double-J stent）or 腎造瘻管引流 + 靜脈抗生素；等感染控制後再處理結石
  • 擇期手術適應症：結石 >10 mm（自然排出率低）；持續疼痛；腎功能受損；單腎或功能腎梗阻；4-6 週觀察無進展
  • ESWL（體外衝擊波碎石）：腎結石 ≤20 mm；輸尿管近端結石；非侵入性；禁忌：懷孕、凝血異常、主動脈瘤
  • URS（輸尿管鏡碎石）：輸尿管結石首選；鈥雷射碎石；腎結石（軟性輸尿管鏡）
  • PCNL（經皮腎臟碎石術）：腎結石 >20 mm；鹿角石；ESWL 失敗
機轉說明
結石預防 + 代謝評估
  • 飲水量：目標尿液輸出 >2-2.5 L/天；充足飲水是最重要的預防措施
  • 草酸鈣結石：↓ 草酸（菠菜、堅果、巧克力）；正常鈣攝取（不要低鈣飲食！）；Thiazide 利尿劑（↓ 尿鈣）；Potassium citrate（鹼化尿液）
  • 尿酸結石：低嘌呤飲食；Allopurinol；Potassium citrate（鹼化尿液 pH >6.5）；Sodium bicarbonate
  • 鳥糞石：治療根本感染；手術完全清除結石；Acetohydroxamic acid（尿素酶抑制劑）
  • 代謝評估（復發性結石患者）：24 小時尿液（鈣、草酸、尿酸、檸檬酸、磷、肌酸酐）；血液（鈣、PTH、尿酸）
BPH + 急性尿滯留 Benign Prostatic Hyperplasia & Acute Urinary Retention
BPH 影響 50% 的 50 歲男性和 90% 的 85 歲男性，是最常見的泌尿外科疾病。LUTS（下泌尿道症狀）= 儲尿症狀（頻尿、夜尿、尿急、急迫性尿失禁）+ 排尿症狀（尿流細弱、需要用力、間歇性排尿、排尿不完全）。急性尿滯留（AUR）是最常見的泌尿科急症之一。

緊急處置
急性尿滯留（Acute Urinary Retention，AUR）
急性尿滯留 → 立刻導尿！不要因等候評估而讓患者繼續痛苦。

診斷 + 處置

  • 臨床：無法排尿 + 恥骨上脹痛 + 膀胱可叩診；超音波確認膀胱容量（>300 mL 有意義；>600 mL 嚴重）
  • 立刻導尿：Foley catheter（14-16 Fr）經尿道；若尿道阻力高 → 較小號（12 Fr）或使用彎頭導管（Coudé catheter）；若仍失敗 → 恥骨上導管（Suprapubic catheter，SPC）
  • 放尿注意：一次放出超過 1 L 後可先夾管（避免血尿 / 低血壓），現多數指引允許完全排空
  • TWOC（Trial Without Catheter，拔管試驗）：48-72 小時後嘗試拔管；同時口服 Tamsulosin（↑ TWOC 成功率）；TWOC 成功率約 50-70%（取決於誘發因素）

AUR 誘發因素（記憶口訣：MITO）

  • M — Medications：抗膽鹼藥（抗組織胺 / 抗憂鬱）；Opioid；Alpha-agonist（鼻塞藥）；Ca channel blocker
  • I — Infection / Inflammation：攝護腺炎；UTI；術後
  • T — Trauma / Surgery：腹部 / 骨盆手術；脊椎麻醉後；會陰外傷
  • O — Obstruction：BPH（最常見）；尿道狹窄；結石；腫瘤；糞便嵌塞
  • 慢性尿滯留（Chronic urinary retention，CUR）= 大量殘尿（通常 >300 mL）但無急性症狀；overflow incontinence（滿溢性尿失禁）是常見表現；長期可造成腎水腫和腎功能損傷
泌尿系統腫瘤 Urological Cancers
泌尿系統三大癌症：攝護腺癌（台灣男性第五大癌症死因，PSA 篩查）；膀胱癌（無痛性肉眼血尿 = 直到排除為止是膀胱癌）；腎細胞癌（RCC）（沉默的腫瘤，多數偶然發現）。另有睪丸腫瘤（年輕男性最常見的實心腫瘤）。
判斷框架
攝護腺癌 + 膀胱癌

攝護腺癌（Prostate Cancer）

  • 篩查：PSA + 直腸指診（DRE）；PSA >4 ng/mL 或 DRE 異常 → 經直腸超音波引導切片（TRUS biopsy）；12 核心切片 + 可疑區域
  • Gleason Score：5（最惡性）+ 5（最惡性）= 10（最高）；≥7（4+3）= 中高風險；Grade Group 1-5 是新分類
  • 分期治療：
    • 局部（T1-T2）：積極監測（低風險）；根治性前列腺切除術（Radical prostatectomy）；放射治療（外照射 / 近接放療）
    • 局部進展（T3-T4）：放療 + 雄性激素剝奪療法（ADT）
    • 轉移性（M1）：ADT（Leuprolide / Bicalutamide）；去勢抵抗性前列腺癌（CRPC）→ Enzalutamide / Abiraterone / Docetaxel
  • 骨轉移（最常見轉移部位）= 成骨性（Osteoblastic）病灶 → 骨掃描（Bone scan）；PSA 無法用來監測 CRPC 療效

膀胱癌（Bladder Cancer）

  • 危險因素：吸菸（最大危險因素，↑ 風險 2-6 倍）；職業暴露（苯胺染料、橡膠）；Cyclophosphamide；慢性膀胱炎（Schistosomiasis → 鱗狀細胞癌）
  • 表現：無痛性肉眼血尿（最常見）；刺激性 LUTS（尿急、頻尿，原位癌 CIS 特徵）
  • 組織學：移行上皮癌（TCC / Urothelial carcinoma）95%；鱗狀細胞癌（慢性刺激）；腺癌
  • 分期 + 治療：
    • Non-muscle invasive（Ta, T1, CIS）：TURBT（經尿道膀胱腫瘤切除）+ 膀胱內灌注（BCG or Mitomycin C）；定期膀胱鏡追蹤
    • Muscle invasive（T2-T4）：根治性全膀胱切除術（Radical cystectomy）± 新輔助化療（Cisplatin-based）；尿液改道（Ileal conduit / Neobladder）
    • 轉移性：Gem/Cis 化療；Pembrolizumab（PD-1）/ Atezolizumab（PD-L1）
判斷框架
腎細胞癌（RCC）+ 睪丸腫瘤

腎細胞癌（Renal Cell Carcinoma）

  • 危險因素：吸菸；肥胖；高血壓；von Hippel-Lindau（VHL）病（雙側多發）；長期透析患者
  • 臨床三聯症（只有 10% 出現）：側腹痛 + 血尿 + 可觸及的腹部腫塊 → 晚期
  • 副腫瘤症候群：高鈣血症（PTHrP）；紅血球增多症（Erythropoietin）；高血壓（Renin）；Stauffer syndrome（肝功能異常，無肝轉移）
  • 組織學：Clear cell（75%，VHL 突變）；Papillary（15%）；Chromophobe（5%）
  • 影像：CT 增強 = 評估血管侵犯和淋巴腺；腎靜脈 / 下腔靜脈瘤栓（Tumor thrombus）評估
  • 治療：局部 → 根治性 or 部分腎切除術；轉移性 → TKI（Sunitinib / Pazopanib）；免疫治療（Nivolumab + Ipilimumab）；mTOR 抑制劑（Everolimus）；RCC 對化療和放療均不敏感

睪丸腫瘤（Testicular Cancer）

  • 最常見的 15-35 歲男性實心腫瘤；95% 為生殖細胞瘤（GCT）
  • 危險因素：隱睪症（Cryptorchidism，最重要）；Klinefelter syndrome；家族史
  • 分類：精原細胞瘤（Seminoma，50%）= 對放療和化療敏感；預後好；非精原細胞瘤（NSGCT）= Embryonal carcinoma / Yolk sac / Choriocarcinoma / Teratoma；hCG 和 AFP 升高（Seminoma 只有 hCG 輕度升高）
  • 臨床：無痛性睪丸腫塊（最典型）；超音波確認；CT 分期
  • 治療：根治性睪丸切除術（經腹股溝）+ 依分期：放療 / 化療（BEP = Bleomycin + Etoposide + Cisplatin）/ 腹膜後淋巴清除；不要做穿刺活檢（播種風險）
泌尿科急症 Urological Emergencies
泌尿科最危急的急症：睪丸扭轉（Testicular torsion）= 6 小時內手術救回率 90-100%，超過 24 小時幾乎喪失；Fournier's Gangrene= 生殖器 / 會陰壞死性筋膜炎，死亡率 20-40%；陰莖骨折（Penile fracture）= 立刻手術修補。
緊急處置
睪丸扭轉（Testicular Torsion）
睪丸扭轉懷疑 → 立刻叫泌尿科！不要等超音波結果。臨床懷疑即手術探查。
  • 好發：12-18 歲青少年（最高峰）；新生兒；Bell-clapper deformity（睪丸固定異常）
  • 臨床：突發劇烈單側陰囊疼痛；噁心嘔吐；睪丸抬高（High-riding testis）；水平位（橫位）；Cremasteric reflex 消失（最重要）；Prehn's sign 陰性（托高睪丸疼痛無緩解）
  • 救治時間窗：
    • <6 小時 → 存活率 90-100%
    • 6-12 小時 → 約 50%
    • 12-24 小時 → 約 10%
    • >24 小時 → 幾乎 0%
  • 處置：立刻手術探查（不要等超音波耽誤時間）；手法復位（Manual detorsion，「開書」方向，由內向外旋轉）可嘗試暫時緩解但仍需手術；雙側固定（Orchiopexy）預防復發；壞死睪丸 → 睪丸切除
  • 鑑別：副睪丸炎（Epididymitis）= 漸進性疼痛 + 發燒 + 膿尿 + Cremaster reflex 存在 + Prehn sign 陽性（托高緩解）；但無法確定時優先排除扭轉
緊急處置
Fournier's Gangrene + 陰莖骨折 + 異物

Fournier's Gangrene（陰囊 / 會陰壞死性筋膜炎）

  • 危險因素：糖尿病（最重要）；免疫缺陷；酗酒；肥胖；局部外傷 / 感染（肛周膿瘍、尿道損傷）
  • 臨床：陰囊 / 會陰紅腫熱痛 → 皮膚壞死（黑色）/ 捻髮音（Crepitus）→ 全身毒性；進展極快（數小時內可蔓延）
  • 處置：立刻廣泛清創（不能等待）+ 靜脈廣效抗生素（Pip/Tazo + Vancomycin + Metronidazole）；高壓氧（輔助）；造口（保護傷口）；重建（傷口癒合後）；死亡率 20-40%
  • FGSI 評分（Fournier's Gangrene Severity Index）：預測死亡率（體溫、心率、血壓、呼吸速率、鈉、鉀、肌酸酐、WBC、Hct）

陰莖骨折（Penile Fracture）

  • 勃起時白膜（Tunica albuginea）破裂；性交時最常見；聽到「啪」聲 + 陰莖立即軟化 + 血腫（茄子陰莖，Eggplant deformity）；可能合併尿道損傷（血尿）
  • 立刻手術修補（不要保守治療，否則勃起功能障礙和畸形）

持續性陰莖勃起（Priapism）

  • 缺血性（Low-flow，最常見，急症）：疼痛；陰莖缺血；原因：鐮刀型貧血、藥物（PDE5i、抗精神病藥）；海綿體血氣分析（低氧酸中毒）
  • 處置：冰敷 + 運動（輕度）；海綿體抽血（減壓）→ 注射 Phenylephrine（Alpha-agonist，血管收縮）；持續 >4 小時 → 急症；>24 小時 → 勃起功能障礙風險極高
  • 非缺血性（High-flow）：無痛；外傷後動靜脈瘻管；海綿體血氣分析正常 → 動脈栓塞治療
