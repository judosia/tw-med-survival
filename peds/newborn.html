新生兒評估 + APGAR + NRP Neonatal Assessment & Resuscitation
新生兒出生後的最初幾分鐘決定後續的神經發育預後。NRP（Neonatal Resuscitation Program）2020 更新重點：延遲臍帶結紮（DCC）≥30-60 秒；初始復甦用室內空氣（21% O₂）；心率是最重要的復甦反應指標。APGAR 評分是標準化記錄，但不用來決定是否需要復甦——復甦應在評分完成前就開始。依 Nelson 22nd（Ch.123）。

NRP 2020 流程（依 Nelson 22nd Ch.123）
心率是復甦反應的最重要指標——最重要的介入是有效通氣。

初始評估（出生後立刻）

  • 三個問題：足月？肌張力正常？哭泣 or 呼吸？
  • 三個都是 → 延遲臍帶結紮（DCC ≥30-60 秒）→ 皮膚接觸 → 常規護理
  • 任何一個否 → 送到輻射保溫台 → 保暖 + 擺位 + 清潔氣道 + 刺激

Step 1（0-30 秒）：初始步驟

  • 保暖（輻射保溫台）；擺位（輕微伸展頸部）；清潔氣道（吸引分泌物）；刺激（擦乾 + 拍打腳底）
  • 評估：呼吸 + 心率 + SpO₂（右手）

Step 2（30-60 秒）：若心率 <100 或呼吸暫停

  • 正壓通氣（PPV）：面罩 + 氣球；PIP ~20 cmH₂O；PEEP 5 cmH₂O；速率 40-60 次/分
  • 初始 FiO₂：足月 = 21%（室內空氣）；早產 <35 週 = 21-30%；依 SpO₂ 調整
  • 目標 SpO₂（生後分鐘）：1 分 60-65%；3 分 70-75%；5 分 80-85%；10 分 85-95%
  • 有效 PPV 指標 = 心率↑（最重要）+ 胸廓起伏 + SpO₂ 上升

Step 3（60 秒後）：若 PPV 後心率 <60 bpm

  • 插管（確保有效通氣）→ 胸外心臟按壓（3:1 比例，90 次壓 + 30 次通氣 / 分）
  • FiO₂ → 100%（胸外按壓期間）
  • Epinephrine：0.01-0.03 mg/kg IV（臍靜脈導管）或 0.05-0.1 mg/kg ETT（若無靜脈）
  • 找可逆原因：氣胸？低血容？先天性心臟病（PGE₁）？

MRSOPA（PPV 無效時的矯正步驟）

  • M：Mask adjustment（面罩密合度）
  • R：Reposition airway（頭部姿勢）
  • S：Suction（清潔口鼻）
  • O：Open mouth（張嘴）
  • P：Pressure increase（增加 PIP）
  • A：Airway alternative（考慮 LMA 或插管）

新生兒黃疸 Neonatal Jaundice / Hyperbilirubinemia
新生兒黃疸影響 60%（足月）至 80%（早產）的新生兒，大多數是生理性且良性的。需要立即處置的警訊：24 小時內出現黃疸（病理性）；快速上升（>0.5 mg/dL/h）；需要換血輸血的嚴重高膽紅素血症（核黃疸風險）。依 Nelson 22nd（Ch.137）+ AAP 2022 指引。

24 小時內黃疸的鑑別

  • 溶血性疾病（ABO 或 Rh 不相容）= 最常見
  • G6PD 缺乏症（台灣男性盛行率約 3%）
  • 先天性感染（TORCH）；敗血症
  • 內出血（頭血腫、皮下出血）

黃疸高風險因素（AAP 2022）

  • 溶血性疾病（isoimmune、G6PD、球形紅血球症）
  • 敗血症；低白蛋白（<3.0 g/dL）
  • 胎齡 35-36 週；前 24 小時快速上升
  • 前一胎有換血輸血史
  • 早產兒（胎齡越小）：膽紅素腦損傷閾值越低——早產兒的光照治療閾值比足月兒低
用藥指引
光照治療 + 換血輸血（依 AAP 2022 + Nelson 22nd）

光照治療閾值（足月 ≥38 週，無高危因素）

  • 生後 24 小時：TSB ≥12 mg/dL → 光照
  • 生後 48 小時：TSB ≥15 mg/dL → 光照
  • 生後 72 小時：TSB ≥18 mg/dL → 光照
  • 有高危因素（溶血、G6PD、<38 週）→ 閾值降低 2-3 mg/dL

光照治療（Phototherapy）

  • 機轉：藍綠光（波長 460-490 nm）使不溶性膽紅素 → 水溶性異構體 → 尿液 / 膽汁排出
  • 強化光照（Intensive phototherapy）：多組光源；暴露最大皮膚面積；眼罩保護（視網膜損傷）；遮蓋生殖器
  • 監測：每 4-6 小時測 TSB；持續水分補充（光照↑ 不顯性水分喪失）
  • 停止光照條件：TSB 低於光照閾值 2 mg/dL 以下；停後 24 小時追蹤（反彈）

換血輸血（Exchange Transfusion）

  • 適應症：TSB 超過換血閾值（依胎齡 + 高危因素）；急性膽紅素腦病（Acute Bilirubin Encephalopathy）
  • 急性膽紅素腦病三期：早期（嗜睡、肌張力低、哭聲高亢）→ 中期（後弓反張、高音調哭聲、發燒）→ 晚期（神經損傷永久，核黃疸）
  • 雙倍血量換血（2 × 80 mL/kg = 160 mL/kg）；全血 or pRBC + FFP；通過臍靜脈導管
  • 母乳性黃疸（Breast Milk Jaundice）：生後 1-3 週持續輕度非結合性膽紅素↑；母乳成分抑制膽紅素代謝；通常不需停母乳；若 TSB >20 mg/dL 才考慮暫停 24-48 小時

新生兒敗血症 Neonatal Sepsis
新生兒敗血症的臨床表現非常非特異性——「新生兒看起來不太對」= 需要排除敗血症。依發病時間分為早發性（EOS，<72 小時）和晚發性（LOS，≥72 小時），兩者病原不同，抗生素選擇不同。依 Nelson 22nd（Ch.148）。

評估步驟

  • 血液培養（×2 sets）：在抗生素前，從不同部位抽取；血量 ≥1 mL（新生兒）
  • 尿液培養（無菌導尿）：LOS 必做；EOS 若臨床懷疑也做
  • 腰椎穿刺：EOS 有症狀；LOS 所有懷疑敗血症；血培養陽性前先做（抗生素會使 CSF 培養快速轉陰）
  • CBC + CRP + Procalcitonin：輔助，不能確診或排除；WBC <5000 or >30000 = 異常；Procalcitonin 是較敏感的感染標誌物
  • 胸部 X 光：有呼吸症狀時；排除 RDS、氣胸

GBS 預防（產前）

  • 妊娠 35-37 週 GBS 陰道 / 直腸培養篩查
  • GBS ⊕ 或上次分娩有 GBS 新生兒敗血症史 → 分娩時 Penicillin G IV（或 Ampicillin）
  • Penicillin 過敏 + 低過敏風險 → Cefazolin；高過敏風險 → Clindamycin（若 GBS 敏感）or Vancomycin
新生兒呼吸窘迫 Neonatal Respiratory Distress
新生兒呼吸窘迫的鑑別最重要的是依胎齡和發病時間：早產兒早期 → RDS（界面活性劑缺乏）；足月兒剖腹產 → TTN（暫時性呼吸急促）；過期產 + 胎便羊水 → MAS（胎便吸入症候群）。Silverman-Anderson 評分是評估嚴重度的工具。依 Nelson 22nd（Ch.126）。

Surfactant 替代治療（依 Nelson 22nd Ch.126）

  • 適應症：<30 週預防性；任何胎齡 FiO₂ >0.3 + CPAP 失敗 → 治療性
  • 種類：天然（Calfactant / Beractant / Poractant alfa）優於人工合成
  • 劑量：Poractant alfa（Curosurf）100-200 mg/kg 氣管內
  • INSURE 法：Intubate → Surfactant → Extubate（給完立刻拔管接 CPAP）↓ 需要機械通氣時間
  • CPAP（持續氣道正壓）是 RDS 輕中度的首選通氣支持；PEEP 4-6 cmH₂O 防止肺泡塌陷

緊急處置
新生兒持續性肺動脈高壓（PPHN）
  • 定義：出生後肺血管阻力（PVR）持續升高 → 右向左分流（通過 PFO / PDA）→ 嚴重低氧
  • 病因：MAS；肺炎；RDS；先天性膈疝（CDH）；窒息；敗血症
  • 診斷線索：導管前（右手）SpO₂ - 導管後（左手 / 腳）SpO₂ 差異 >5-10%（右向左分流徵象）；高濃度 O₂ 反應差；心臟超音波確診
  • 治療：高濃度氧氣（肺血管擴張）；吸入性一氧化氮（iNO，20 ppm）= 選擇性肺血管擴張；機械通氣；Sildenafil（PDE-5 抑制劑）；ECMO（極重度 / iNO 無效）
  • 先天性膈疝（CDH）= 橫膈缺損 → 腸管進入胸腔 → 肺發育不全 + PPHN；出生後立刻插管；避免面罩 PPV（脹氣惡化）
新生兒代謝問題 Neonatal Metabolic Issues
新生兒低血糖是最常見的代謝問題，高危族群包括 LGA（母親 DM）、SGA（IUGR）、早產兒。低血糖的臨床表現非特異性，可能與敗血症、呼吸問題類似——所有病態新生兒均需排除低血糖。依 Nelson 22nd（Ch.113、121）。
緊急處置
新生兒低血糖（依 Nelson 22nd Ch.113）

定義 + 高危族群

  • 定義：血糖 <40-45 mg/dL（生後 24 小時）；<50 mg/dL（>24 小時）
  • 高危族群：
    • LGA（母親 DM → 高胰島素血症）
    • SGA / IUGR（肝醣儲存不足）
    • 早產兒（糖質新生和脂肪分解能力低）
    • 窒息 / 低體溫（↑ 葡萄糖消耗）
    • 先天性高胰島素血症（Nesidioblastosis）

臨床表現

  • 抖動（Jitteriness）；煩躁；嗜睡；餵食差；哭聲異常（高亢）；低體溫；呼吸暫停；發紺；癲癇
  • 無症狀低血糖也可能造成神經損傷（尤其持續低血糖）

治療

  • 無症狀 / 輕度（>25 mg/dL）：立刻餵食（母乳 or 配方奶）；30 分後重測血糖
  • 無法口服 / 有症狀：D10W（10% 葡萄糖水）2 mL/kg IV bolus → 維持 GIR（葡萄糖輸注速率）4-8 mg/kg/分
  • 難治性低血糖：GIR >12 mg/kg/分仍無法維持 → 考慮 Glucagon 0.1 mg/kg IM（短效）；皮質醇（先天性腎上腺增生）；Diazoxide / Octreotide（高胰島素血症）
  • 目標血糖：≥50 mg/dL（無症狀）；≥60 mg/dL（有症狀）；穩定後漸減 IV 葡萄糖
用藥指引
新生兒低鈣血症 + 電解質問題

低鈣血症（Hypocalcemia）

  • 定義：總鈣 <7 mg/dL（早產 <6 mg/dL）；或游離鈣 <1.0 mmol/L
  • 早發型（<72 小時）：早產兒；母親 DM；窒息；DiGeorge 症候群（PTH 缺乏）
  • 晚發型（>7 天）：高磷配方奶（牛奶 / 未稀釋）→↑ 磷 → ↓ 鈣；維生素 D 缺乏
  • 臨床：抖動；高音調哭聲；癲癇；Chvostek 徵（叩擊顏面神經 → 臉部抽搐）；QTc 延長
  • 急性治療：10% Calcium Gluconate 1-2 mL/kg IV 緩慢推注（>10 分）；監測 ECG（心搏過緩）；不可 IM（組織壞死）
  • 維持：口服 Calcium gluconate；維生素 D 補充

新生兒體溫調節

  • 正常體溫：36.5-37.5°C（腋溫）
  • 低體溫：<36.5°C；早產兒和 SGA 最高風險（體表面積 / 體重比高）
  • 預防：立刻擦乾 + 保暖毯；輻射保溫台；塑膠袋包裹（極早產）；延遲洗澡（>24 小時）
  • 低體溫後果：↑ 耗氧量；↑ 低血糖；↑ 代謝性酸中毒；↑ 死亡率

出生後常規處置

  • 維生素 K₁ 1 mg IM（出生後立刻）：預防新生兒出血症（VKDB）；應拒絕者需簽切結書並衛教
  • 眼藥水（眼結膜炎預防）：Erythromycin 眼藥膏（淋病性眼炎預防）；台灣常規給予
  • 聽力篩查：出院前 AABR 或 OAE；雙側未通過 → 轉介 ABR 確診
  • 先天性心臟病（CCHD）篩查：出生後 24 小時以上 Pulse oximetry 篩查（右手 + 一隻腳）；任一 <95% 或差異 >3% → 心臟超音波

新生兒餵食

  • 母乳：首選；按需哺乳 8-12 次/天；生後第 1 天 5-7 mL/次 → 第 3 天 30 mL/次 → 第 7 天 60 mL/次
  • 配方奶（足月）：20 kcal/oz（標準濃度）；需求量 150-180 mL/kg/天
  • 早產兒配方奶：22-24 kcal/oz（高熱量密度）；含 DHA/ARA；Fortifier 可加入母乳
  • 母乳哺育充足性評估：生後 3-5 天每日至少 6 次黃色軟便；體重每天增加 20-30 g（生後 2 週後）；餵食後嬰兒滿足感
