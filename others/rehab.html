復健評估基礎 Rehabilitation Assessment（ICF + 量表 + 治療團隊）
復健醫學的核心架構是 ICF（International Classification of Functioning, Disability and Health）——從身體功能、活動和參與三個層面評估患者。功能評估量表是復健的語言，Barthel index 和 FIM 是日常生活功能評估的主要工具；復健團隊是跨領域合作，包括復健科醫師、物理治療師（PT）、職能治療師（OT）、語言治療師（ST）、護理師和社工。
數值判讀
功能評估量表（Barthel + FIM + MRC + Berg）

Barthel Index（日常生活活動，ADL）

  • 評估項目（共 10 項）：進食、移位、修飾、如廁、洗澡、行走、上下樓梯、穿脫衣物、大便控制、小便控制
  • 滿分 100 分；判讀：100 = 完全獨立；75-95 = 輕度依賴；50-70 = 中度依賴；25-45 = 重度依賴；0-20 = 完全依賴
  • 臨床應用：中風後功能追蹤；住院復健入出院評估；≥60 分通常可回家；<40 分需考慮機構

FIM（Functional Independence Measure）

  • 18 個項目（13 項動作 + 5 項認知）；每項 1-7 分；總分 18-126
  • 7 = 完全獨立；1 = 完全依賴；5-6 = 需監督或輔具；1-4 = 需部分至完全協助
  • 優於 Barthel：包含認知功能（記憶、解決問題、社交）；更細緻的協助程度分級

其他常用量表

量表評估項目臨床應用
MRC Muscle Scale肌力（0-5 級）；0=無收縮；3=抗重力；5=正常神經肌肉疾病；GBS；ICU 肌無力
Berg Balance Scale14 項平衡測試；滿分 56 分<45 分 = 跌倒高風險；中風 / 帕金森評估
Modified Ashworth Scale（MAS）痙攣程度（0-4 級）中風 / 脊髓損傷後痙攣評估；Botox 治療前後
VAS / NRS疼痛強度（0-10）肌肉骨骼疼痛；慢性疼痛管理
6 分鐘步行測試（6MWT）6 分鐘最大步行距離心肺功能；COPD；心臟復健評估
判斷框架
ICF 架構 + 復健團隊分工

ICF 架構（WHO 2001）

  • 身體功能與結構（Body function & structure）：器官層面；肌力、關節活動度、認知功能、語言
  • 活動（Activity）：個人層面；行走、進食、穿衣、溝通
  • 參與（Participation）：社會層面；工作、休閒、社交、家庭角色
  • 環境因素（Environmental factors）：物理環境、社會支持、輔具、政策
  • 個人因素（Personal factors）：年齡、性別、動機、因應方式
  • 復健目標應涵蓋三個層面，不只是「讓肌力恢復」，而是「讓患者回到想要的生活角色」

復健團隊分工

角色主要負責
復健科醫師（Physiatrist）診斷、處方、協調團隊；肉毒桿菌注射；電診斷（EMG/NCS）
物理治療師（PT）動作功能；肌力、平衡、步態訓練；徒手治療；儀器治療
職能治療師（OT）日常生活活動（ADL）；手部功能；認知訓練；輔具評估；環境改造
語言治療師（ST）吞嚥功能評估（VFSS / FEES）；構音；語言障礙（失語症）；認知溝通
義肢矯具師（P&O）義肢製作與調整；矯具（AFO、KAFO）
社工（Social worker）出院計畫；社會資源；長照申請；家庭支持

電診斷（Electrodiagnosis）

  • 神經傳導檢查（NCS）：評估周邊神經功能；傳導速度 + 波幅；軸突損傷（波幅↓）vs 髓鞘病變（速度↓）
  • 肌電圖（EMG）：評估肌肉去神經狀態；Fibrillation + PSW = 去神經；MUP 分析評估再生
  • 臨床應用：腕隧道症候群；GBS；ALS；神經根病變；肌病變鑑別
中風復健 Stroke Rehabilitation（Brunnstrom + 痙攣 + Botox）
中風是成人最常見需要復健的神經疾病。早期復健（發病 24-48 小時內開始）是改善預後的關鍵。Brunnstrom 分期是評估中風後運動恢復的標準工具。痙攣（Spasticity）是中風後常見的上運動神經元症候群，Botox 注射是局部痙攣的一線治療。
判斷框架
中風復健時程 + Brunnstrom 分期

中風復健時程

階段時間重點
急性期發病後 0-2 週早期床邊復健（坐起、移位）；預防併發症（DVT、壓瘡、攣縮、肺炎）；吞嚥評估；早期下床
亞急性期2 週-3 個月恢復最快的黃金期；住院復健；密集治療（PT + OT + ST）；步態訓練；ADL 訓練
慢性期>3-6 個月功能維持；社區復健；輔具；環境改造；預防跌倒；繼發性預防（抗血小板、降壓）

Brunnstrom 分期（上肢 / 下肢 / 手部各自評估）

分期描述
Stage I弛緩性麻痺（Flaccid）；無自主動作
Stage II痙攣開始出現；聯合反應（Associated reaction）
Stage III痙攣達高峰；可做共同動作（Synergy pattern）
Stage IV開始脫離共同動作；部分分離動作
Stage V痙攣↓；更多分離動作；精細動作困難
Stage VI接近正常；協調稍差

中風常見復健問題

  • 肩關節半脫位：弛緩期上肢重力拉扯；肩帶支撐（吊帶）；避免強拉患側手
  • 肩手症候群（CRPS Type I）：患側手腫痛；避免靜脈注射患側；抬高患肢；類固醇；鏡像治療
  • 失語症（Aphasia）：Broca（表達型）；Wernicke（接受型）；語言治療；溝通輔助工具（AAC）
  • 半側忽略（Hemineglect）：右腦中風常見；視覺掃描訓練；Prism adaptation
  • 吞嚥障礙（Dysphagia）：床邊篩查（Water swallow test）；VFSS / FEES 確認；改變食物質地；姿勢調整
用藥指引
痙攣（Spasticity）處置 + Botulinum Toxin

痙攣評估（Modified Ashworth Scale）

  • 0：無張力增加
  • 1：輕微阻力（活動末端）
  • 1+：輕微阻力（<1/2 關節活動度）
  • 2：明顯阻力但仍可活動
  • 3：大幅阻力；被動活動困難
  • 4：關節固定（攣縮）

痙攣治療（依嚴重度 + 範圍）

治療適用重點
伸展運動 + 擺位所有痙攣；預防攣縮每日持續性伸展；副木固定
口服藥物全身性痙攣Baclofen（GABA-B）；Tizanidine（α2 agonist）；Dantrolene（周邊作用）；Diazepam（鎮靜副作用）
Botulinum Toxin A（Botox）注射局部痙攣（1-2 塊肌肉）一線局部治療；效果 3-6 個月；超音波或 EMG 引導注射
Phenol / Alcohol 神經阻斷局部痙攣；長效效果可達 6-12 個月；感覺神經阻斷後可能疼痛
鞘內 Baclofen（ITB）嚴重全身性痙攣；脊髓損傷 / MS泵浦植入；持續鞘內給藥；口服無效時考慮

Botulinum Toxin 臨床重點

  • 機轉：抑制乙醯膽鹼釋放 → 神經肌肉阻斷 → 肌肉弛緩
  • 中風常見注射目標：上肢屈肌（肱二頭肌、腕屈肌、指屈肌）；下肢（腓腸肌、比目魚肌 → 馬蹄足）
  • 起效時間：注射後 3-7 天；最大效果 2-4 週；持續 3-6 個月
  • 劑量限制：每次總量 ≤400-600 U（Botox A）；分散注射
  • 合併治療：注射後配合伸展 + PT 效果最佳；不可單獨靠 Botox
神經復健 Neurological Rehabilitation（脊髓損傷 + TBI + 帕金森）
脊髓損傷（SCI）的功能預後與損傷節段和完整性密切相關，ASIA 分類是國際標準。創傷性腦傷（TBI）的 Rancho Los Amigos 認知分期用於追蹤恢復。帕金森復健強調步態訓練、平衡訓練和語言治療（LSVT），配合藥物治療效果最佳。
數值判讀
脊髓損傷（SCI）— ASIA 分類 + 功能預後

ASIA 損傷分類（AIS）

分級描述
ASIA A（完全性）S4-S5 節段無感覺或運動功能保留
ASIA B（感覺不完全）損傷平面以下有感覺但無運動功能（包括 S4-S5）
ASIA C（運動不完全）損傷平面以下超過一半關鍵肌肉肌力 <3 級
ASIA D（運動不完全）損傷平面以下超過一半關鍵肌肉肌力 ≥3 級
ASIA E（正常）感覺和運動功能正常（但可能有反射異常）

損傷節段與功能預後

損傷節段保留功能預期獨立程度
C1-C4頸部肌肉；可能需呼吸器電動輪椅；需全時照護
C5屈肘（肱二頭肌）；肩外展電動輪椅；部分上肢功能；需協助
C6伸腕（橈側伸腕肌）手動輪椅（部分）；腱固定性抓握（Tenodesis grip）；較獨立
C7伸肘（肱三頭肌）；屈腕手動輪椅；大部分 ADL 獨立
T1-T9上肢完整；部分軀幹手動輪椅；ADL 獨立
T10-L2上肢完整；部分下肢矯具輔助步行（KAFO）；輪椅為主
L3-S1股四頭肌（L3/4）；踝背屈（L4）AFO 輔助步行；部分可獨立行走

SCI 重要併發症

  • 自律神經反射異常（Autonomic Dysreflexia）：T6 以上損傷；誘因（膀胱過脹/便秘/壓瘡）→ 突發高血壓 + 頭痛 + 皮膚潮紅 / 出汗（損傷以上）+ 心搏過緩；緊急處置：坐起 + 找誘因（先排尿）；Nitroglycerine / Nifedipine（血壓極高時）
  • 神經性膀胱：間歇性導尿（CIC）= 標準處置；目標殘尿量 <100 mL；Oxybutynin（逼尿肌過動）
  • 壓瘡：翻身 q2h；減壓坐墊；定期皮膚檢查
  • 異位骨化（Heterotopic ossification）：關節周圍異常骨形成；髖關節最常見；Indomethacin 預防；放射治療

Rancho Los Amigos 認知分期（重度 TBI）

  • I-II（無反應/反射）：昏迷期；感覺刺激；被動關節運動
  • III（局部反應）：對刺激有一致性反應；開始感覺刺激
  • IV（混亂躁動）：激動、攻擊、無目的行為；結構化環境；低刺激
  • V-VI（混亂、適當）：開始跟從指令；記憶困難；需提示
  • VII-VIII（自動、有目的）：日常例行活動；監督至獨立
  • 腦震盪後症候群：頭痛、頭暈、認知困難、情緒障礙；多數 3 個月內恢復；重返運動分階段原則

帕金森復健重點

  • 步態訓練：凍步（Freezing of gait）= 最影響功能；視覺提示（地板線條）；聽覺節律提示（節拍器）；跨大步訓練
  • LSVT LOUD（Lee Silverman Voice Treatment）：改善聲音響度；帕金森語言治療金標準；4 週密集療程
  • LSVT BIG：改善動作幅度；大動作訓練（Big amplitude movement）
  • 平衡訓練：太極拳（高品質證據）；跑步機訓練；Berg balance scale 追蹤
  • 運動時機：配合 Levodopa 作用高峰期（On period）進行復健效果最佳
  • 吞嚥問題：晚期帕金森常見；VFSS 評估；改變食物質地；避免誤嗆
肌肉骨骼復健 MSK Rehabilitation（下背痛 + 肩關節 + 膝關節）
肌肉骨骼問題是門診最常見的復健科主訴。下背痛（LBP）是全球失能第一名，90% 是非特異性；紅旗警訊是關鍵鑑別。肩旋轉肌腱撕裂和膝關節骨關節炎是常見的復健目標。運動治療是各種肌肉骨骼問題的核心治療。
判斷框架
下背痛（LBP）— 紅旗 + 分類 + 治療

下背痛紅旗警訊（Red Flags，需進一步檢查）

  • 年齡 >50 或 <20 歲新發
  • 有癌症、結核、HIV 病史
  • 夜間痛、休息不緩解（腫瘤 / 感染）
  • 發燒、體重下降（感染 / 惡性）
  • 馬尾症候群：雙側神經根症狀 + 大小便失禁 + 鞍區感覺喪失 → 緊急 MRI + 外科會診
  • 外傷史（骨質疏鬆患者輕微外傷即可骨折）
  • 類固醇長期使用

下背痛分類 + 治療

類型特徵治療
非特異性下背痛（90%）無神經學缺損；無紅旗；多在 6-12 週內自限活動（不要臥床）；NSAIDs；熱敷；運動治療；認知行為治療
神經根病變（Radiculopathy）沿皮節分布的放射痛；SLR test（+）；感覺 / 運動 / 反射異常NSAIDs；Gabapentin；硬膜外類固醇注射；手術（保守 6 週無效）
椎管狹窄（Stenosis）神經性跛行；走路加重、彎腰緩解；老年人物理治療；硬膜外類固醇；手術減壓（重度）
脊椎滑脫（Spondylolisthesis）椎體前移；L4-L5 最常見；青少年競技運動員（壓力性骨折）核心肌群訓練；限制過度伸展；手術（重度 / 神經學損傷）
  • 核心原則：急性期避免臥床休息（延長恢復）；鼓勵適度活動；運動治療是慢性下背痛最有效的介入
  • Opioid：慢性下背痛不建議長期使用（依賴風險 > 效益）
用藥指引
肩關節（旋轉肌腱）+ 膝關節復健

旋轉肌腱症候群（Rotator Cuff）

  • 旋轉肌腱組成（SITS）：Supraspinatus（最常撕裂）；Infraspinatus；Teres minor；Subscapularis
  • 夾擊症候群（Impingement）：Painful arc（60-120°）；Neer sign（+）；Hawkins test（+）；肩峰下空間狹窄
  • 旋轉肌腱撕裂：MRI 確診；部分撕裂 → 復健；完全撕裂 + 功能障礙 → 手術修補
  • 治療：NSAIDs；肩峰下類固醇注射（短期）；PT（肩胛穩定肌群訓練）；PRP 注射（爭議）

五十肩（Frozen Shoulder / Adhesive Capsulitis）

  • 三期：疼痛期（6 週-9 個月）→ 僵硬期（4-6 個月）→ 恢復期（6-24 個月）；多數 1-3 年自然恢復
  • 治療：NSAIDs；關節內類固醇注射（疼痛期效果最佳）；物理治療（伸展）；水擴張術（Hydrodilation）；關節鏡放鬆術

膝關節骨關節炎（Knee OA）復健

  • 股四頭肌訓練 = 最重要：↑ 關節穩定性；↓ 關節負荷；等長 + 等張 + 水中運動
  • 體重控制：每減 1 kg = 膝關節負荷減少 4 kg（步行時）
  • 輔具：手杖（對側手）；膝護具（卸載支架）；楔型鞋墊（內側 OA → 外側楔型）
  • 注射治療：關節內類固醇（短期 1-3 個月效果）；HA 注射（爭議，部分患者有效）；PRP（中度證據）
  • 髕骨股骨疼痛症候群（PFPS）= 年輕人常見；股四頭肌訓練 + 髕骨貼紮（McConnell taping）
心肺復健 Cardiopulmonary Rehabilitation（心臟復健 + 肺復健）
心臟復健（Cardiac Rehabilitation）是心肌梗塞後的 Class I 建議，可降低死亡率 25%、再住院率 30%，但台灣參與率仍偏低。肺復健（Pulmonary Rehabilitation）是 COPD 最重要的非藥物治療，能改善運動耐受性和生活品質，比藥物更有效改善呼吸困難。

心臟復健（Cardiac Rehabilitation）Phase I-III
階段時間地點內容
Phase I（住院期）急性期住院病房 / CCU早期活動（坐起、站立、短距離步行）；衛教（藥物、飲食、危險因子）；運動耐受性評估
Phase II（門診監測期）出院後 2-12 週醫院門診ECG 監測下有氧運動；個別化運動處方；心血管危險因子管理；心理支持
Phase III（維持期）長期社區 / 家庭自主運動維持；生活型態改變；定期追蹤

心臟復健適應症 + 運動處方

  • 適應症：急性心肌梗塞後；CABG / PCI 後；穩定型心絞痛；心臟衰竭（EF <35% 也可）；心臟瓣膜手術後；心臟移植後
  • 運動強度目標：最大心率的 50-80%；或 RPE（自覺用力程度）12-14；或 HRR（心率儲備）40-70%
  • FITT 原則：Frequency 3-5 次/週；Intensity 中等強度；Time 20-60 分鐘；Type 有氧（步行、腳踏車）+ 阻力訓練
  • 絕對禁忌（暫時停止運動）：不穩定心絞痛；心室頻脈；失代償性心衰竭；嚴重主動脈狹窄；急性心肌炎
  • 心臟復健每降低 1 MET 運動能力 = 死亡率增加 12%；提升運動能力是最重要的預後指標
用藥指引
肺復健（Pulmonary Rehabilitation）

肺復健適應症 + 效益

  • 主要適應症：COPD（GOLD 2-4）；限制性肺疾病；支氣管擴張；肺高壓；肺移植前後；肺癌手術前後
  • 禁忌：不穩定心臟病；嚴重骨骼肌肉問題影響運動；認知障礙無法配合
  • 效益（最高等級證據）：改善呼吸困難（dyspnea）；↑ 運動耐受性（6MWT）；↑ 生活品質（SGRQ）；↓ 急性惡化住院；但不改變 FEV1

肺復健組成

  • 運動訓練（核心）：有氧運動（步行 / 腳踏車）+ 上下肢肌力訓練；高強度優於低強度；間歇訓練（Interval training）適合嚴重 COPD
  • 呼吸技巧：縮唇呼吸（Pursed-lip breathing）= 延長呼氣、↓ 動態過度充氣；橫膈呼吸；能量節省技巧
  • 胸腔物理治療：姿位引流（Postural drainage）；扣擊；主動循環呼吸技巧（ACBT）；震動排痰；適合痰多患者（支氣管擴張）
  • NIV 輔助運動：嚴重 COPD 在肺復健期間使用 BiPAP → 可增加運動強度
  • 衛教：戒菸；藥物使用（吸入劑技術）；急性惡化早期辨識；營養

ICU 復健（Early Mobilization）

  • ICU 早期活動（發病 48-72 小時內）→ ↓ 機械通氣天數；↓ ICU 獲得性虛弱（ICUAW）；↑ 出院時功能
  • 安全標準：FiO₂ <0.6；PEEP <10；MAP >65（或穩定升壓劑）；HR 40-130；無積極治療的心律不整
截肢 + 義肢 Amputation & Prosthetics（分類 + 義肢選擇 + 幻肢痛）
台灣截肢最常見原因是糖尿病足（約 50%），其次是周邊血管疾病和外傷。截肢平面決定義肢類型和功能潛力——保留越多肢體越好。幻肢痛（Phantom limb pain）影響 70-80% 截肢者，是復健的重要挑戰。

殘肢照護 + 義肢訓練

  • 術後立即：硬式殘肢套（Rigid dressing）→ 塑形 + 減少水腫；彈性繃帶包紮；懸吊時避免長時間屈髖（膝上截肢）
  • 義肢訓練時機：傷口癒合（6-8 週）+ 殘肢定型後；臨時義肢（Preparatory prosthesis）→ 定型義肢
  • K-Level 功能分類（義肢保險給付依據）：K0 = 無法使用；K1 = 室內平地；K2 = 社區低強度；K3 = 社區全強度；K4 = 高度活動（運動員）
  • 義肢足部選擇：SACH（最簡單）；Energy-storing（碳纖維，K3-K4）；Microprocessor ankle（高功能）
  • 膝上截肢義肢膝：Single-axis；Polycentric；Microprocessor knee（C-Leg，K3-K4，最智慧）
用藥指引
幻肢痛（Phantom Limb Pain）+ 殘肢問題

幻肢痛

  • 定義：截肢後感覺截肢部位仍然存在並有疼痛；70-80% 截肢者發生；機轉 = 中樞神經重塑（Cortical reorganization）
  • 區分：幻肢痛（Phantom limb pain）= 有痛；幻肢感（Phantom sensation）= 無痛的感覺；殘肢痛（Residual limb pain）= 殘端本身疼痛
  • 藥物治療：
    • Gabapentin / Pregabalin（神經病變痛，一線）
    • Tricyclic antidepressants（Amitriptyline）
    • SNRIs（Duloxetine）
    • Opioid（短期重度疼痛）
    • Ketamine（頑固性幻肢痛）
  • 非藥物治療：
    • 鏡像治療（Mirror therapy）：最有證據的非藥物治療；視覺反饋重塑大腦皮質
    • TENS（經皮電神經刺激）；殘肢按摩；針灸
    • 虛擬實境（VR）= 新興治療
