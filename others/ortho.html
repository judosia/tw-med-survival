骨科評估基礎 Orthopaedic Assessment（骨折分類 + AO 分型 + 手術原則）
骨科評估的三大核心：骨折描述（解剖位置 + AO 分型）；神經血管評估（6P）；手術時機與方式決策。參考 Rockwood & Green 9th Edition 骨折分類原則，任何骨折描述都需包含：部位、骨折型態（橫型/斜型/螺旋/粉碎）、移位程度、開放或閉鎖、合併神經血管傷害。
判斷框架
骨折描述 + AO 分型 + 骨折型態

骨折系統性描述（每個骨折必須包含）

  • 骨骼 + 解剖位置：哪根骨頭；近端 / 中段 / 遠端；骨幹 / 幹骺端 / 骨骺
  • 骨折型態：橫型（Transverse）/ 斜型（Oblique）/ 螺旋型（Spiral）/ 粉碎型（Comminuted）/ 節段型（Segmental）
  • 移位（Displacement）：成角（Angular，degrees）；平移（Translation，%）；縮短（Shortening，cm）；旋轉（Rotation）
  • 開放 vs 閉鎖（Open vs Closed）：Gustilo-Anderson 分型（見急症 block）
  • 合併傷：神經損傷；血管損傷；關節內骨折；韌帶損傷

AO/OTA 骨折分型（長骨三碼系統）

  • 第一碼（骨骼）：1 = 肱骨；2 = 橈尺骨；3 = 股骨；4 = 脛腓骨
  • 第二碼（部位）：1 = 近端；2 = 骨幹；3 = 遠端
  • 第三碼（型態）：A = 簡單骨折；B = 楔形（Wedge）；C = 複雜（Complex）/ 粉碎
  • 例：31A2 = 股骨近端簡單骨折（股骨頸骨折）；42C3 = 脛骨遠端複雜粉碎骨折（Pilon 骨折）

骨折癒合基礎

癒合類型條件機轉
初級癒合（Primary healing）解剖復位 + 絕對穩定（鋼板固定）直接哈佛氏系統重建；無骨痂
次級癒合（Secondary healing）相對穩定（髓內釘 / 石膏）骨痂形成（軟骨性骨痂 → 硬骨痂）；最常見
不癒合（Non-union）感染 / 不穩定 / 血供不良 / 骨缺損肥大型（血供好，固定不足）vs 萎縮型（血供差）
判斷框架
神經血管評估 + 固定方式選擇

神經血管評估（每個骨折都要做）

  • 脈搏（Pulse）：遠端動脈搏動（橈動脈 / 足背動脈 / 脛後動脈）；ABI；若疑似血管損傷 → CTA 或血管攝影
  • 毛細血管充填（Capillary refill）：正常 <2 秒；延遲 → 末端缺血
  • 感覺（Sensation）：輕觸覺；兩點辨別覺（2-point discrimination）；神經支配區域
  • 運動（Motor）：關鍵肌肉測試；骨折附近神經支配區域
  • 常見合併神經損傷：肱骨幹骨折 → 橈神經（Radial nerve，垂腕）；髖關節脫臼 → 坐骨神經；腓骨頸骨折 → 腓總神經（Foot drop）；肱骨遠端骨折（兒童）→ 前骨間神經（AIN）

固定方式選擇

方式適應症優缺點
石膏 / 副木（Cast/Splint）穩定性骨折；兒童骨折；非手術治療非侵入性；但需長期制動；肌肉萎縮
髓內釘（IMN）長骨骨幹骨折（脛骨、股骨、肱骨）負重早；生物力學佳；感染率低；手術時間短
鋼板螺釘（ORIF）關節內骨折；幹骺端；IMN 無法處理解剖復位；需廣泛剝離；感染率略高
外固定器（External fixator）開放性骨折（暫時）；感染；嚴重軟組織傷；骨盆骨折快速；感染少；但釘道感染；不適合長期
全關節置換（TKR/THR）股骨頸骨折（老年人）；嚴重關節炎合併骨折立刻負重；但人工關節壽命有限

手術時機

  • 緊急（<6-8 小時）：開放性骨折（清創）；血管損傷；筋膜室症候群（筋膜切開）；脊髓進行性損傷
  • 急迫（<24-48 小時）：股骨頸骨折（<24 小時，↓ 股骨頭壞死）；不穩定骨盆骨折；多重外傷患者長骨穩定
  • 擇期（3-7 天）：軟組織腫脹消退後；複雜關節內骨折；等待全身狀況改善
上肢常見骨折 Upper Extremity Fractures（Colles + 肱骨 + 鎖骨）
上肢骨折中最常見的是橈骨遠端骨折（Distal radius fracture），又稱 Colles 骨折，是成人最常見的骨折，好發於老年骨質疏鬆女性（手撐地跌倒）。肱骨近端骨折是老年人第三常見骨折。鎖骨骨折是年輕人最常見的骨折（接觸性運動）。
用藥指引
橈骨遠端骨折（Colles / Distal Radius Fracture）

典型表現 + 分型

  • Colles 骨折：橈骨遠端背側成角（Dorsal angulation）+ 橈側移位；「Dinner fork deformity」；跌倒手撐地（FOOSH = Fall on outstretched hand）
  • Smith 骨折（反 Colles）：掌側成角（Volar angulation）；手背撐地或直接暴力
  • Barton 骨折：橈骨遠端關節內邊緣骨折 + 腕關節半脫位
  • Chauffeur 骨折（Radial styloid）：橈骨莖突撕裂骨折；舟狀骨壓迫機轉

影像評估關鍵參數

參數正常值臨床意義
橈骨傾斜角（Radial inclination）22°（正面）<15° → 功能受損
掌側傾斜角（Volar tilt）11°（側面）背側成角 >10° → 考慮手術
橈骨高度（Radial height）11-12 mm縮短 >5 mm → 考慮手術
關節內台階（Articular step-off）0 mm>2 mm → 手術適應症

治療

  • 非手術（穩定骨折）：閉合復位 + 短臂石膏（6 週）；老年患者輕微移位可接受保守
  • 手術適應症：關節內台階 >2 mm；背側成角 >10°；橈骨縮短 >5 mm；不穩定骨折（閉合復位失敗）
  • 掌側鎖定鋼板（VLP，Volar locking plate）：目前主流手術方式；可早期活動
  • 注意合併傷：舟狀骨骨折（10%）；TFCC 損傷；正中神經急性卡壓（急性腕管症候群）→ 緊急減壓
判斷框架
肱骨近端骨折（Neer 分型）+ 鎖骨骨折

肱骨近端骨折（Neer 分型）

  • Neer 分型依骨折部分（Part）數分類：大結節（Greater tuberosity）、小結節（Lesser tuberosity）、肱骨頭（Head）、肱骨幹（Shaft）
  • 1-Part：無移位 or 移位 <1 cm / <45°；佔所有肱骨近端骨折 80%；保守治療（懸吊 + 早期鐘擺運動）
  • 2-Part：一個部分移位；外科頸骨折最常見；保守或手術（依移位程度）
  • 3-Part：兩個部分移位；肌腱旋轉力使骨折移位；手術（ORIF / 鎖定鋼板）
  • 4-Part：所有部分移位；肱骨頭缺血性壞死（AVN）風險高（>30%）；老年人 → 半肩關節置換（Hemiarthroplasty）或反肩置換；年輕人 → 嘗試 ORIF
  • 大結節骨折：肩關節前脫臼後最常見合併傷；移位 >5 mm → 手術固定（否則外轉力量受損）

鎖骨骨折（Clavicle Fracture）

  • 分段：中段（Midshaft，80%，最常見）；外側段（Lateral，15%，靠近肩鎖關節）；內側段（Medial，5%，罕見）
  • 中段鎖骨骨折：縮短 >2 cm；粉碎；垂直移位 >100%；開放性；神經血管損傷 → 手術（鋼板）；其餘多保守（懸吊 3-6 週）
  • 外側段骨折（Neer Type II）：喙鎖韌帶（Coracoclavicular ligament）斷裂 → 不穩定 → 手術固定率高
  • 注意合併傷：氣胸（鎖骨骨折端穿刺）；臂神經叢損傷；鎖骨下血管損傷（少見但危急）

其他上肢重要骨折

  • 舟狀骨骨折（Scaphoid）：解剖鼻煙盒（Anatomic snuffbox）壓痛；X 光可能正常（早期）→ MRI 或 CT 確診；腰部骨折（Waist）血供差 → 不癒合 / AVN 風險；移位 → 手術（headless compression screw）
  • 肱骨幹骨折：橈神經（Radial nerve）損傷 20%（中下 1/3 交界）→ 垂腕；多數保守（functional brace）；橈神經多觀察 3 個月（多數自行恢復）
下肢骨折 Lower Extremity Fractures（股骨頸 + 髖關節脫臼 + 脛骨 + 踝關節）
股骨頸骨折是老年人最重要的骨折，死亡率高（1 年死亡率 20-30%），需在 24-48 小時內手術。髖關節後脫臼= 骨科急症，需在 6 小時內復位（↓ 股骨頭壞死風險）。脛骨骨折是最常見需要髓內釘固定的骨折。踝關節骨折依 Lauge-Hansen 分型決定穩定性和手術適應症。
緊急處置
股骨頸骨折（Garden 分型）+ 髖關節脫臼

股骨近端骨折分類

骨折類型位置特徵
股骨頸骨折（Femoral neck）囊內（Intracapsular）股骨頭血供受損 → AVN 風險；Garden 分型；外旋短縮
轉子間骨折（Intertrochanteric）囊外（Extracapsular）血供好；出血較多；Evans 分型；外旋縮短更明顯
轉子下骨折（Subtrochanteric）囊外肌肉牽拉使骨折端移位；髓內釘治療

Garden 分型（股骨頸骨折）

  • Garden I（嵌插型）：不完全骨折；外翻嵌插；穩定；可保守 or 螺釘固定
  • Garden II（完全無移位）：完全骨折但無移位；螺釘固定
  • Garden III（部分移位）：部分位移；小梁線不連續；AVN 風險↑
  • Garden IV（完全移位）：完全移位；AVN 風險最高
  • 實務簡化：Garden I/II = 未移位（保留頭，螺釘固定）；Garden III/IV = 移位（老年 → 半髖置換；年輕 → 嘗試 ORIF）
  • 手術時機：<24-48 小時內（↓ AVN 風險；↓ 臥床併發症）；老年人延遲手術 → 肺炎 / DVT 風險↑
  • 轉子間骨折：DHS（Dynamic hip screw）= 穩定型首選；PFNA（髓內釘）= 不穩定型；半髖置換（嚴重粉碎）

髖關節脫臼（急症！）

  • 後脫臼（90%）：屈曲 + 內收 + 內旋姿勢（如坐車膝蓋撞儀表板）；坐骨神經損傷（10-15%）
  • 前脫臼（10%）：伸展 + 外旋 + 外展姿勢；股神經 / 血管損傷
  • 緊急閉合復位（Allis / Stimson 法）：<6 小時 AVN 風險 <10%；>6 小時風險急增；復位後 X 光確認 + CT 評估合併骨折
  • 合併股骨頭骨折（Pipkin 分型）：復位後若關節面不整 → 手術取出或固定骨折片
判斷框架
脛骨骨折 + 踝關節骨折（Lauge-Hansen）

脛骨骨折

  • 脛骨幹骨折：最常見需要髓內釘固定的骨折；筋膜室症候群最常見（36% 的 ACS 來自脛骨幹骨折）；開放性骨折多見（脛骨前方皮下缺乏軟組織保護）
  • 髓內釘（IMN）：首選治療；閉合性骨幹骨折；允許早期負重
  • 脛骨平台骨折（Schatzker 分型）：I-VI 型；外側（最常見，Schatzker I-III）；雙髁（Schatzker V-VI，高能量）；CT 評估壓陷程度（>2 mm → 手術）；注意合併韌帶損傷（LCL / ACL）

踝關節骨折（Lauge-Hansen 分型）

類型受傷機轉骨折型態
SA（Supination-Adduction）旋後 + 內收腓骨橫向骨折（下脛腓韌帶以下）+ 可能內踝縱向骨折（Vertical）
SER（Supination-External Rotation，最常見）旋後 + 外旋前下脛腓韌帶損傷 → 腓骨斜型骨折（下脛腓韌帶水平）→ 後踝 → 內踝（4 期）
PA（Pronation-Abduction）旋前 + 外展內踝 / 三角韌帶 → 脛腓韌帶 → 腓骨粉碎（下脛腓韌帶水平）
PER（Pronation-External Rotation）旋前 + 外旋內踝 → 下脛腓韌帶 → 腓骨高位骨折（Maisonneuve 骨折）
  • Maisonneuve 骨折：腓骨近端骨折 + 內踝 / 三角韌帶損傷 + 下脛腓韌帶損傷 → 踝關節不穩定；若只照踝關節 X 光會漏診 → 必須照全長腓骨
  • 穩定性評估：Weber A（下脛腓韌帶以下）= 穩定；Weber B（水平）= 可穩定或不穩定；Weber C（以上）= 不穩定；重力壓力試驗 / 外旋壓力試驗判斷
  • 治療：穩定骨折 → 石膏；不穩定（移位 >2 mm 或下脛腓分離）→ 手術（ORIF + 下脛腓螺釘）
脊椎骨折 Spine Fractures（頸椎 + 胸腰椎 + 骨質疏鬆）
脊椎骨折的穩定性評估依 Denis 三柱理論：前柱（前 2/3 椎體）+ 中柱（後 1/3 椎體 + 後縱韌帶）+ 後柱（椎弓 + 棘突韌帶），中柱是穩定性的關鍵——中柱受損 → 不穩定。骨質疏鬆性壓迫性骨折（VCF）是最常見的脊椎骨折，需注意排除病理性骨折。
判斷框架
胸腰椎骨折（Denis 分類）+ 骨質疏鬆 VCF

Denis 骨折分類

類型受傷機轉穩定性治療
壓迫型（Compression）軸向負荷 + 屈曲；前柱受損；中柱完整穩定保守（支架 / 保守）；前柱高度喪失 >50% → 手術
爆裂型（Burst）軸向壓縮；前 + 中柱受損；骨片可能後移壓迫脊髓部分不穩定無神經症狀 + 穩定 → 保守；有神經症狀或椎管狹窄 → 手術
屈曲-分離型（Flexion-distraction / Chance）安全帶傷害；後柱張力傷害；穿越椎體或椎間盤不穩定骨性 Chance → 石膏；韌帶性 Chance → 手術融合
骨折-脫臼型（Fracture-dislocation）高能量；三柱全損；脊髓損傷風險最高極不穩定手術（後路或前後路聯合）

TLICS 評分（胸腰椎損傷分類和嚴重度評分）

  • 骨折型態：壓迫型 1 分；爆裂型 2 分；旋轉 / 平移 3 分；分離型 4 分
  • 後韌帶複合體（PLC）：完整 0 分；懷疑 2 分；損傷 3 分
  • 神經功能：完整 0 分；神經根 2 分；完全脊髓損傷 2 分；不完全脊髓損傷 3 分
  • 判斷：≤3 分 → 保守；4 分 → 個別化；≥5 分 → 手術

骨質疏鬆性椎體壓迫骨折（VCF）

  • 好發：T12-L1 交界；停經後女性；骨質疏鬆；可無明顯外傷史
  • 排除病理性骨折：MRI（水腫訊號）；骨掃描；若惡性腫瘤病史 → 切片
  • 治療：急性期止痛 + 臥床（短期）+ 支架；骨鬆治療（Bisphosphonate / Denosumab）；椎體成形術（Vertebroplasty）/ 後凸成形術（Kyphoplasty）= 頑固疼痛 or 後凸進行性增加
緊急處置
頸椎骨折 + NEXUS / Canadian C-spine Rule

頸椎骨折臨床評估（何時需要影像）

  • NEXUS 低風險標準（全部符合才可不照 X 光）：無後頸中線壓痛；無意識改變；無中毒；無局部神經缺損；無分散注意力的疼痛傷害
  • Canadian C-Spine Rule（更高敏感度）：高風險因素（年齡≥65、危險機轉、肢端感覺異常）→ 一定要照；低風險因素 + 能主動旋轉頸部 45° → 可不照

重要頸椎骨折類型（見神經外科 neuro-spine 更完整）

骨折機轉穩定性 + 處置
Jefferson 骨折（C1）軸向壓縮韌帶完整 → 穩定；Halo brace；橫韌帶斷裂 → 不穩定 → 手術
Odontoid（齒狀突）骨折屈曲 / 過伸Type II（齒突基部）= 最常見不穩定型 → 手術（螺釘固定 or 後路融合）；老年骨質疏鬆高不癒合率
Hangman 骨折（C2 椎弓）過伸 + 軸向壓縮多數穩定（椎管減壓）；Cervical collar or Halo；嚴重移位 → 手術

任何外傷患者有頸部疼痛 / 神經症狀 → 立刻頸椎固定（Cervical collar）！確認影像前不可移除。
骨科急症 Orthopaedic Emergencies（筋膜室症候群 + 開放性骨折 + 骨髓炎）
急性筋膜室症候群（ACS）是骨科最重要的急症，Rockwood & Green 強調：唯一正確治療是緊急筋膜切開術。關鍵診斷標準：ΔP（舒張壓 - 筋膜室內壓）<30 mmHg = 手術適應症。開放性骨折需在 6 小時內清創（Gustilo-Anderson 分型決定是否一期縫合）。化膿性關節炎是真正的急症，需 24-48 小時內沖洗。
緊急處置
急性筋膜室症候群（ACS）— 參考 Rockwood & Green Ch.16
ACS → 立刻筋膜切開術！延誤是導致治療失敗的唯一原因。脈搏存在不能排除 ACS！

好發骨折（Rockwood & Green 數據）

  • 脛骨幹骨折（36%，最常見）；軟組織傷（23%）；橈骨遠端骨折（9.8%）；前臂骨折（7.9%）；股骨骨折（3%）
  • 高風險族群：年輕男性（肌肉量大，筋膜室空間相對小）；閉鎖性骨折（比開放性更易）；低 Gustilo 級別開放性骨折

臨床診斷（5P + 1P）

  • Pain（疼痛）：與損傷不成比例（Out-of-proportion pain）= 最早、最重要的症狀
  • Pain on passive stretch（被動伸展疼痛）：被動拉伸受影響筋膜室肌肉時疼痛加劇 = 最敏感的體徵
  • Pressure（筋膜室腫脹）：筋膜室緊繃感
  • Paresthesia（感覺異常）：麻木、針刺感（神經缺血）
  • Paralysis（麻痺）：晚期；運動功能喪失
  • ⚠️ Pulselessness（無脈搏）：極晚期；脈搏存在不能排除 ACS！

筋膜室壓力測量（Rockwood & Green 標準）

  • ΔP = 舒張壓（DBP）- 筋膜室內壓（ICP）
  • ΔP ≤ 30 mmHg = 手術適應症（緊急筋膜切開術）
  • 絕對壓力 > 30 mmHg：過去常用閾值，但 McQueen 等研究顯示 ΔP 更可靠（考慮個體灌流差異）
  • 適用情況：昏迷患者；區域麻醉；無法配合的患者；臨床診斷不確定時

小腿四個筋膜室切開

  • 前室（Anterior）：脛前動脈；腓深神經（foot drop 風險）
  • 外側室（Lateral）：腓淺神經
  • 後淺室（Superficial posterior）：腓腸肌 / 比目魚肌
  • 後深室（Deep posterior）：脛後動靜脈；脛神經；最常被遺漏！需完整切開
  • 切開後：傷口開放（VAC 或 wet dressing）→ 3-5 天腫脹消退後延遲縫合或植皮

開放性骨折處置（MESS 評分 / 保肢 vs 截肢）

  • 急性處置：用生理食鹽水濕紗布覆蓋（現場）；止血；固定；緊急送往手術室
  • 抗生素：Type I/II → Cefazolin；Type III → Cefazolin + Gentamicin；農業傷 / 污水 → 加 Penicillin（涵蓋 Clostridium）；越早越好（傷後 3 小時內）
  • 清創（Debridement）：<6 小時（傳統黃金時間，現已有爭議但仍建議早期）；徹底切除壞死組織；大量生理食鹽水沖洗（>9L）
  • 骨折固定：Type I/II → 一期髓內釘 or 鋼板；Type III → 外固定器（暫時）→ 軟組織穩定後轉換
  • 一期縫合：Type I → 可；Type II/III → 不宜（延遲縫合或皮瓣）
  • 破傷風預防：確認接種史；未接種或不確定 → Tetanus toxoid + TIG

化膿性關節炎（Septic Arthritis）

  • 臨床：發燒 + 單關節紅腫熱痛 + 活動度↓；膝關節最常見；S. aureus 最常見（成人）；淋球菌（年輕性活躍成人）
  • 診斷：關節液穿刺：WBC >50,000（高度懷疑）；>100,000（幾乎確定）；革蘭氏染色 + 培養；血液培養
  • Kocher criteria（兒童）：發燒 + 不負重 + ESR >40 + WBC >12,000；4 項全中 = 化膿性關節炎機率 >99%
  • 治療：關節沖洗（Arthroscopic lavage / Open washout）= 緊急；24-48 小時內；靜脈抗生素（S. aureus → Vancomycin 直到藥敏）；延遲處置 → 關節軟骨破壞 → 骨關節炎
關節疾病 Joint Diseases（退化性關節炎 + TKR/THR + 類風濕）
骨科最常見的擇期手術是全膝關節置換（TKR）和全髖關節置換（THR），主要適應症是終末期骨關節炎（OA）。術後最重要的急性併發症是人工關節感染（PJI）和DVT/PE。缺血性股骨頭壞死（AVN）需要早期診斷（MRI），否則股骨頭塌陷後只能換關節。

骨關節炎（Osteoarthritis）治療階梯

  • 非藥物：體重控制（最重要）；有氧運動 + 肌力訓練；物理治療；輔具（手杖）；避免過度負重活動
  • 藥物：乙醯胺酚（Acetaminophen，輕度）；NSAIDs（口服 or 外用，中度）；關節內類固醇注射（短期疼痛緩解）；Duloxetine（SNRIs，慢性疼痛）；關節內 Hyaluronic acid（HA）注射（效果爭議）
  • 手術適應症：嚴重疼痛影響日常生活 + 藥物治療失敗 + X 光顯示終末期關節炎（關節間隙消失）

人工關節感染（Periprosthetic Joint Infection，PJI）

  • 分類：早期（<3 個月）= S. aureus；遲發（3-24 個月）= CoNS（生物膜）；晚期（>24 個月）= 血行性
  • 診斷：ESR + CRP + 關節液 WBC（>1700，TKR；>4200，THR）+ 培養；Alpha-defensin 測試（高特異性）
  • 治療：早期（<3-4 週）→ 清創 + 更換內襯（DAIR）；確立感染 → 二階段翻修（移除 + 抗生素骨水泥墊片 → 6 週抗生素 → 重新置換）

AVN 危險因素（記憶：CAST）

  • C — Corticosteroids：最常見的非外傷性原因；劑量和時間相關
  • A — Alcohol：酒精中毒；脂肪栓塞理論
  • S — Sickle cell / SLE：鐮狀細胞貧血；自體免疫（合併類固醇使用）
  • T — Trauma：股骨頸骨折（移位）；髖關節脫臼；減壓症（潛水員）
  • 其他：痛風；Gaucher disease；放射線治療；化療

類風濕性關節炎（RA）骨科相關重點

  • 頸椎不穩定（C1-C2）：橫韌帶侵蝕 → 寰樞椎半脫臼（Atlantoaxial subluxation）；術前麻醉需評估（頸椎 X 光 / CT）；頸椎屈曲 X 光 ADI >3.5 mm（成人）→ 警訊
  • 前足（Forefoot）變形：蹠趾關節半脫臼；拇指外翻（Hallux valgus）；爪狀趾；手術矯正
  • 腕關節：橈腕關節侵蝕；尺骨頭背側半脫臼；屈肌腱鞘炎；腕隧道症候群
  • 術前注意：MTX 術前可繼續（現已更新建議）；類固醇患者需補充應激劑量（Stress dose）；術後感染風險↑（免疫抑制）
