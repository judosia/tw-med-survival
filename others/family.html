家庭醫學科

預防醫學、慢性病管理、老年醫學與安寧緩和，以台灣 NHI 框架和基層醫療視角整理 PGY 必備知識。

預防醫學 Preventive Medicine（癌症篩查 + 成人健檢 + 疫苗）
台灣國健署提供四大癌症免費篩查（乳癌、子宮頸癌、大腸癌、口腔癌）和成人健康檢查，是家醫科門診最重要的預防醫學工作。疫苗接種是最有成本效益的預防措施，成人疫苗常被忽略。

台灣四大癌症篩查 + 其他篩查建議

國健署四大癌症免費篩查（2024）

癌症對象篩查工具頻率
大腸癌50-74 歲糞便潛血（FIT）每 2 年
乳癌45-69 歲女性；40-44 歲一等親有乳癌乳房攝影（Mammography）每 2 年
子宮頸癌30 歲以上曾有性行為女性子宮頸抹片（Pap smear）每 3 年
口腔癌30 歲以上有嚼檳榔或吸菸習慣；18 歲以上原住民口腔黏膜檢查每 2 年

其他重要篩查（非國健署常規但臨床重要）

  • 肺癌（低劑量 CT，LDCT）：50-80 歲；每年 >20 包-年吸菸史；目前戒菸 <15 年；台灣 2022 年起納入補助（高風險族群）
  • 腹主動脈瘤（AAA）：65-75 歲曾吸菸男性；超音波一次篩查
  • 骨質疏鬆（DXA）：65 歲以上女性；70 歲以上男性；較早停經 / 類固醇使用 / 脆弱性骨折史 → 提早
  • 糖尿病前期：45 歲以上或有危險因素（肥胖 / 家族史 / 高血壓）→ FPG 或 HbA1c
  • HIV：15-65 歲常規篩查（USPSTF）；高風險族群更頻繁

台灣成人健康檢查（國健署）

  • 40-64 歲：每 3 年一次；血壓、BMI、腰圍、空腹血糖、血脂、腎功能、尿液
  • 65 歲以上：每年一次；加入老年功能評估（ADL / 憂鬱篩查 / 跌倒風險）

慢性病管理 Chronic Disease Management（DM + HTN + 高血脂）
台灣慢性病管理以NHI 慢性病連續處方箋為框架，最常見的三高（高血壓、高血糖、高血脂）往往同時存在。家醫科的核心任務是目標達成率追蹤和用藥調整，以及識別需要轉介專科的時機。

糖尿病（DM）+ 高血壓（HTN）基層管理

第二型糖尿病基層管理目標

指標一般目標個別化調整
HbA1c<7.0%老年 / 低血糖高風險 → <8.0%；年輕 / 新診斷 → <6.5%
血壓<130/80 mmHg老年（>65）→ <140/90 可接受
LDL-C<100 mg/dL有 ASCVD → <70 mg/dL；極高風險 → <55 mg/dL
BMI<24（台灣標準）體重減少 5-10% = 顯著改善血糖

DM 追蹤項目（家醫科定期）

  • 每次門診：血壓、體重、足部檢查、用藥依從性、低血糖評估
  • 每 3 個月：HbA1c
  • 每年：空腹血脂、腎功能（eGFR + 尿液 ACR）、眼底檢查、足部神經病變（10-g monofilament）、牙科
  • 轉介時機：HbA1c 持續 >8% 難以控制；eGFR <30（腎臟科）；蛋白尿（腎臟科）；視網膜病變（眼科）；足部潰瘍（血管外科）

高血壓基層管理

  • 診斷：非同日兩次測量 SBP ≥140 或 DBP ≥90；居家血壓（HBPM）目標 <130/80
  • 生活型態優先（Stage 1 可試 3 個月）：DASH 飲食；鈉 <2.3 g/天；有氧運動 150 分/週；戒菸；限酒；體重控制
  • 一線藥物（四大類）：ACEi / ARB（DM / 蛋白尿首選）；CCB（老年人 / 黑人）；Thiazide diuretics；β-blocker（心衰竭 / 心絞痛時優先）
  • 難治性高血壓（Resistant HTN）：使用 ≥3 種藥物（含利尿劑）仍未達標 → 加 Spironolactone；排除白袍高血壓（ABPM）/ 繼發性原因（腎動脈狹窄 / 原醛 / 睡眠呼吸中止）

ASCVD 風險分層（決定 LDL 目標）

風險定義LDL 目標
極高風險確診 ASCVD（心肌梗塞 / 中風 / 周邊動脈疾病）；或 DM + 靶器官損傷<55 mg/dL（ESC）；<70 mg/dL（AHA）
高風險DM 無靶器官損傷；10 年 ASCVD 風險 >10%；重度高血壓；慢性腎病<70 mg/dL
中風險10 年風險 5-10%；多重危險因子<100 mg/dL
低風險10 年風險 <5%<116 mg/dL

降血脂藥物

  • Statin（首選）：高強度（Atorvastatin 40-80 mg / Rosuvastatin 20-40 mg）= ASCVD 或極高風險；中強度（其他劑量）= 一般預防；副作用：肌肉病變（CK 監測）；肝毒性（轉氨酶）
  • Ezetimibe（腸道吸收抑制劑）：Statin 基礎上 LDL 未達標；加用可再降 15-20%
  • PCSK9 抑制劑（Evolocumab / Alirocumab）：極高風險 Statin + Ezetimibe 仍未達標；注射型；降 LDL 50-60%；台灣健保部分給付
  • Fibrate：主要降三酸甘油脂（TG）；TG >500 mg/dL → 急性胰臟炎風險 → 優先使用

代謝症候群（台灣標準）

  • 符合以下 3 項以上：腰圍（男 >90 cm；女 >80 cm）；TG ≥150 mg/dL；HDL-C（男 <40；女 <50 mg/dL）；血壓 ≥130/85 mmHg；空腹血糖 ≥100 mg/dL
  • 治療：生活型態改變為主；個別危險因子處置；代謝症候群本身不需藥物
生活型態介入 Lifestyle Intervention（戒菸 + 戒酒 + 肥胖）
生活型態介入是預防醫學的核心，也是家醫科的日常。戒菸是單一最有效的健康介入；5A 模型是結構化戒菸諮詢的標準框架。酒精使用障礙常被漏診，CAGE / AUDIT 是篩查工具。肥胖在台灣以 BMI ≥27 定義，GLP-1 受體促效劑已改變肥胖治療格局。
用藥指引
戒菸介入（5A + 藥物）

5A 戒菸諮詢框架

  • Ask（詢問）：每次門診詢問吸菸狀況；記錄於病歷
  • Advise（建議）：明確、強烈建議戒菸（「最重要的健康改變」）；30 秒即有效
  • Assess（評估）：評估戒菸意願；Prochaska 改變階段（前思考 / 思考 / 準備 / 行動 / 維持）
  • Assist（協助）：設定戒菸日期；處方戒菸藥物；提供資源（戒菸專線 0800-636363）
  • Arrange（追蹤）：1 週後回診；持續支持；預防復發

戒菸藥物

藥物機轉療程重點
Varenicline（Champix）部分 α4β2 nAChR 促效劑；↓ 戒斷症狀 + ↓ 吸菸滿足感12 週（可延長）最有效單一藥物（戒菸率 ~33%）；噁心（飯後服）；精神科症狀監測；台灣健保給付
Bupropion（Wellbutrin SR）多巴胺 / 正腎上腺素再回收抑制；↓ 尼古丁渴望7-12 週戒菸率 ~24%；有抗憂鬱效果；癲癇 / 飲食障礙禁忌；台灣健保給付
尼古丁替代療法（NRT）尼古丁貼片 / 口嚼錠 / 噴劑；緩慢補充尼古丁8-12 週最安全；可在懷孕期間考慮；組合療法（貼片 + 即時型）效果更好
  • 台灣戒菸補助：健保給付 Varenicline + Bupropion（每年 2 療程）+ NRT；戒菸門診 + 電話諮詢
  • 電子菸（ENDS）：尼古丁成癮風險；台灣禁止銷售但廣泛使用；不建議作為戒菸工具（FDA 未核准）
用藥指引
酒精使用障礙（CAGE / AUDIT）+ 肥胖

酒精使用障礙篩查

  • CAGE（4 題，≥2 陽性 = 高風險）：
    • C — Cut down：曾想要減少飲酒？
    • A — Annoyed：被批評飲酒而惱怒？
    • G — Guilty：對飲酒感到罪惡？
    • E — Eye-opener：早晨需要飲酒提神？
  • AUDIT（10 題）：≥8 分 = 有害飲酒；≥16 = 酒精依賴；更完整的量化評估
  • 安全飲酒量：男性 ≤2 標準杯/天；女性 ≤1 標準杯/天（1 標準杯 = 約 14 g 酒精）；無安全量（癌症風險）
  • 酒精戒斷處置：Benzodiazepine（Diazepam / Lorazepam）= 預防戒斷性癲癇；Thiamine 100 mg IM 或 IV（預防 Wernicke encephalopathy，優先於葡萄糖）；CIWA-Ar 量表監測
  • 維持戒酒：Naltrexone（↓ 飲酒渴望）；Acamprosate（↓ 戒斷症狀）；Disulfiram（飲酒後不適反應，依從性差）；戒酒無名會（AA）

肥胖管理（台灣標準：BMI ≥27）

  • 台灣定義：過重 BMI 24-27；肥胖 BMI ≥27；腰圍（男 >90 cm；女 >80 cm）= 中央型肥胖
  • 藥物治療適應症（台灣）：BMI ≥30；或 BMI ≥27 合併合併症（DM / HTN / 高血脂 / 睡眠呼吸中止）
  • GLP-1 受體促效劑：Semaglutide（Ozempic / Wegovy）= 最有效；平均減重 15-17%；同時改善心血管預後（SELECT trial）；副作用：噁心嘔吐；胰臟炎（罕見）；甲狀腺 C 細胞腫瘤（動物，人類不確定）
  • Tirzepatide（GIP/GLP-1 雙重促效劑）：減重 20-22%（SURMOUNT trial）；目前台灣仍以 DM 適應症為主
  • 手術（Bariatric surgery）：BMI ≥37.5；或 BMI ≥32.5 合併 DM / HTN；Sleeve gastrectomy / RYGB；可緩解 DM（~70%）
老年醫學 Geriatric Medicine（衰弱症 + 跌倒 + 多重用藥）
台灣 2025 年正式進入超高齡社會（65 歲以上 >20%）。老年醫學的核心概念是老年症候群（Geriatric syndromes）——跌倒、失智、衰弱、失禁、譫妄，這些問題相互交織且不能用單一疾病模型解釋。多重用藥（Polypharmacy）是老年病人最常見的問題之一，Beers list 是識別潛在不適當用藥（PIM）的工具。
判斷框架
衰弱症（Frailty）+ 跌倒評估

衰弱症（Frailty）— Fried Phenotype

  • 符合以下 3 項以上 = 衰弱；1-2 項 = 衰弱前期
  • 體重減輕：過去一年非刻意減重 >4.5 kg 或 >5%
  • 握力下降：握力計測量低於性別 / BMI 校正下限
  • 疲憊感：CES-D 問卷「幾乎每天感到疲憊」
  • 步行速度慢：4 公尺步行 >6 秒（男）/ >7 秒（女）
  • 低活動量：每週消耗熱量低於標準（MLTA 問卷）
  • 快速篩查（FRAIL scale）：Fatigue / Resistance / Aerobic / Illnesses ≥5 / Loss of weight；≥3 = 衰弱
  • 介入：阻力運動（最有效）；蛋白質補充（1.2-1.5 g/kg/天）；維生素 D；多學科評估

跌倒評估 + 預防

  • 高風險：過去一年跌倒 ≥2 次；或跌倒合併受傷；或步態 / 平衡問題
  • Timed Up and Go（TUG）test：>12 秒 = 高跌倒風險；從椅子站起 + 走 3 m + 回坐
  • 跌倒原因評估（4D）：Drugs（藥物）；Disease（疾病）；Delirium（譫妄）；Dysfunction（功能）
  • 高風險藥物：Benzodiazepine；Opioid；抗組織胺；α-blocker；降血壓藥（直立性低血壓）
  • 預防介入：運動（太極拳高等級證據）；視力矯正；環境改造（浴室扶手、防滑墊）；維生素 D（>800 IU/天）；骨質疏鬆治療；檢視藥物

多重用藥（Polypharmacy）+ Beers List

多重用藥評估

  • 定義：同時使用 ≥5 種藥物（Polypharmacy）；≥10 種（Hyperpolypharmacy）
  • 問題：藥物交互作用；副作用累積；依從性↓；跌倒風險↑；認知功能↓
  • Medication reconciliation（用藥調和）：每次入院 / 出院必做；核對所有藥物（含 OTC + 健康食品）
  • 去藥物化（Deprescribing）：定期檢視每種藥物是否仍有適應症；從最不必要的開始停；緩慢減量（避免戒斷）

Beers List 重點（AGS 2023，老年人潛在不適當用藥）

藥物類別風險替代方案
第一代抗組織胺（Diphenhydramine / Chlorpheniramine）抗膽鹼效應 → 譫妄、便秘、尿滯留、跌倒第二代（Loratadine / Cetirizine）
Benzodiazepine（所有）跌倒、骨折、認知障礙、依賴；老年人代謝慢認知行為治療（失眠）；Melatonin
Z-drugs（Zolpidem / Eszopiclone）同 Benzodiazepine；夢遊睡眠衛生；CBT-I
NSAIDs（口服）GI 出血；腎功能惡化；心血管風險；體液滯留Acetaminophen；局部 NSAIDs；Tramadol（謹慎）

安寧緩和 Palliative Care（預立醫療 + 症狀控制）
台灣病人自主權利法（2019）是亞洲首部以病人為主體的自主權利法，讓民眾可以預先設定拒絕醫療的意願。安寧緩和不等於放棄治療，而是以症狀控制和生活品質為核心的整合性照護。
判斷框架
預立醫療（ACP）+ 台灣法律框架

台灣相關法規

法規重點
安寧緩和醫療條例（2000）末期病人可簽署 DNR（不施行心肺復甦術）；需兩位醫師診斷末期；意識清楚本人簽署或委任代理人
病人自主權利法（2019）預立醫療決定（AD）= 事先選擇接受或拒絕維生醫療；需預立醫療照護諮商（ACP）+ 公證 / 2 位見證人；適用 5 種臨床條件（末期 / 不可逆昏迷 / 永久植物人 / 極重度失智 / 其他中央主管機關公告）

DNR vs 預立醫療決定（AD）差異

  • DNR：針對末期病人；限心肺復甦術；需醫師診斷末期才生效
  • 預立醫療決定（AD）：健康成人即可簽署；涵蓋更廣（維生醫療 + 人工營養）；5 種臨床條件下生效
  • ACP 諮商流程：醫療機構執行；本人 + 二親等 + 醫療委任代理人；說明病情預後和醫療選項；記錄於健保 IC 卡

安寧緩和照護對象

  • 台灣健保安寧給付：癌症末期；8 大非癌末期（心衰竭 / COPD / 慢性腎衰竭 / 慢性肝病 / 腦血管病變 / 神經退化疾病 / 老年期失智 / HIV）
  • SPICT（支持性和緩和照護指標工具）：功能下降 + 疾病進展指標 → 識別需要安寧的患者；Surprise Question（「如果這個患者在一年內死亡，你會驚訝嗎？」= 不驚訝 → 考慮安寧）
用藥指引
末期症狀控制（疼痛 + 呼吸困難 + 噁心）

疼痛控制（WHO 三階梯）

  • 第一階（輕度）：Acetaminophen ± NSAIDs；定時給藥（ATC）而非按需
  • 第二階（中度）：弱效 Opioid（Tramadol / Codeine）± 非 Opioid
  • 第三階（重度）：強效 Opioid（Morphine / Oxycodone / Fentanyl）± 非 Opioid；無天花板劑量
  • Morphine 使用原則：口服優先；定時 + PRN（突破性疼痛 = 每日量的 10-15%）；預防便秘（必給緩瀉劑）；滴定原則（每 24-48 小時增加 25-50%）
  • Opioid 副作用：便秘（幾乎必發，不耐受）；噁心（前 1-2 週）；嗜睡；呼吸抑制（過量時）→ Naloxone
  • 輔助止痛（Adjuvants）：神經病變痛 → Gabapentin / Amitriptyline；骨轉移 → NSAIDs + Bisphosphonate + 放療；腦壓高 → Dexamethasone

基層心理衛生 Primary Mental Health（憂鬱 + 焦慮 + 轉介）
台灣基層醫療是心理衛生的第一線，80% 以上的憂鬱症患者首先就診於非精神科。PHQ-9 和 GAD-7 是家醫科最實用的篩查工具。家醫科醫師需要識別、初步處置，並知道何時轉介精神科。
數值判讀
憂鬱（PHQ-9）+ 焦慮（GAD-7）篩查

PHQ-9（過去兩週頻率，0-3 分 × 9 題）

  • 快篩（PHQ-2）：①情緒低落；②對事物失去興趣 → 任一 >0 = 進行 PHQ-9
  • PHQ-9 判讀：1-4 = 最低限度；5-9 = 輕度；10-14 = 中度；15-19 = 中重度；20-27 = 重度
  • 功能損害問題（第 10 題）：症狀對工作 / 日常生活的影響程度 → 決定是否需要治療
  • 自殺評估：PHQ-9 第 9 題（想死或自傷）= 任何分數都需進一步評估

GAD-7（廣泛性焦慮量表）

  • 判讀：5-9 = 輕度；10-14 = 中度；≥15 = 重度
  • ≥10 分：敏感度 89%、特異度 82% 診斷 GAD
  • 其他焦慮障礙：恐慌症（突發性、身體症狀 + 死亡恐懼）；社交焦慮；特定恐懼症；PTSD（創傷史 + 過度警覺 + 再體驗 + 逃避）

排除身體疾病（繼發性憂鬱 / 焦慮）

  • 甲狀腺功能（甲亢 / 甲低）；貧血；糖尿病；睡眠呼吸中止；腎上腺功能；藥物副作用（Beta-blocker / 類固醇 / Interferon）
用藥指引
基層心理治療 + 轉介精神科標準

輕中度憂鬱處置（家醫科可處理）

  • 輕度（PHQ-9 5-9）：心理衛生教育；生活型態介入（運動最有效）；問題解決治療；2-4 週追蹤；可暫不用藥
  • 中度（PHQ-9 10-14）：藥物 + 心理治療（CBT）= 最有效組合
  • SSRI（一線）：Sertraline / Escitalopram（副作用少，首選）；起效 2-4 週；至少用藥 6-9 個月（初次發作）；停藥需緩慢減量
  • SNRI：Duloxetine（合併疼痛）；Venlafaxine（高劑量 → 血壓↑）
  • Mirtazapine：失眠 + 食慾差 + 憂鬱（鎮靜效果；體重增加）

轉介精神科時機

  • 有自殺意念或自傷行為（立刻）
  • 重度憂鬱（PHQ-9 ≥15）；精神病性症狀（幻覺 / 妄想）
  • 雙極性障礙疑似（躁狂病史 / 家族史）= SSRI 可能誘發躁狂
  • 藥物治療 2 個月無效 / 難治性（Treatment-resistant depression）
  • 物質使用合併（酒精 / 毒品）
  • 嚴重功能損害無法工作 / 照顧自己
