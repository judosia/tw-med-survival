耳鼻喉科

耳科、鼻科、咽喉與頸部腫塊評估，涵蓋急診常見 ENT 急症處置與臨床鑑別診斷。

耳鼻喉評估基礎 ENT Assessment
ENT 評估的三大工具：音叉試驗（Weber + Rinne）快速鑑別傳導性 vs 感音性聽損；耳鏡評估耳道和鼓膜；鼻腔/咽喉視診。傳導性聽損（Conductive hearing loss，CHL）= 外耳/中耳問題；感音神經性聽損（Sensorineural hearing loss，SNHL）= 內耳/第八對腦神經問題。
判斷框架
Weber + Rinne 音叉試驗（512 Hz）

Rinne Test（單耳）

  • 操作：音叉置於乳突（骨導）→ 聲音消失後移至外耳道口（氣導）
  • 正常 / SNHL：氣導 > 骨導（AC > BC）= Rinne 陽性（+）
  • CHL：骨導 > 氣導（BC > AC）= Rinne 陰性（-）

Weber Test（雙耳比較）

  • 操作：音叉置於頭頂正中（或額頭）→ 問患者聲音偏哪側
  • 正常：居中（兩耳相等）
  • CHL（單側）：聲音偏向患側（患耳骨導相對↑）
  • SNHL（單側）：聲音偏向健側（患耳感音↓）

整合判讀

情況Rinne（患側）Weber 偏向
正常（+）AC > BC居中
單側 CHL（左耳）左側（-）BC > AC左側（患側）
單側 SNHL（左耳）左側（+）AC > BC（但音量↓）右側（健側）
雙側對稱性 SNHL雙側（+）居中
判斷框架
耳鏡 + 鼻腔 + 咽喉視診重點

耳鏡（Otoscope）評估

正常鼓膜異常發現考慮診斷
珍珠灰色；半透明；光錐（light reflex）明顯；錘骨柄可見紅色 + 膨出 + 光錐消失急性中耳炎（AOM）
鼓膜後方積液（氣泡/液面）；鼓膜內陷滲出性中耳炎（OME）
鼓膜穿孔（中央型 / 邊緣型）慢性中耳炎；外傷
白色角化斑塊（上鼓室或後上方）膽脂瘤（Cholesteatoma）
外耳道紅腫 + 壓耳屏痛外耳道炎（Swimmer's ear）

鼻腔視診重點

  • 鼻中隔偏曲：單側鼻塞；常合併習慣性鼻出血
  • 鼻息肉（Polyp）：蒼白水腫的半透明腫塊；不痛；常合併過敏性鼻炎/慢性鼻竇炎；單側息肉要排除腫瘤
  • 黏膜顏色：蒼白水腫 = 過敏；鮮紅充血 = 感染性；蒼白乾燥 = 萎縮性鼻炎
  • 鼻出血來源：前鼻腔（Little's area，Kiesselbach plexus）= 最常見；後鼻腔 = 老年人多，出血較難控制

咽喉視診重點

  • 扁桃腺分級（Friedman 分級）：Grade I（扁桃腺窩內）→ Grade IV（超過中線）；Grade III-IV 合併打鼾 → 評估 OSA
  • 懸雍垂偏移：扁桃腺周圍膿瘍（Peritonsillar abscess）→ 懸雍垂偏向健側；口腔張開困難（Trismus）
  • 喉部視診（喉頭鏡）：聲帶活動度；聲帶結節 / 息肉（Reinke's edema）；喉癌（白色不規則增生）
耳科 Otology（外耳炎 + 中耳炎 + 突發性聽損）
耳科最常見急症：急性中耳炎（AOM）是兒童最常見的細菌感染，首選 Amoxicillin；突發性聽損（SSNHL）是耳科急症，72 小時內類固醇治療預後較好。惡性外耳道炎（Malignant OE）= 糖尿病/免疫缺陷患者的危險性外耳炎，可侵犯顱底。
用藥指引
外耳道炎 + 中耳炎

外耳道炎（Otitis Externa，OE）

類型病原特徵治療
急性外耳道炎（Swimmer's ear） P. aeruginosa（最常見）；S. aureus 耳道紅腫痛；壓耳屏（Tragus）或拉耳廓時疼痛加劇（鑑別中耳炎）；耳道分泌物；聽力可正常 外用 Ciprofloxacin + Hydrocortisone 耳滴劑（首選）；保持耳道乾燥；嚴重 → 抗生素填充（Wick）再滴藥
惡性外耳道炎（Malignant / Necrotizing OE） P. aeruginosa 糖尿病/免疫缺陷患者；外耳道底部肉芽組織；顱底骨髓炎風險（面神經麻痺！）；ESR ↑；CT/MRI 評估侵犯範圍 靜脈 Ciprofloxacin 或 Pip/Tazo × 6-8 週；外科清創（嚴重）；血糖控制

中耳炎（Otitis Media）

類型特徵治療
急性中耳炎（AOM） 兒童最常見細菌感染；<2 歲最高風險；病原：S. pneumoniae（最常見）、H. influenzae、M. catarrhalis；鼓膜充血膨出、光錐消失、耳痛、發燒；拉耳廓不會加劇疼痛（區別 OE） ≥2 歲輕度單側：觀察 48-72 小時（可 watchful waiting）
抗生素適應症：<2 歲；雙側；嚴重症狀；穿孔；免疫缺陷
Amoxicillin 80-90 mg/kg/天 × 5-10 天（首選）；失敗 → Amoxicillin-clavulanate；青黴素過敏 → Cefdinir / Azithromycin
滲出性中耳炎（OME，分泌性） 鼓膜後積液（無發炎症狀）；鼓膜內陷 / 淡黃色 / 氣泡；傳導性聽損；兒童常見（腺樣體肥大壓迫耳咽管）；多自限（3 個月內） 觀察（3 個月）；持續 → 耳管（Ventilation tube，PE tube）置入；腺樣體切除（復發性）；不建議常規使用抗生素或類固醇
膽脂瘤（Cholesteatoma） 鱗狀上皮細胞在中耳異常增生；長期侵蝕骨頭（聽小骨、顏面神經管、顱底）；無痛性慢性流膿；傳導性聽損；耳鏡見白色角化物質（上鼓室或後上方） 手術切除（唯一治療）；不切除會持續侵蝕造成嚴重併發症（顏面神經麻痺、腦膜炎、腦膿瘍）
緊急處置
突發性聽損（SSNHL）+ 耳鳴 + 梅尼爾氏症
突發性聽損 = 耳科急症！72 小時內開始類固醇治療，預後較好。不要觀察等待。

突發性感音神經性聽損（SSNHL）

  • 定義：72 小時內發生的單側感音神經性聽損（≥3 個連續頻率，聽力下降 ≥30 dB）
  • 原因：多數不明（特發性）；病毒感染（HSV、CMV）；血管性；免疫性；腫瘤（聽神經瘤 Acoustic neuroma = Vestibular schwannoma）
  • 症狀：突然單側聽力下降；可合併耳鳴、耳悶脹感、輕微眩暈
  • 治療：口服 Prednisolone 1 mg/kg/天（最大 60 mg）× 10-14 天後漸減；鼓膜內類固醇注射（Intratympanic steroid）= 口服失敗或禁忌時替代；高壓氧治療（輔助）
  • MRI 檢查：排除聽神經瘤（Gadolinium 增強 MRI）
  • 預後：約 1/3 完全恢復；1/3 部分恢復；1/3 無改善；越早治療預後越好

梅尼爾氏症（Meniere's Disease）

  • 四聯症：反覆性眩暈（20 分鐘 - 12 小時）+ 單側感音神經性聽損 + 耳鳴 + 耳悶脹感
  • 病生理：內淋巴水腫（Endolymphatic hydrops）
  • 治療：急性發作 → 抗組織胺（Dimenhydrinate）/ Benzodiazepine；長期 → 低鹽飲食（<2 g/天）；利尿劑（Hydrochlorothiazide）；鼓膜內 Gentamicin 注射（破壞前庭功能）；難治性 → 迷路切除術

耳鳴（Tinnitus）分類

  • 主觀性（最常見）：只有患者聽得到；SNHL 合併耳鳴（老年性聽損、噪音性聽損）；聽神經瘤；Aspirin / Quinine / 胺基糖苷類抗生素（耳毒性）
  • 客觀性（罕見）：聽診器也聽得到；血管性搏動性耳鳴（動靜脈畸形、頸靜脈球瘤）；肌肉陣攣性
  • 治療：治療原因；耳鳴遮蔽（Masker）；認知行為治療（CBT）；聽力輔具（改善聽損）
鼻科 Rhinology（過敏性鼻炎 + 鼻竇炎 + 鼻出血）
過敏性鼻炎（Allergic Rhinitis）影響台灣 30% 以上人口，是最常見的鼻科疾病，第二代抗組織胺和鼻用類固醇是主力。急性細菌性鼻竇炎的關鍵：症狀 >10 天未改善，或改善後再惡化（double sickening），才需要抗生素。鼻出血處置先壓迫，後填塞。
用藥指引
過敏性鼻炎 + 急慢性鼻竇炎

過敏性鼻炎（Allergic Rhinitis）

  • 症狀：打噴嚏（陣發性）+ 水狀鼻涕 + 鼻塞 + 眼睛癢（過敏三聯症合併）；鼻黏膜蒼白水腫；Allergic salute（鼻子向上摩擦）；Allergic shiner（黑眼圈）；Dennie-Morgan lines（眼眶下皺摺）
  • 分類：間歇性（<4 天/週 or <4 週）vs 持續性（>4 天/週 and >4 週）；輕度 vs 中重度（影響睡眠 / 日常活動）
治療藥物效果
鼻用類固醇（最有效）Fluticasone / Mometasone / Budesonide 鼻噴劑最有效；對鼻塞效果最好；每天規律使用；副作用少（局部）
第二代口服抗組織胺Cetirizine / Loratadine / Fexofenadine對噴嚏/鼻涕/眼癢效果好；鼻塞效果較差；不嗜睡（第二代）
口服抗組織胺 + 鼻用類固醇合用中重度首選；協同效果
Montelukast（Leukotriene 拮抗劑）每晚口服合併氣喘時加用；效果次於鼻用類固醇
免疫治療（減敏）皮下注射 or 舌下滴劑唯一改變疾病自然病程的治療；需 3-5 年

急性細菌性鼻竇炎（ABRS）

  • 診斷標準（IDSA 指引）：症狀持續 ≥10 天未改善；或症狀嚴重（高燒 >39°C + 膿性鼻涕 + 顏面疼痛 ≥3-4 天）；或 double sickening（改善後 5-6 天再惡化）
  • 最常見病原：S. pneumoniae；H. influenzae；M. catarrhalis
  • 治療：Amoxicillin-clavulanate（首選，含抗 beta-lactamase）× 5-7 天；過敏 → Doxycycline 或 Levofloxacin；輔助：鼻腔沖洗（Nasal irrigation）；鼻用類固醇；鼻腔減充血劑（短期，<3-5 天避免藥物性鼻炎）
  • 大多數急性鼻竇炎是病毒性（感冒後），不需抗生素！10 天才是細菌性的分界

慢性鼻竇炎（CRS，>12 週）

  • CRS with polyps（CRSwNP）：雙側鼻息肉；嗅覺喪失；常合併氣喘 + Aspirin 不耐受（Samter's triad）；Dupilumab（IL-4/13 抑制劑）= 嚴重型生物製劑
  • 治療：鼻用類固醇 + 鼻腔沖洗；息肉 → 口服類固醇短療程；手術（FESS，功能性內視鏡鼻竇手術）；復發常見

鼻出血（Epistaxis）處置流程

鼻出血部位分類

前鼻腔出血（80-90%）後鼻腔出血（10-20%）
來源Kiesselbach's plexus（Little's area，鼻中隔前下方）Woodruff's plexus（鼻腔後部）
好發兒童；乾燥；挖鼻老年人；高血壓；抗凝血藥物；動脈硬化
嚴重度通常不嚴重；可自止出血量較多；較難控制；容易後流

處置流程（Step by step）

  • Step 1：直接壓迫（First line）
    • 頭部前傾（不要後仰！後仰讓血流入咽部）
    • 捏住鼻翼軟骨部（鼻中隔前下方）持續 10-15 分鐘
    • 張口呼吸；冰敷鼻樑（輔助）
  • Step 2：局部處理（壓迫失敗）
    • 局部麻醉（Lidocaine spray）+ 血管收縮劑（Oxymetazoline 噴劑）
    • 前鼻腔視診確認出血點
    • 化學燒灼（Silver nitrate 棉棒 or 電燒）= 可見出血點的首選
  • Step 3：前鼻腔填塞（Anterior packing）
    • 凡士林紗布（Ribbon gauze）或 Merocel（膨脹海綿）填塞；維持 24-48 小時
    • 填塞後預防性抗生素爭議（預防中毒休克症候群 TSS）
  • Step 4：後鼻腔填塞 / 手術（前填塞失敗）
    • 後鼻腔填塞（Foley catheter balloon）或 Posterior packing；需住院監測（呼吸道風險）
    • 血管栓塞（Embolization）or 內視鏡蝶口竇動脈結紮（難治性）

鼻出血的系統性評估

  • 血壓（高血壓 = 常見加重因素，但非直接原因）；CBC；凝血功能；抗凝血藥物使用
  • 出血性疾病：血小板低下；血友病；von Willebrand disease；Hereditary Hemorrhagic Telangiectasia（HHT = Osler-Weber-Rendu，多發性 AVM）
  • 反覆單側鼻出血 + 鼻塞 → 排除腫瘤（nasopharyngeal angiofibroma 或 NPC）
咽喉 Pharynx & Larynx（扁桃腺炎 + 會厭炎 + 聲音嘶啞）
咽喉急症中最危險的是急性會厭炎（Acute Epiglottitis）——成人比兒童更常見（Hib 疫苗普及後），千萬不要直接看喉嚨（可能誘發完全阻塞），直接到 OR 在麻醉下評估和插管。扁桃腺周圍膿瘍（Peritonsillar abscess，PTA）= 最常見的咽喉深層感染。
用藥指引
扁桃腺炎 + 扁桃腺周圍膿瘍（PTA）

急性扁桃腺炎（Acute Tonsillitis）

  • 病原：病毒（Adenovirus、EBV = Mono）= 最常見（70-80%）；細菌（GAS = Group A Streptococcus）
  • GAS 篩查（Centor criteria）：扁桃腺滲出物 + 頸前淋巴腺腫大 + 發燒 + 無咳嗽 = 4 分；分數高 → Rapid Strep test 或咽拭子培養
  • 治療（GAS）：Penicillin V 或 Amoxicillin × 10 天（預防風濕性心臟病）；過敏 → Azithromycin；勿用 Ampicillin 或 Amoxicillin 若懷疑 EBV（→ 全身皮疹，maculopapular）
  • EBV（傳染性單核球增多症 Mono）：咽喉炎 + 全身淋巴腺腫 + 脾腫大 + 異形淋巴球 + Monospot test 陽性；避免接觸運動（脾破裂風險）；支持性治療

扁桃腺周圍膿瘍（Peritonsillar Abscess，PTA）

  • 最常見的咽喉深層感染；GAS 為主 + 厭氧菌（Fusobacterium）混合感染
  • 臨床：嚴重喉嚨痛（單側）；Trismus（牙關緊閉，張嘴困難）；吞嚥困難；說話「Hot potato voice」（口含熱馬鈴薯樣的含糊音）；懸雍垂偏向健側；同側扁桃腺膨出
  • 治療：
    • 引流（首選）：針吸（Needle aspiration）或切開引流（I&D）
    • 抗生素：Amoxicillin-clavulanate；或 Penicillin + Metronidazole（涵蓋厭氧菌）
    • 類固醇（Dexamethasone 10 mg IV）：↓ 水腫、改善張口、加速恢復
    • 復發性 PTA → 扁桃腺切除術
緊急處置
急性會厭炎 + 聲音嘶啞鑑別
急性會厭炎 → 不要用壓舌板檢查喉嚨！不要做咽拭子！直接到手術室在麻醉下處置。

急性會厭炎（Acute Epiglottitis）

  • 病原：H. influenzae type b（兒童，Hib 疫苗後減少）；GAS、S. aureus、S. pneumoniae（成人）；成人現比兒童多見
  • 臨床三 D：Dysphagia（吞嚥困難）+ Dysphonia（聲音改變）+ Drooling（流口水）；高燒；坐前傾（Tripod position）；吸氣性喘鳴；恐懼外觀
  • X 光（頸部側位）：「拇指徵（Thumbprint sign）」= 會厭腫大如拇指；正常會厭纖細（Vallecula sign）
  • 處置：
    • 最小刺激原則（不要激惹患者）
    • 準備插管（困難氣道！）+ 環甲膜切開術備用
    • 到 OR 由麻醉科 / ENT 在安全環境下處置氣道
    • Ceftriaxone IV（H. influenzae）；Vancomycin（MRSA 懷疑）

聲音嘶啞（Hoarseness）鑑別

原因特徵處置
急性喉炎（Laryngitis）病毒感染後；聲音粗啞 / 失聲；咳嗽；低燒；自限 1-2 週聲音休息；蒸氣吸入；避免耳語（反而傷聲帶）
聲帶結節（Vocal cord nodule）長期聲音過度使用（歌手、老師）；雙側對稱性結節（中三分之一交界）；漸進性沙啞聲音治療；手術切除（頑固性）
聲帶息肉（Polyp）單側；急性創傷性（大喊）或慢性（菸、胃食道逆流）；Reinke's edema（全段水腫）= 長期吸菸女性手術切除；戒菸；抗逆流治療
聲帶麻痺（Vocal cord palsy）喉返神經損傷（手術、腫瘤壓迫）；單側 = 聲音沙啞；雙側 = 呼吸困難；左側較右側多（左喉返神經繞主動脈弓）找原因（CXR / CT 頸部胸部）；語言治療；注射填充（單側）；氣切（雙側嚴重）
喉癌（Laryngeal Cancer）>2 週持續聲音嘶啞 + 抽菸 / 飲酒；喉鏡下不規則白色增生；SCC 最常見喉鏡 + 切片；手術 / 放療 / 化療
胃食道逆流（GERD）晨起聲音沙啞；咽喉清嗓；喉嚨感黏液；後喉壁發紅PPI；飲食調整；床頭抬高
頸部腫塊鑑別 Neck Mass Differential Diagnosis
頸部腫塊的鑑別依年齡、位置、病程三大要素分析。臨床口訣：<20 歲多良性（炎症/先天性）；20-40 歲多良性腫瘤；>40 歲持續性腫塊 = 惡性直到排除為止。成人持續 >2 週的無痛性頸部腫塊 = 惡性淋巴結轉移，直到切片排除。

惡性頸部腫塊評估（成人 >40 歲）

  • 轉移性淋巴結：無痛；硬；固定；>1 cm 且持續 >2 週 → 強烈懷疑惡性
  • 鼻咽癌（NPC）：無痛性頸部腫塊（最常見表現）+ 鼻塞 + 鼻出血 + 耳鳴 + 聽力下降；Epstein-Barr Virus（EBV）相關；東南亞（台灣、廣東）好發；鼻咽視診 + EBV 抗體 + 切片
  • 淋巴瘤：無痛性橡皮狀頸部腫塊；B 症狀（發燒、盜汗、體重下降 >10%）；CT + PET + 淋巴結切片（不做 FNA）
  • 評估流程：超音波（大小、特性）→ CT（範圍）→ FNA（細胞學）→ 切片（組織學）；先找原發灶（鼻咽 / 口咽 / 喉 / 下咽 / 甲狀腺）
ENT 急症 ENT Emergencies
ENT 急症以氣道急症最危險——任何引起上呼吸道阻塞的 ENT 問題都可能致命。異物在兒童極為常見（耳、鼻、咽喉/食道），處置原則依位置而不同。顳骨骨折需評估面神經功能和腦脊液漏。

深頸部感染（Deep Neck Space Infection）

  • Ludwig's Angina：下頜下 / 頦下 / 舌下間隙雙側蜂窩性組織炎；牙源性感染（80%）；舌頭向上向後推擠 → 氣道阻塞；板狀頸部；氣道管理優先（清醒纖維光束插管）+ Pip/Tazo IV
  • 咽旁間隙膿瘍（Parapharyngeal Abscess）：牙源性 or 扁桃腺炎後；頸部腫脹 + 吞嚥困難；CT 確認範圍 → 手術引流 + 抗生素
  • 咽後間隙膿瘍（Retropharyngeal Abscess）：兒童 (<5 歲) 多見；頸部淋巴結（咽後）化膿；頸部僵硬 / 伸展受限；X 光 = 咽後壁增寬；CT 確認 → 手術引流 + Ceftriaxone + Metronidazole
  • Lemierre Syndrome：咽喉感染（扁桃腺炎）→ 頸內靜脈血栓形成 → 化膿性栓塞（肺、關節）；Fusobacterium necrophorum；青年人；抗生素（Pip/Tazo + Metronidazole）；抗凝血爭議
