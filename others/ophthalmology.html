眼科

眼科評估、青光眼、視網膜疾病、眼科急症與神經眼科，涵蓋各科 PGY 必備的眼科臨床知識。

眼科評估基礎 Ophthalmic Assessment（視力 + 裂隙燈 + 眼壓）
眼科評估的系統性順序：視力（VA）→ 瞳孔反應 → 眼球運動 → 視野 → 眼壓（IOP）→ 裂隙燈（前節）→ 眼底鏡（後節）。非眼科醫師最重要的技能是辨識需要緊急眼科會診的情況：急性視力喪失、急性眼痛合併充血、眼外傷。
數值判讀
視力評估 + 瞳孔反應 + 視野

視力（Visual Acuity）

  • Snellen chart：6/6（台灣）= 20/20（美國）= 正常；6/60 = 只能看到正常人在 60 m 看到的字；數手指（CF）→ 手動（HM）→ 光感（LP）→ 無光感（NLP）
  • 針孔測試（Pinhole test）：視力改善 → 屈光問題（近視/散光）；視力不改善 → 眼球本身病變（角膜/水晶體/視網膜/視神經）
  • 法定失明（Legal blindness）：較好眼矯正視力 <6/60（20/200）或視野 <20°

瞳孔檢查

  • 直接對光反射（Direct）：光照右眼 → 右眼縮小
  • 間接對光反射（Consensual）：光照右眼 → 左眼也縮小
  • RAPD（Relative Afferent Pupillary Defect）= Marcus Gunn 瞳孔：搖擺手電筒測試（Swinging flashlight test）；患側眼照光時兩眼反而散大 → 患側視神經 / 視網膜嚴重病變；RAPD（+）= 重要的客觀視神經損傷指標
  • Horner syndrome：患側縮瞳（Miosis）+ 上眼瞼下垂（Ptosis）+ 下眼瞼上提 + 無汗；交感神經受損；需排除頸動脈剝離 / Pancoast 腫瘤
  • CN III 麻痺：散瞳（Mydriasis）+ 完全上眼瞼下垂 + 眼球下外偏；後交通動脈瘤 → 緊急 CTA

視野（Visual Field）缺損定位

缺損類型病灶位置
單眼全盲視神經（視交叉前）
雙顳側偏盲（Bitemporal hemianopia）視交叉（如垂體瘤壓迫）
同側偏盲（Homonymous hemianopia）視交叉後（視放射 / 枕葉）
象限盲（Quadrantanopia）視放射（顳葉上方 → 下象限；頂葉 → 上象限）
中心暗點（Central scotoma）黃斑部病變 / 視神經炎
數值判讀
眼壓（IOP）+ 裂隙燈 + 眼底檢查

眼壓（Intraocular Pressure，IOP）

  • 正常：10-21 mmHg；平均 15 mmHg
  • ≥22 mmHg：高眼壓（Ocular hypertension）；青光眼風險↑
  • 急性閉角型青光眼：IOP 常 >40-50 mmHg；眼球硬如石頭
  • 眼球破裂（Globe rupture）：IOP 極低（軟眼）；禁止壓迫量測
  • 量測方法：Goldmann applanation tonometry（金標準）；Non-contact tonometry（氣流，篩查用）；Tono-Pen（急診，可臥床）

裂隙燈（Slit-lamp）前節評估

結構評估重點
結膜充血（睫狀充血 vs 結膜充血）；乳突；濾泡；分泌物
角膜透明度；Fluorescein 染色（上皮缺損）；Keratic precipitates（KP）= 葡萄膜炎；Seidel test（房水滲漏）
前房（AC）深度（淺前房 = 閉角型青光眼風險）；Flare & Cell（葡萄膜炎）；Hyphema（積血）；Hypopyon（積膿）
虹膜後粘連（Posterior synechiae）；新生血管（Rubeosis iridis）= 糖尿病 / CRVO
水晶體混濁程度（白內障）；位置（脫位）

眼底（Fundus）重要所見

  • 視神經乳頭（Optic disc）：C/D ratio（正常 <0.5）；Cupping（青光眼）；Papilledema（顱壓升高）= 邊緣模糊 + 靜脈怒張
  • 視網膜血管：A/V ratio（正常 2/3）；AV nicking（高血壓）；銅線 / 銀線（高血壓動脈硬化）
  • 黃斑部（Macula）：Cherry-red spot = CRAO；Drusen = AMD；黃斑部水腫
  • 視網膜出血類型：點狀（Dot）= 深層；火焰狀（Flame）= 表層（視神經纖維層）；船形（Subhyaloid）= 玻璃體下
青光眼 Glaucoma（急性閉角型 + 原發性開角型）
急性閉角型青光眼（AACG）是眼科急症，數小時內可造成永久視力喪失，需立刻降眼壓。原發性開角型青光眼（POAG）是最常見的青光眼（佔 90%），無症狀緩慢進展，是全球第二大失明原因。兩者治療核心都是降低眼壓。
緊急處置
急性閉角型青光眼（AACG）
急性閉角型青光眼 → 立刻眼科會診！數小時內不降眼壓 → 永久視力喪失。

臨床表現

  • 症狀：突發劇烈眼痛 + 頭痛 + 噁心嘔吐（可誤診為偏頭痛或急腹症）；視力模糊；看燈光有彩虹光暈（Halos）
  • 誘發因素：暗室（瞳孔散大）；強烈情緒；散瞳劑；抗膽鹼藥物；抗組織胺
  • 危險族群：遠視眼（淺前房）；亞洲人；女性；年齡 >50
  • 眼部表現：IOP >40-50 mmHg；結膜睫狀充血；角膜水腫（霧狀）；瞳孔中度散大固定（約 4-6 mm）；淺前房

緊急處置（降眼壓）

  • Acetazolamide（Diamox）500 mg IV/PO：抑制碳酸酐酶 → ↓ 房水生成；立刻給
  • Timolol 0.5% 眼藥水：β-blocker；↓ 房水生成；每 30 分鐘一次 × 2 次
  • Pilocarpine 2% 眼藥水：縮瞳 → 拉開虹膜角 → 開放房角；IOP >50 時先降壓再用（太高時效果差）
  • Mannitol 1-2 g/kg IV：高滲透壓劑；迅速降低玻璃體體積；IOP 極高時使用
  • 止痛止吐：減輕症狀；降低迷走神經反射
  • 根本治療：雷射周邊虹膜切開術（Laser Peripheral Iridotomy，LPI）= 急性期控制後 / 預防性（對側眼）
用藥指引
原發性開角型青光眼（POAG）

診斷標準

  • 三要素：開放的前房角（Gonioscopy）+ 視神經損傷（C/D ratio 增大 / 視神經纖維層缺損）+ 視野缺損（弓形暗點、鼻側階梯）
  • IOP：多數 >21 mmHg，但正常眼壓性青光眼（NTG）IOP 正常也可有視神經損傷
  • 視野缺損（Humphrey 視野計）：弓形暗點（Arcuate scotoma）；鼻側階梯（Nasal step）；晚期管狀視野（Tunnel vision）

降眼壓藥物（眼藥水）

藥物機轉降壓效果注意事項
Prostaglandin analogues（Latanoprost / Travoprost）↑ 葡萄膜鞏膜房水外流最強（↓ 25-35%）一線首選；每日一次（睡前）；副作用：睫毛變長、虹膜色素沉著
β-blocker（Timolol）↓ 房水生成↓ 20-25%禁忌：氣喘、COPD、心搏過緩、心臟傳導阻滯
α2-agonist（Brimonidine）↓ 房水生成 + ↑ 外流↓ 20-25%可能有神經保護作用；嗜睡
碳酸酐酶抑制劑（Dorzolamide / Brinzolamide）↓ 房水生成↓ 15-20%局部用；磺胺藥過敏者禁用
縮瞳劑（Pilocarpine）↑ 小樑網外流↓ 20%現少用（視力模糊、頭痛）；閉角型有效
  • 雷射治療（SLT）：選擇性雷射小樑成形術；可作為一線治療或藥物輔助
  • 手術（Trabeculectomy）：藥物控制不佳；建立新的房水外流通道
  • 追蹤：視野（Humphrey）+ OCT（視神經纖維層）每 6-12 個月；IOP 目標通常降低 30% 以上
視網膜疾病 Retinal Diseases（糖尿病視網膜病變 + 黃斑部 + 視網膜剝離）
糖尿病視網膜病變（DR）是工作年齡成人失明的最常見原因；嚴格控制血糖和血壓是預防的關鍵。年齡相關黃斑部病變（AMD）是老年人失明的最常見原因；濕性 AMD 的抗 VEGF 注射是有效治療。視網膜剝離是眼科急症，需緊急手術。
數值判讀
糖尿病視網膜病變（DR）分期 + 黃斑部病變

DR 分期（ETDRS / 國際分類）

分期眼底所見處置
無 DR正常眼底每年追蹤；嚴格控制血糖 + 血壓
輕度非增殖性（NPDR）微血管瘤（Microaneurysm）每年追蹤；血糖 / 血壓控制
中度 NPDR出血點、硬性滲出、棉絮斑（Cotton-wool spots）每 6 個月追蹤
重度 NPDR（4-2-1 rule）4 象限出血 or 2 象限靜脈串珠 or 1 象限 IRMA每 3-4 個月；考慮雷射
增殖性 DR（PDR）新生血管（NVD / NVE）；玻璃體出血；牽引性視網膜剝離緊急眼科；全視網膜雷射（PRP）或玻璃體切除術
  • 糖尿病黃斑部水腫（DME）：任何分期均可發生；最常見視力下降原因；抗 VEGF 注射（Ranibizumab / Bevacizumab / Aflibercept）= 一線治療；雷射（Focal laser）= 輔助
  • 篩查建議：第一型 DM → 診斷後 5 年開始年度眼底檢查；第二型 DM → 診斷時立刻篩查；懷孕 DM → 孕前和孕期篩查

年齡相關黃斑部病變（AMD）

乾性 AMD（90%）濕性 AMD（10%）
特徵Drusen（玻璃疣）；地圖狀萎縮；緩慢進展脈絡膜新生血管（CNV）；急性視力下降；Amsler grid 扭曲
治療AREDS2 補充劑（維生素 C/E + Zinc + Lutein）= 中重度乾性 AMD；無治癒玻璃體內抗 VEGF 注射（Ranibizumab / Aflibercept）= 一線；每月注射
緊急處置
視網膜剝離 + 視網膜靜脈阻塞（CRVO/BRVO）

視網膜剝離（Retinal Detachment）

  • 類型：
    • 裂孔性（Rhegmatogenous，最常見）：視網膜破裂 → 玻璃體液進入 → 剝離；近視眼 / 外傷 / 老化
    • 牽引性（Tractional）：纖維膜牽拉（PDR / 外傷）
    • 滲出性（Exudative）：液體滲出（腫瘤 / 葡萄膜炎）
  • 前驅症狀：飛蚊症突然增加（玻璃體出血 / 視網膜撕裂）；閃光感（Photopsia）= 玻璃體牽拉視網膜
  • 視野缺損：「窗簾遮住視野」= 典型描述；從周邊向中央進展；黃斑部未剝離 → 中心視力尚存（緊急程度更高）
  • 治療：黃斑部未受累 → 緊急手術（24 小時內）；已受累 → 盡快手術；術式：鞏膜扣壓術（Scleral buckling）/ 氣體填充（Pneumatic retinopexy）/ 玻璃體切除術（PPV）

視網膜靜脈阻塞（CRVO / BRVO）

  • 危險因素：高血壓（最重要）；糖尿病；高血脂；青光眼；高凝狀態（年輕患者）
  • CRVO（中央靜脈阻塞）：「番茄醬眼底」= 4 象限大量火焰狀出血 + 視乳頭水腫；急性視力下降
  • BRVO（分支靜脈阻塞）：1 個象限出血；沿受累靜脈分布；視力下降（若累及黃斑）
  • 治療：黃斑部水腫 → 抗 VEGF 注射（一線）；新生血管性青光眼（Neovascular glaucoma）= 最嚴重併發症 → PRP 雷射
  • 全身評估：血壓、血糖、血脂、凝血功能（年輕患者 → 血栓篩查）
水晶體 + 角膜 Lens & Cornea（白內障 + 角膜炎 + 乾眼症）
白內障是全球失明的最常見原因（可治癒），手術是唯一有效治療。角膜炎需要區分感染性（細菌 / 病毒 / 真菌）和非感染性，細菌性角膜炎是角膜潰瘍最常見原因，需積極抗生素治療。乾眼症是門診最常見的眼科問題，台灣盛行率約 30%。
判斷框架
白內障（Cataract）+ 角膜炎

白內障

  • 危險因素：老化（最常見）；紫外線；類固醇（後囊下白內障）；糖尿病；外傷；先天性
  • 症狀：漸進性視力模糊；眩光（Glare）；夜間視力差；近視度數增加（核性白內障）；單眼複視
  • 手術適應症：視力影響日常生活（無絕對的視力數值）；需清楚看眼底（DR 追蹤）
  • 手術：超音波乳化術（Phacoemulsification）= 現代標準；人工水晶體（IOL）植入；術後視力多可恢復至 6/9 以上
  • 術後注意：眼藥水（抗生素 + 類固醇 + NSAIDs）4 週；避免揉眼；術後眼壓監測

感染性角膜炎（Infectious Keratitis）

類型特徵治療

乾眼症（Dry Eye）+ 葡萄膜炎（Uveitis）

乾眼症（Dry Eye Disease）

  • 分類：水液缺乏型（ADDE，如 Sjögren syndrome）；蒸發過度型（EDE，瞼板腺功能障礙 MGD，最常見）；混合型
  • 症狀：異物感、乾澀、燒灼感、畏光；下午加重（淚膜蒸發累積）；矛盾性流淚
  • 診斷：Schirmer test（<5 mm/5 min = 水液缺乏）；TBUT（淚膜破裂時間，<5 秒 = 異常）；角膜 Fluorescein 染色
  • 治療：
    • 人工淚液（首選，無防腐劑效果更好）
    • 瞼板腺熱敷 + 按摩（MGD）
    • Cyclosporine 0.05% 眼藥水（Restasis）= 中重度；抗炎
    • Lifitegrast（Xiidra）= LFA-1 拮抗劑
    • 淚點封閉（Punctal plugs）= 保留淚液
    • Omega-3 補充劑（輔助）

葡萄膜炎（Uveitis）

  • 前葡萄膜炎（前部 Uveitis / Iritis）：最常見；睫狀充血；裂隙燈見 Flare & Cell；KP（角膜後沉澱物）；後粘連；疼痛 + 畏光
  • 常見原因：HLA-B27 相關（AS、反應性關節炎、IBD、乾癬）；結節病；梅毒；TB；CMV（免疫缺陷）；特發性（50%）
  • 治療：局部類固醇眼藥水（Prednisolone acetate）；散瞳劑（Cyclopentolate = 放鬆睫狀肌 + 預防後粘連）；嚴重 / 後部 → 全身類固醇；免疫抑制劑
  • HLA-B27（+）前葡萄膜炎：反覆發作；單側交替；和 AS 活動度不完全平行
眼科急症 Ocular Emergencies（CRAO + 化學燒傷 + 眼前房積血 + 眼眶骨折）
眼化學燒傷是最緊急的眼科急症——立刻大量清水沖洗，不要等眼科。CRAO（視網膜中央動脈阻塞）是眼科的中風，黃金治療窗口極短。眼球破裂不可壓迫眼球，立刻眼科手術。各科 PGY 需要識別這些急症並給予第一線處置。
緊急處置
CRAO（視網膜中央動脈阻塞）+ 眼化學燒傷
眼化學燒傷 → 立刻大量清水沖洗 >30 分鐘！不要等眼科。

視網膜中央動脈阻塞（CRAO）

  • 臨床：突發無痛性單眼視力喪失（數秒至數分鐘內）；RAPD（+）；眼底：視網膜蒼白水腫 + Cherry-red spot（黃斑部）
  • 病因：血栓（頸動脈粥樣硬化最常見）；栓塞（AF 心臟栓子）；血管炎（GCA，老年人）
  • 黃金時間：視網膜缺血耐受約 90 分鐘；超過後不可逆損傷
  • 急性處置（目前缺乏確切有效治療）：眼球按摩（降低 IOP，嘗試移動栓子）；降眼壓（Acetazolamide / Timolol）；吸入高濃度 CO₂（血管擴張）；前房穿刺（Paracentesis）= 眼科執行；溶栓（僅選擇性患者）
  • 全身評估（重要！）：CRAO = 腦中風等效風險；立刻心臟和神經科評估；頸動脈超音波；心電圖；超音波心臟圖；GCA 排除（ESR/CRP，老年人）
  • 暫時性單眼視力喪失（Amaurosis fugax）= TIA 等效 → 緊急神經科評估 + 抗血小板

眼化學燒傷

  • 鹼燒傷（更危險）：液化性壞死；持續穿透；石灰 / 氨水 / NaOH
  • 酸燒傷：凝固性壞死；有自限性；電池酸液 / 氫氟酸
  • 立刻處置：大量清水 / 生理食鹽水沖洗 >30 分鐘；翻開眼瞼確保沖洗到穹隆部；沖洗後測 pH（目標 7.0-7.4）；局部麻醉眼藥（Proparacaine）協助配合
  • Roper-Hall 分級：I（預後佳，角膜清澈）→ IV（預後差，角膜混濁 + 肢部缺血 >1/2）
  • 後續治療：類固醇眼藥（前 10 天）；Ascorbate（維生素 C，抑制角膜潰瘍）；Citrate；人工淚液；嚴重 → 羊膜移植

眼前房積血（Hyphema）+ 眼球破裂 + 眼眶骨折

眼前房積血（Hyphema）

  • 原因：鈍傷（最常見）；術後；新生血管（Rubeosis）
  • 分級：Grade 1（<1/3 前房）→ Grade 4（全前房 / 8-ball hyphema）
  • 處置：頭抬高 30-45°（積血沉降）；眼罩保護（不要壓迫）；限制活動；類固醇眼藥（↓ 炎症 + ↓ 再出血）；眼壓監測（特別注意鐮狀細胞患者）；Grade 3-4 或 IOP 無法控制 → 外科沖洗
  • 再出血：3-5 天後風險最高；更嚴重；Aminocaproic acid（抗纖溶）= 部分使用

眼球破裂（Globe Rupture）

  • 警示徵兆：眼球變形；IOP 極低（軟眼）；結膜下出血（massive）；玻璃體脫出；淚滴形瞳孔（指向破裂方向）
  • 立刻：眼罩保護（Fox shield）；禁止壓迫眼球；NPO；破傷風預防；抗生素；緊急手術
  • Seidel test：Fluorescein 染色後見房水滲流 = 角膜 / 鞏膜破裂

眼眶骨折（Orbital Fracture）

  • 眶底骨折（Blowout fracture）：鈍傷 → 眶內壓↑ → 眶底骨折 → 下直肌嵌頓；垂直複視（上視困難）；眼球內陷；眶下神經麻木（臉頰 / 上唇）
  • CT（冠狀切面）：確認骨折範圍和肌肉嵌頓；「Teardrop sign」= 軟組織疝入上顎竇
  • 緊急手術適應症：肌肉嵌頓（兒童尤其）；白眼破裂（White-eyed blowout）= 兒童可有迷走神經反應（嘔吐、心搏過緩）；大面積骨折 + 眼球內陷
神經眼科 Neuro-ophthalmology（瞳孔異常 + 複視 + 視神經炎）
神經眼科是神經內科和眼科的交界。複視（Diplopia）需要區分單眼（眼球本身）vs 雙眼（神經肌肉問題）；視神經炎常是 MS 的首發症狀；乳突水腫（Papilledema）代表顱壓升高。各科 PGY 需要識別這些神經眼科徵象並適時轉介。

複視（Diplopia）+ 顱神經麻痺

複視評估流程

  • 步驟 1：單眼 vs 雙眼複視
    • 遮住一眼複視消失 = 雙眼複視（眼外肌 / 顱神經 / 神經肌肉接合部）
    • 遮住一眼仍有複視 = 單眼複視（角膜 / 水晶體 / 黃斑部病變）= 眼球本身問題
  • 步驟 2：哪個方向最嚴重（幫助定位受損肌肉 / 神經）
  • 步驟 3：其他神經學症狀（頭痛、眼瞼下垂、瞳孔異常）

顱神經麻痺鑑別

CN III（動眼神經）眼球下外偏（Down and out）多方向散瞳（+）→ 後交通動脈瘤（緊急 CTA）；散瞳（-）→ 糖尿病 / 微血管病變

視神經炎（Optic Neuritis）

  • 臨床：單眼視力下降（數天內進展）；眼球後方疼痛（眼動時加重）；色覺下降（紅色褪色）；RAPD（+）；眼底可正常（球後神經炎，65%）或視乳頭水腫
  • 最重要關聯：MS（多發性硬化症）= 50% 視神經炎患者最終診斷 MS；VEP（視覺誘發電位）延遲 = MS 客觀證據
  • ONTT 試驗：高劑量 IV Methylprednisolone（1 g/天 × 3 天）加速恢復但不改善最終視力；口服 Prednisone 低劑量反而增加復發 → 不建議口服類固醇
  • MRI 腦部：如有白質病變（Dawson fingers）→ 高風險 MS → DMT（疾病修飾治療）
  • 其他原因：NMO（神經脊髓炎，AQP4 抗體）；視神經脊髓炎譜系障礙（NMOSD）；感染後；結節病；梅毒

乳突水腫（Papilledema）

  • 定義：顱內壓升高引起的雙側視乳頭水腫（bilateral）；單側水腫 = 視神經炎 / 缺血性視神經病變
  • 眼底：視乳頭邊緣模糊；靜脈怒張；火焰狀出血；視杯消失；Paton lines（同心圓狀視網膜皺褶）
  • 原因：顱內占位；腦積水；靜脈竇血栓；特發性顱內高壓（IIH）= 肥胖年輕女性；腦膜炎
  • IIH（特發性顱內高壓）：頭痛（體位性）+ 暫時性視力模糊（視力瞬間變黑）+ 搏動性耳鳴；腰椎穿刺（ICP >25 cmH₂O）；治療：Acetazolamide；體重減輕；難治 → LP shunt / 視神經鞘開窗術
  • 乳突水腫本身不影響視力（初期）；長期 → 視神經萎縮 → 永久視力喪失 → 需定期視野追蹤
