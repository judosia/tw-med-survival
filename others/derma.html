皮膚評估基礎 Dermatological Assessment
皮膚科評估的核心是準確描述病灶形態（Morphology）。外用類固醇分級是 PGY 最常需要的實用知識：臉部 / 皺摺 / 嬰兒只能用弱效（Class VI-VII），手掌腳掌可用超強效。Wood's lamp（365 nm UV）可快速鑑別多種皮膚感染和色素疾患。
判斷框架
皮膚病灶形態術語（Morphology）

原發性病灶

術語定義舉例
Macule / Patch平坦色素變化；<1 cm = Macule；>1 cm = Patch雀斑、白斑、太田母斑
Papule / Plaque實心隆起；<1 cm = Papule；>1 cm = Plaque痤瘡、乾癬、扁平苔癬
Nodule深層實心隆起（至真皮/皮下）BCC、化膿性汗腺炎
Vesicle / Bulla含清澈液體；<1 cm = Vesicle；>1 cm = Bulla水痘/HSV；類天疱瘡/SJS
Pustule含膿液的隆起膿痂疹、膿皰性乾癬、痤瘡
Wheal（膨疹）短暫性水腫（數小時消退）蕁麻疹
Telangiectasia皮膚表面可見擴張微血管BCC、酒糟、CREST 症候群

繼發性病灶

術語定義 + 臨床意義
Scale（鱗屑）銀白色（乾癬）；油膩黃色（脂漏性）；糠皮樣（汗斑）
Crust（痂皮）蜜黃色（膿痂疹特徵）；乾燥血清/膿
Erosion / Ulcer糜爛 = 未至真皮（天疱瘡）；潰瘍 = 真皮以下（梅毒下疳、SCC）
Lichenification皮膚增厚 + 皮紋加深（慢性搔抓）；異位性皮膚炎慢性期
Burrow（隧道）蜿蜒線狀病灶 = 疥瘡特徵
Atrophy（萎縮）皮膚變薄；長期外用類固醇副作用
用藥指引
外用類固醇分級 + Wood's Lamp
強度Class代表藥物適用部位
超強效IClobetasol propionate 0.05%（Dermovate）手掌/腳掌；短期
強效II-IIIBetamethasone dipropionate；Mometasone furoate 0.1%（Elomet）軀幹/四肢；中重度濕疹
中效IV-VTriamcinolone acetonide 0.1%（Kenacort）軀幹/四肢；一般皮膚炎
弱效VI-VIIHydrocortisone 1-2.5%；Desonide 0.05%臉部/眼週/腹股溝/腋下/嬰兒
臉部/眼週/皺摺/嬰兒禁用強效類固醇！長期 → 皮膚萎縮、Telangiectasia、青光眼（眼週）、掩蓋感染（類固醇癬）。

Wood's Lamp（伍氏燈，365 nm UV）

疾病Wood's lamp 下表現
紅癬（Erythrasma）珊瑚紅螢光（Corynebacterium minutissimum）
頭癬（Microsporum）亮綠色螢光；Trichophyton 不螢光
白斑（Vitiligo）亮白色（ivory white）螢光
汗斑（Tinea versicolor）黃綠色螢光（Malassezia）
綠膿桿菌（P. aeruginosa）綠色螢光（Pyocyanin）
濕疹 + 皮膚炎 Eczema & Dermatitis
最常見類型是異位性皮膚炎（AD）——台灣兒童盛行率約 10-20%，常合併過敏性鼻炎和氣喘（過敏三聯症）。免疫機轉：急性期 TH2/IL-4/IL-13；慢性期 TH1。Filaggrin 基因突變 → 皮膚屏障↓。Dupilumab 現已納入台灣健保。
用藥指引
異位性皮膚炎（Atopic Dermatitis）

診斷標準（4 取 3）

  • 搔癢（Pruritus）
  • 典型分布（嬰兒：臉頰/伸側；兒童/成人：屈側皺摺）
  • 慢性或反覆發作病程
  • 個人或家族過敏史（氣喘/過敏性鼻炎/AD）

治療階梯

嚴重度治療
基礎（所有）保濕劑多次塗抹；避免誘發因子（刺激物、流汗）；溫水短時間沐浴
輕度弱效外用類固醇；外用 Tacrolimus / Pimecrolimus（鈣調神經磷酸酶抑制劑，臉部可長期使用）
中重度中強效外用類固醇；Crisaborole（PDE-4 抑制劑）；NB-UVB 光療；口服抗組織胺
重度Dupilumab（IL-4Ra 拮抗劑，抑制 IL-4+IL-13）；台灣健保給付；Tralokinumab；JAK 抑制劑（Baricitinib / Abrocitinib）
急性惡化短期口服類固醇；合併 S. aureus → Cephalexin
判斷框架
接觸性皮膚炎 + 脂漏性 + 蕁麻疹
疾病機轉特徵治療
刺激性接觸性（ICD）直接化學傷害（無需致敏）邊界清晰對應接觸部位；燒灼感 > 搔癢避開刺激物；保濕；外用類固醇
過敏性接觸性（ACD）Type IV 延遲型過敏（T 細胞）再接觸才發病；常見：鎳、香料、Neomycin；Patch test 金標準避過敏原；外用/口服類固醇
脂漏性皮膚炎Malassezia 相關油膩黃色鱗屑；頭皮/眉間/鼻側；HIV 患者更嚴重Ketoconazole 洗髮精/乳膏；弱效類固醇
汗皰疹（Pompholyx）不明（多汗相關）手掌/腳掌深層小水泡；劇烈搔癢強效外用類固醇（手掌可 Class I）

蕁麻疹（Urticaria）

  • 急性（<6 週）：IgE 媒介；膨疹單個 <24 小時消退；H1 抗組織胺；嚴重 → Prednisolone；過敏休克 → Epinephrine IM
  • 慢性（>6 週）：50% 不明原因；頑固性 → Omalizumab（抗 IgE）
  • 血管性水腫：深層水腫（臉/嘴唇/喉）；ACEi 引起（緩激肽）→ 停藥改 ARB；HAE（C1-INH 缺乏）→ C4 ↓
乾癬 + 糠疹 Psoriasis & Pityriasis
乾癬（Psoriasis）= 慢性自體免疫皮膚病；HLA-Cw6；好發 Extensor side 和頭皮。誘發因子：TIDES（Trauma、Infection 鏈球菌、Drugs、Stress、Sunlight）。指甲乾癬：Nail pitting 最常見；Salmon patch / Oil spot 最具特異性。禁用口服類固醇（停藥後反彈）。
用藥指引
乾癬亞型 + 治療階梯
亞型特徵
尋常性（最常見）銀白色鱗屑的紅色斑塊；伸側（膝、肘）；Auspitz sign；Koebner phenomenon；可融合成地圖狀
點滴狀（Guttate）多橘紅色（salmon pink）點滴狀病灶；鏈球菌感染後；年輕人；預後較好
乾癬性關節炎（PsA）30% 乾癬患者；非對稱性；DIP 關節；腊腸指（Dactylitis）；RF 陰性
膿皰性（Von Zumbusch）急性；全身無菌性膿皰；高燒；「Lake of pus」；需住院
乾癬性紅皮症>90% BSA 發紅；體溫調節障礙；心衰竭風險

加劇乾癬藥物（ABCD+LI）

  • β-blocker；ACEi；Lithium；Anti-malarials（Chloroquine）；Corticosteroid 突然停藥；Interferon-a

治療階梯

  • 輕度：外用類固醇；Calcipotriol（Vit D 類似物）；焦油（Coal tar）；水楊酸
  • 中重度：NB-UVB（311 nm，光療首選）；PUVA；MTX；Acitretin；Cyclosporine（短期）
  • 生物製劑：TNF-a 抑制劑（Etanercept / Adalimumab）；IL-17 抑制劑（Secukinumab）；IL-23 抑制劑（Guselkumab）；IL-12/23（Ustekinumab）
判斷框架
糠疹速查（Pityriasis）
疾病特徵 + 治療
玫瑰糠疹（Pityriasis Rosea）先驅斑（Herald patch）→ Christmas tree 分布；HHV-6/7 相關；自限（6-8 週）；NB-UVB 加速消退
汗斑（Tinea Versicolor）Malassezia 過度生長；KOH = 義大利麵加肉丸；Wood's lamp = 黃綠色；外用 Ketoconazole；口服 Itraconazole
毛孔角化症（Keratosis Pilaris）上臂外側雞皮疙瘩；常合併 AD；外用 Urea / Retinoid
感染性皮膚病 Infectious Skin Diseases
蜂窩性組織炎 vs 丹毒最常需要鑑別。壞死性筋膜炎外觀輕微但疼痛不成比例，立刻外科清創不能等。帶狀疱疹後神經痛（PHN）= 最常見併發症。疥瘡在安養院容易群聚，接觸者需一起治療。

細菌性皮膚感染速查

病毒性 + 黴菌性 + 疥瘡速查
疾病特徵 + 治療
帶狀疱疹（VZV）單側沿皮節水泡 + 劇痛；Hutchinson sign = 鼻尖水泡 → 眼帶狀疱疹風險；PHN 最常見併發症；Acyclovir（72 h 內）；PHN → Gabapentin；Shingrix 疫苗
HSV群聚水泡 → 潰瘍（痛）；反覆發作；Tzanck smear = 多核巨細胞；Acyclovir；復發頻繁 → 長期抑制
疣（HPV）Common wart：粗糙丘疹；Condyloma：HPV 6/11 良性、16/18 癌變；冷凍 / 水楊酸 / Imiquimod

黴菌性（Tinea）

  • KOH 鏡檢（菌絲 + 孢子）；Wood's lamp（Microsporum = 亮綠色）
  • 外用：Terbinafine / Clotrimazole / Ketoconazole（體癬/足癬）
  • 口服：Terbinafine 首選（甲癬、頭癬）；甲癬需 3-6 個月療程

疥瘡（Scabies）

  • Sarcoptes scabiei；夜間搔癢；好發指縫/手腕屈側/腹股溝；Burrow（隧道）= 特徵
  • 挪威疥：免疫缺陷患者；大量蟎蟲；傳染力極強
  • 治療：Permethrin 5%（全身 8-12 h）= 首選；Ivermectin PO（挪威疥）；同住者一起治療；衣物 60°C 洗滌
水泡病 + SJS/TEN Blistering Diseases & Drug Reactions
天疱瘡（Pemphigus）= 表皮內裂解，水泡易破，Nikolsky（+）；類天疱瘡（Pemphigoid）= 表皮下裂解，水泡緊實，Nikolsky（-）。SJS/TEN死亡率高，懷疑即停藥，越早越好。HLA-B*1502 + Carbamazepine 在台灣漢族是高風險組合，使用前需基因篩查。

常見致病藥物

  • Carbamazepine + HLA-B*1502（台灣漢族）：使用前需基因篩查
  • Allopurinol + HLA-B*5801；Phenytoin；Sulfa；Lamotrigine；NSAIDs

SCORTEN（TEN 死亡率預測，各 1 分）

  • 年齡 >40；惡性腫瘤史；HR >120；初始剝脫 >10% BSA；BUN >28 mg/dL；血糖 >252 mg/dL；HCO3 <20 mEq/L
  • 0-1 分：3.2%；2 分：12.1%；3 分：35.3%；4 分：58.3%；≥5 分：90%
  • 立刻停可疑藥物；燒燙傷病房；眼科會診（預防失明）；大量補液
  • Cyclosporine 3-5 mg/kg/天；IVIG 1 g/kg/天 × 3 天
  • DRESS = 廣泛皮疹 + 嗜酸性球↑ + 臉部水腫 + 內臟侵犯 + 用藥 2-6 週後發作；停藥 + 全身類固醇
色素疾患 Pigmentary Disorders
色素疾患分為脫色素和色素沉著兩大類。台灣人最常見的黑色素瘤亞型是肢端性（Acral lentiginous），好發手掌 / 腳掌 / 指趾甲下，與日曬無直接關係。任何符合 ABCDE 的黑色斑塊都需要切片確認。

皮膚腫瘤 Skin Tumors（BCC + SCC + Melanoma）
皮膚癌三大類：BCC 最常見（轉移罕見）；SCC 有轉移風險（口腔/生殖器最危險）；Melanoma 致死率最高。台灣最常見 Melanoma 亞型：肢端性（Acral lentiginous），不與日曬直接相關。最重要預後因子：Breslow thickness（腫瘤厚度）。
判斷框架
BCC vs SCC + 癌前病灶 + 手術切緣
BCC（最常見）SCC（第二常見）
起源基底層細胞角質細胞（Keratinocyte）
外觀珍珠樣有光澤結節；Telangiectasia；Rodent ulcer；無痛增厚結節/潰瘍/結痂；出血；邊緣不規則
轉移罕見（<0.1%）有轉移風險（口腔/生殖器 SCC 較高）
病理Nuclear palisading；Retraction artifact；Tumor island角化珠（Keratin pearl）；細胞間橋
手術切緣低風險 4-5 mm；高風險 → Mohs surgery低風險 4-6 mm；高風險 → Mohs surgery
治療手術切除（首選）；Mohs；Vismodegib（轉移性，Hedgehog 抑制劑）手術切除；Cemiplimab（PD-1，晚期）

癌前病灶

  • 日光性角化症（AK）：SCC 前期；慢性 UVB；冷凍/5-FU/Imiquimod
  • Bowen's disease（SCC in situ）：未穿破基底膜；治療同 AK
  • 角化棘皮瘤：SCC 變型；中央火山口形；建議切除排除真正 SCC

  • Superficial Spreading（70%）：最常見；水平生長期長；白人多
  • Nodular（15%）：直接進入垂直期；生長快；外觀似藍莓；預後差
  • Acral Lentiginous（5-10%）：台灣最常見；東亞/非洲裔；手掌/腳掌/指甲下；好發 >60 歲；不與日曬相關
  • Lentigo Maligna（5%）：老人臉部；慢性日曬；水平期可達 20 年
  • 手術切緣：<1 mm → 1 cm；1-2 mm → 1-2 cm；>2 mm → 2 cm
  • SLNB：>1 mm 或有潰瘍
  • 轉移：淋巴結 → 肺 → 腦 → 肝 → 骨頭
  • BRAF V600E（~50%）：Vemurafenib + Trametinib
  • 免疫治療：Pembrolizumab / Nivolumab（PD-1）；Ipilimumab（CTLA-4）
自體免疫皮膚病 Autoimmune Skin Diseases
皮膚是多種自體免疫疾病的窗口。皮肌炎成人患者需積極排除惡性腫瘤（東亞人特別注意 NPC 鼻咽癌）。SLE 皮膚表現分急性/亞急性/慢性，各有不同抗體關聯。結節性紅斑是最常見的脂膜炎。
